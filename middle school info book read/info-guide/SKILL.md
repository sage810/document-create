## 활동지 만들기 순서

1. **단원 확정** — 요청한 주제를 [단원 색인](#단원-색인)에서 ch 번호로 바꾼다.
2. **ch 파일의 해당 소단원 읽기** — 소단원마다 같은 순서로 정리되어 있다:
   `수업 흐름(차시별 도입–전개–정리)` → `동기 유발 — 새싹 틔우기` → `전개 — 본문 흐름과 핵심 개념` → `발문 모음(표)` → `활동` → `형성 평가` → `활동지 제작 아이디어 (제안)`.
   중단원 첫 차시면 파일 앞의 `중단원 도입 — 생각의 씨앗 심기`도 본다.
3. **수업 흐름 맞추기** — "수업 흐름"의 도입·전개(➊➋➌)·정리를 활동지 카드 순서로 옮긴다. 대응표는 [patterns.md 「활동지 카드 대응」](patterns.md#middle-school-info-활동지-카드-대응).
4. **지도서 활동지 확인** — 그 단원 부록 `uN-appendix.md`의 「수행 평가 활동지」에서 양식(칸 구조·예시 답·평가 기준)을 본다. 이미 있는 양식을 변형하는 것이 가장 빠르다. 지도서도 "수행 평가가 아닌 수업 활동지로 응용할 수 있다"고 안내한다(p.35).
5. **확인 문제** — 부록의 「쏙쏙 요약 정리」(굵은 글씨 = 빈칸 정답 낱말), 「똑똑 형성 평가」, 「시험 대비 단원 평가」의 출제 개념으로 빈칸·O/X·고르기 문항을 만든다. 문항 문장은 새로 쓴다.
6. **평가 칸** — 성취 수준 A/B/C(차시별 지도 계획)와 A~E(중단원 마무리 뒤·총론 5절)를 쓴다. 채점 기준 수식어 위계: 정확하게·명확하게 > 대체로 > 부분적으로 → [ch00 5절](chapters/ch00-overview.md).
7. **점검** — [cheatsheet.md 「원문 오류 의심」](cheatsheet.md#원문-오류-의심-목록)에 걸리는 정답·코드는 그대로 쓰지 않는다. 외부 사이트(티처블 머신, 엔트리, 캐글, 커리어넷, 스마트쉼센터 등)는 수업 전에 접속을 확인한다. 민감 주제(사이버 폭력, 과의존 척도)는 결과 비공개와 상담 연계 안내를 넣는다.

## 핵심 틀 (단원을 가로지르는 개념)

- **성취기준 코드** `[9정AA-BB]`: 영역 01 컴퓨팅 시스템(3개) · 02 데이터(5개) · 03 알고리즘과 프로그래밍(9개) · 04 인공지능(5개) · 05 디지털 문화(3개) = 25개 → [ch00 2절](chapters/ch00-overview.md).
- **교과 역량 3가지**: 컴퓨팅 사고력(추상화·자동화·창의·융합) / 디지털 문화 소양(의사소통·협업, 윤리의식, 기술 활용) / 인공지능 소양(AI 문제 해결력, 데이터 문해력, AI 윤리의식).
- **입력–처리–출력(IPO)**: Ⅰ 컴퓨팅 시스템 동작 원리 → Ⅰ 피지컬 컴퓨팅(센서–마이크로컨트롤러–액추에이터) → Ⅲ 문제 추상화(IPO 표) → Ⅲ 모든 프로젝트의 "입력, 처리, 출력 형태로 만들어 보기". 단원을 잇는 가장 강한 줄기.
- **문제 상태 정의**: 초기 상태 → 현재 상태 → 목표 상태 + 핵심 요소(ch05). ch06·ch07의 모든 프로그래밍 활동이 "문제 정의 → 핵심 요소(오브젝트·변수·기능 표) → 알고리즘 설계 → 코드" 4단 지시문을 되풀이한다.
- **문제 해결 5단계가 단원마다 있다** (이름이 조금씩 다름):
  - Ⅱ 데이터 분석: 문제 정의 → 계획 수립 → 데이터 수집 → 구조화 및 분석 → 결론 정리 (ch04)
  - Ⅲ 프로그래밍: 문제 이해·추상화 → 알고리즘 → 프로그래밍 → 실행 및 디버깅(분석) → … (ch07 생각의 씨앗)
  - Ⅳ 인공지능: 문제 정의 → 데이터 수집 → 모델 선택·학습 → 모델 사용·평가 → 문제 해결 (ch09)
- **데이터 → 인공지능 연결**: 디지털 표현·수집·관리(ch03) → 구조화·분석·결측치·이상치(ch04) → 학습 데이터·전처리·증강(ch08) → 데이터 편향(ch09) → 개인 정보(ch11).
- **도구 흐름**: MakeCode·마이크로비트(Ⅰ) → 스프레드시트·Audacity·엔트리 데이터 분석(Ⅱ) → 엔트리(주)·스크래치(병기)(Ⅲ, 파이썬 없음) → 티처블 머신·엔트리 AI 블록(Ⅳ) → 커리어넷·스마트쉼센터·CCL(Ⅴ).
- **평가 운영 예시**: 지필 40% + 수행 60%(과제 2개 × 30점), 고정 분할 A~E. 수행 과제 예: 컴퓨팅 시스템 구현하기[9정01-03], 데이터 분석하기[9정02-03], 문제 해결 프로그래밍[9정03-07], 인공지능 윤리 실천하기[9정04-05] → [ch00 5절](chapters/ch00-overview.md).

## 범위와 한계

- 지도서 원문을 요약·재구성한 기록이다. 원문 그대로인 것은 발문·지시문·말풍선·학습 목표·성취기준·성취 수준·평가 기준뿐이다. 짧은 블록 코드는 구조를 옮겨 적었다.
- 지도서에 실린 교과서 축쇄면 기준이다. 교과서 원본에만 있는 실습 파일(T셀파 자료실 zip), 화면 속 세부 값(용돈 실습 행 값, 일부 그래프 값)은 "확인 불가"로 표시되어 있다.
- 2단 편집이 섞인 쪽은 문맥으로 복원했고, 각 파일에 복원했다고 적혀 있다.
- 지도서와 이 기록은 저작물을 바탕으로 한 것이므로 공개 저장소에 올리지 않는다.
