### 코드·실습이 조건과 맞지 않는 것
- p.101 u1 활동지 05: 알고리즘은 0~9 난수인데 코드는 1~8 → X(0)·네모(9)가 안 나옴.
- p.82 축제 카운터: `인원수 > 100`이면 경고라서 101명까지 입장. B 버튼 0 미만 방지 없음.
- p.230 ch06 활동 8-3: 의미 없는 `숫자에 10만큼 더하기` 블록, 논리 연산자 활용이라면서 중첩 조건만 사용.
- p.232~233 장애물 게임: 알고리즘 480·이하 vs 코드 470·<.
- p.259 정비례 그래프: y=4x가 엔트리 무대 y 범위 ±135를 대부분 벗어남. 변수 a를 만든다고 했으나 코드는 '대답'을 바로 곱함.
- p.264~265 대단원 마무리(Ⅲ) 06·배경 움직이기: 그리기/채우기 블록 짝 불일치, 두 배경 코드가 뒤바뀐 듯.
- p.275 u3 활동지 05: 삭제하기 예시 답이 "추가하기" 블록.
- p.278~279 u3 활동지 07: "불 꺼"에 "불 켜" 신호, 읽어주기 문구도 "불을 켭니다."
- p.282~283 u3 활동지 09: 알고리즘 1~3초 vs 코드 0.5~2초, 신호 이름 '때렸다'/'때리기' 혼용.
- p.284 u3 활동지 10-1: 오류 내용 예시 답이 문제 서술·코드와 맞지 않음.
- p.320 티처블 머신 단계 4: "새 이미지를 올린 후 학습시키면" — 실제로는 재학습 없이 미리보기에서 바로 분류.
- p.325·302 폐렴 분류: 문제 상황 "흉부 CT", 실제 데이터는 흉부 엑스레이.
- p.348 u4 활동지 02: 단계 4·5 순서 뒤바뀜(문제 해결하기 ↔ 모델 사용하기). p.353 활동지 05 단계 5에 활동지 03 문장 복사.

- 성취 수준 A=B 또는 C=D 중복 인쇄: p.46·p.85 [9정01-03], p.209 [9정03-01], p.300 [9정04-03].
- 운영 계획(p.39~43) 시수 Ⅱ12/Ⅲ21/Ⅳ15 vs 연간 계획(p.36~37) Ⅱ10/Ⅲ22/Ⅳ16. p.44 지필 "100점(60%)"은 40%의 오기.
- p.40 [9정03-04]가 "2. 프로그래밍"에 배치(연간 계획은 1중단원).
- 차시 계획표의 지도서·교과서 쪽수가 실제와 어긋남: p.174(Ⅲ-1-01), p.248(Ⅲ-3-02 148~155 → 148~151), p.362(Ⅴ-1-01).
