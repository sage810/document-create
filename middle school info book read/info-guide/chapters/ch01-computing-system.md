# ch01 컴퓨팅 시스템의 구성과 동작
> 대단원: Ⅰ. 컴퓨팅 시스템 | 지도서 p.52~73 | 교과서 12~25쪽 | 성취기준: [9정01-01] | 차시: 4차시 (01 동작 원리 2차시 + 02 운영체제의 기능 2차시)

## 핵심 한 줄
- 모양·크기가 달라도 모든 컴퓨팅 시스템은 하드웨어+소프트웨어(시스템 SW/응용 SW)의 상호 작용으로 '전원→부팅→OS→응용 프로그램→입력·처리·저장·출력→종료' 순으로 동작하며, 운영체제는 사용자 인터페이스와 자원 관리(프로세스·주기억 장치·입출력 장치·파일)를 맡는다. (p.67, p.71)

## 대단원 개관
### 대단원 성격 (p.52)
- 하드웨어·소프트웨어 구성 요소로 컴퓨팅 시스템 작동 원리를 설명하고, 친숙한 실생활 사례로 문제 해결 방식을 이해하게 설계함.
- 운영체제의 역할·기능 학습 → 센서·액추에이터로 물리적 환경과 상호 작용하는 피지컬 컴퓨팅 개념·사례 → 피지컬 컴퓨팅 보드와 프로그램으로 현실 문제 해결, 창의·융합적 사고 함양. (p.52)

### 대단원 지도 목표 (원문, p.52)
1. "컴퓨팅 시스템을 구성하고 있는 하드웨어 장치 간의 관계와 역할, 하드웨어와 소프트웨어의 관계와 역할을 이해할 수 있다."
2. "실생활에서 사용되고 있는 다양한 컴퓨팅 시스템의 구성과 동작 원리를 분석할 수 있다."
3. "운영체제의 개념과 역할을 이해하고, 운영체제의 기능을 분석할 수 있다."
4. "피지컬 컴퓨팅의 개념을 이해하고, 시스템을 구성하는 다양한 입출력 장치를 알 수 있다."
5. "피지컬 컴퓨팅 시스템의 입출력 프로그램 과정을 이해하고, 실생활에 필요한 피지컬 컴퓨팅 장치를 구상하고 프로그램을 작성할 수 있다."

### 대단원 핵심 역량 (p.53)
- **컴퓨팅 사고력**(추상화·자동화·창의·융합 능력): 이 단원에서는 피지컬 컴퓨팅 보드로 일상 문제를 해결하는 시스템을 구현해 봄.
- **디지털 문화 소양**(디지털 의사소통 협업·디지털 윤리의식·디지털 기술 활용 능력): 정보 사회를 구성하는 컴퓨팅 시스템의 구성 요소·동작 원리를 배우고, 인간과 상호 작용하며 함께 발전함을 이해. (p.53)

- 지도 방안(p.60): 과거 모습과 오늘날을 비교 → 크게 변한 부분과 **시간이 흘러도 유지되는 특징**을 관찰·대화 → 미래 컴퓨팅 시스템이 사회에 어떤 형태로 등장·기능할지 자유롭게 이야기.
- 예시 답안(p.60): ① 분자 크기 초소형 시스템이 몸 안에서 정보 수집·분석해 질병 예방·치료 ② 속도 향상으로 고사양 프로그램이 스마트폰·스마트워치에서도 동작 ③ 다양한 사물에 컴퓨팅 기능이 추가되어 삶 전반이 편리해짐.
- 지도서 해설 소재(p.61)
  - 다양한 인터페이스: 초기 컴퓨터는 형태가 많이 달랐지만 키보드(입력)·모니터(출력) 같은 기본 입출력 장치는 기본 기능이 유지됨.
  - 인터페이스의 확장 VR: 60년대 VR은 무겁고 복잡 → 현재 가볍고 단독 실행. 뉴럴 링크 같은 두뇌 직접 연결 기술 실험 중 → VR/AR로 게임·예술·의료·교육에 적용.
  - 컴퓨팅 성능의 발전: 무어의 법칙(트랜지스터 수가 18~24개월마다 2배). 1964년 슈퍼컴퓨터 CDC-6600은 1메가플롭스, 초기 라즈베리파이는 42메가플롭스. 출처 https://zdnet.co.kr/view/?no=20140630104055
- 지식 플러스 "모든 데모의 어머니"(p.61): 1968년 샌프란시스코 학회에서 더글러스 엥겔바트가 마우스, 워드 프로세서의 시초 소프트웨어, 실시간 화상 회의를 시연 → "모든 데모의 어머니(The Mother of All Demos)". 출처 https://invention.si.edu/mother-all-demos

## 소단원 01 컴퓨팅 시스템의 동작 원리 (교 14~19쪽, p.62~67)
### 수업 흐름 (차시별 지도 계획)
#### 1차시 (p.54) — 교 12~17쪽, 지도서 60~65쪽, 1시간
- **학습 목표**: "컴퓨팅 시스템의 개념을 이해하고, 실생활 속에서의 활용 사례를 찾을 수 있다." / "컴퓨팅 시스템의 구성 요소를 설명할 수 있다."
- 수업 형태: 협동 학습, 문제 기반 학습, 탐구 학습, 토의·토론 학습 / 준비물: 교과서, 노트와 필기도구, 컴퓨터 또는 태블릿
- **도입**
  - 생각의 씨앗 심기로 컴퓨터가 과거부터 지금까지 다양한 모습과 성능으로 발전하고 있음을 안내.
  - 새싹 틔우기로 주변에 여러 형태·크기의 컴퓨팅 시스템이 존재함을 안내.
  - 유의점: 과거에서 오늘날까지 모습이 많이 바뀌었지만 **시간이 흘러도 유지되는 특성**이 있는지 생각해 보게 함 / 성능·용량이 크게 발전해 긍정적으로 바뀐 점을 이야기.
- **전개**
  - ➊ 컴퓨팅 시스템의 개념과 구성 요소 이해하기: 컴퓨팅·컴퓨팅 시스템의 정의 설명, 기본 구성으로 하드웨어와 소프트웨어 인식.
  - ➋ 내 주변의 컴퓨팅 시스템 알아보기: 가까운 곳~먼 곳, 작은 것~큰 것까지 구체적 사례로 설명, 다양한 컴퓨팅 시스템이 삶에 끼치는 영향 토의.
  - ➌ 컴퓨팅 시스템의 구성 요소 알아보기: 하드웨어/소프트웨어로 나눠 구체적 설명, HW와 응용 SW를 연결하는 시스템 SW 개념 설명, 주변 컴퓨팅 시스템을 HW/SW로 나눠 구성 요소를 찾고 토의.
  - 유의점: 다양한 모습의 시스템의 **공통된 구성 요소** 이해 / HW는 인터넷 검색으로 이미지를 찾고, 실제 시스템에서 구성 요소를 하나씩 짚어보는 시간 / 시스템 SW 설명 시 이후 배울 운영체제 개념 소개.
- **정리**: 정의와 구성 요소 정리, 주변 시스템의 종류와 역할 정리, 차시 예고. 유의점: 형성 평가로 스스로 정리.

#### 2차시 (p.55) — 교 18~19쪽, 지도서 66~67쪽, 1시간
- **학습 목표**: "컴퓨팅 시스템의 동작 원리를 설명할 수 있다." / "다양한 컴퓨팅 시스템의 문제를 해결하는 방식을 설명할 수 있다."
- 수업 형태: 협동, 문제 기반, 탐구 학습 / 준비물: 교과서, 노트와 필기도구, 컴퓨터 또는 태블릿
- **도입**: 전시 학습 확인[컴퓨팅 시스템의 개념과 구성 요소]. 주변 시스템과 기능을 복습하고 "서로 다른 역할을 가졌지만 컴퓨팅 시스템으로써 공통된 요소가 있는지 발문"한다. 유의점: 기본 구성 요소인 HW·SW 숙지.
- **전개**
  - ➊ 동작 원리 이해하기: 자주 쓰는 응용 SW의 실행 과정을 부팅~종료 흐름에 따라 설명. 주요 개념(부팅, 운영체제, 응용 소프트웨어). 입력-처리-저장-출력에 쓰이는 구성 요소(입력 장치, CPU, 주기억 장치, 보조 기억 장치, 출력 장치).
  - ➋ 주변 다양한 시스템의 동작 원리: 키오스크 주문 과정으로 설명 → **스마트폰 사용을 기본 동작 원리에 맞춰 설명하는 모둠 활동**.
  - ➌ 다양한 시스템이 해결하는 문제 찾기: (활동으로 쑥쑥 1) 직접 사용하는 시스템을 찾고 동작 원리에 맞춰 어떤 문제를 해결하는지 조사.
  - 유의점: 응용 SW 실행 중 OS와 HW가 함께 상호 작용함을 이해 / 서로 다른 시스템의 공통 동작 원리 / 데스크톱·스마트폰·키오스크 등 체험한 것 먼저, 이후 다른 시스템으로 확장.
- **정리**: 모둠 활동으로 본 여러 시스템이 서로 다른 문제를 해결하지만 유사한 원리로 동작함을 정리, 차시 예고. 유의점: 모둠별 공통점·차이점을 찾아 발표.

### 동기 유발 — 새싹 틔우기
- 제목 발문: "다양한 컴퓨팅 시스템을 알아볼까요?" (교 14쪽, p.62)
- 4칸 만화(렌더링 확인):
  1. 스마트폰을 든 아이: "스마트폰도 컴퓨팅 시스템이지!"
  2. 손목의 스마트워치: "스마트워치도 컴퓨팅 시스템이지!"
  3. 자율주행 자동차 등 여러 기기에 둘러싸인 아이: "자율주행 자동차는 물론이고" "이것도" "저것도" "어휴."
  4. 구름 위의 아이: "클라우드 컴퓨팅이란 말이 있는데, 하늘의 구름도 컴퓨팅 시스템인가?" (보조단 *클라우드 컴퓨팅: 인터넷으로 컴퓨팅 자원을 제공하는 기술. 내 컴퓨터에 설치·소유하지 않아도 사용)
- 해설(p.62): 이미 다양한 크기·모양의 시스템이 생활에 자리 잡았고, 예전엔 컴퓨팅 시스템이라 생각하지 않았던 것들도 정보 처리 기능이 확장되어 컴퓨팅 시스템으로 활용됨을 설명하고 실생활 사례를 찾게 함.
- 더 알아보기(p.62): 클라우드는 물리적 HW 구매·유지 보수 없이 자원 확장·SW 업데이트가 쉬워 효율적, 인터넷으로 문서 작성·사진 저장 등 언제 어디서든 자원 접근.
- 지식 플러스 "컴퓨팅 시스템의 활용"(p.62): 미디어 아티스트(관객과 상호 작용하는 작품의 붓·조각칼), 생명 과학자(DNA 유전 정보 처리 프로그래밍), 데이터 분석 전문가(처리·분석·시각화).

### 전개 — 본문 흐름과 핵심 개념
**1 내 주변의 컴퓨팅 시스템 (교 14~15쪽, p.62~63)**
- 컴퓨팅 = 컴퓨터를 이용해 정보를 처리하고 필요한 일을 해결하는 과정. 컴퓨팅 시스템 = 사용자가 원하는 일을 처리하도록 HW·SW로 구성된 도구. [그림 Ⅰ-1] HW(눈에 보이고 만질 수 있는 물리적 전자 장치) / SW(HW를 활용해 특정 작업을 수행하는 프로그램의 모음, 시스템 SW와 응용 SW).
- 말풍선 발문: "실생활에서 컴퓨팅 시스템이 어떻게 활용되는지 찾아보아요."
- [그림 Ⅰ-2] 활용 사례: 태블릿(터치스크린·모바일 OS, 강의 시청·전자펜 그래픽·필기), 노트북(고성능+휴대), 스마트폰(통화·문자·카메라·인증·결제·통신), 스마트워치(운동량·걸음 수·심박수·수면, 스마트폰 연동 알림), 자율주행 자동차(센서·GPS·전자 제어 장치·인공지능, 위치·속도·연료 관리). 공공 기관·학교·병원·기업 업무의 디지털화로 크고 작은 시스템이 동작.
- 해설(p.63): 겉모습은 달라도 HW·SW 상호 작용으로 동작하는 공통점. 범위 확장: 소형(스마트폰·노트북·웨어러블) → 자율주행차·스마트 홈 → 도시 차원(공공 교통 관리, 에너지 관리, 스마트 시티) — 소형 시스템이 연결되어 통합 시스템을 형성.

**2 컴퓨팅 시스템의 구성 요소 (교 16~17쪽, p.64~65)**
- SW = 시스템 SW(HW 제어, 응용 SW가 잘 작동하도록 환경 제공: 운영체제(OS), 드라이버 등, Link 20쪽) + 응용 SW(목적에 따른 작업: 워드 프로세서, 그래픽 편집, 웹 브라우저, 게임).
- [그림 Ⅰ-3] 개인용 컴퓨터(PC) HW: 입력 장치(카메라, 마이크, 키보드, 마우스, 터치스크린, 스마트폰의 소리·밝기 센서) / 처리 장치(CPU: 두뇌, 연산 및 장치 관리·제어; GPU: 고속 그래픽 연산 후 모니터 출력; 최근 AI 전용 처리 장치) / 터치스크린은 입출력 동시. 말풍선 "내가 도와줄게!" "그림을 그려 보자."
- 보조단 QnA: "컴퓨터를 이용하여 그림 그리는 경우를 살펴볼까요?" → 사용자가 응용 SW인 그림판 실행 → 필요한 HW 요청 → OS가 요청을 받아 HW 할당·관리.
- [그림 Ⅰ-4] 스마트폰: 기억 장치(주기억 RAM = 프로세스·데이터 임시 저장 / 보조 기억 HDD·SSD = 장기 저장), 출력 장치(모니터, 터치스크린, 스피커, 프린터), 통신 장치(유선, 와이파이, 블루투스; 전자 우편·문서 편집기·파일 저장소).
- 용어: 드라이버(장치 드라이버, OS와 HW·주변 기기 입출력 제어 SW) / HDD(자기장, 비휘발) / SSD(반도체, 빠른 접근·소형화로 HDD 대체) / 프로세스(프로그램이 실행되어 명령어·데이터가 메모리에 올라가 있는 상태).
- 말풍선 발문: "스마트폰에서 하드웨어와 소프트웨어는 어떻게 상호 작용하는지 예를 들어 이야기해 보세요."
- 해설(p.64~65)
  - 응용 SW 종류 표: 워드 프로세서(MS워드, 한글, 워드, 페이지), 스프레드시트(엑셀, 구글 시트, 넘버스), 프레젠테이션(파워포인트, 키노트, 임프레스), 그래픽(드로우, 김프, 포토샵).
  - 데스크톱 HW는 구분이 명확하고 교체 쉬움 / 모바일은 통합되어 교체·업그레이드 어려움.
  - CPU: 인출→해석→실행 반복. GPU: 많은 코어로 대량 데이터 병렬 처리.
  - 새 인터페이스 VR·AR 관련 입출력 장치 등장, VR 기기는 가상 공간의 이미지를 보고·듣고·활용.
  - HW·SW 상호 작용 예: 카메라 앱(SW)↔카메라 모듈(HW), 자판기 버튼(HW)→내장 프로그램(SW)이 음료 배출, 스마트워치 센서(HW) 수집→전용 앱(SW) 분석.
  - 기억 장치: RAM은 빠르지만 휘발성, HDD·SSD는 느리지만 비휘발성.
  - 통신 장치 예: 학교 컴퓨터→학교 로컬 네트워크→ISP→글로벌 인터넷 백본→외국 서버. 푸드코트 호출 벨도 무선 통신.

**3 컴퓨팅 시스템의 동작 원리 이해 (교 18쪽, p.66)**
- [그림 Ⅰ-5] 전원 → 부팅으로 OS 실행 → 응용 프로그램 실행 → 주기억 장치의 프로그램·데이터를 CPU가 처리 → 결과를 보조 기억 장치에 저장 또는 출력 장치로 출력 → 필요 시 통신 장치로 다른 시스템과 정보 교환 → 응용 프로그램 종료 → 시스템 종료.
- 부팅: 전원이 들어온 뒤 사용 가능한 상태가 될 때까지의 과정, HW 점검·설정 불러오기.
- [그림 Ⅰ-6] 키오스크: 응용 프로그램 + 운영체제(윈도/리눅스) + HW(입력: 주문 화면 터치스크린, 바코드 대는 곳, 카드 넣는 곳 / 처리: CPU, RAM / 출력: 영수증 나오는 곳).
  - 입력: 메뉴를 터치스크린으로 선택 / 처리: 비용 계산, 결제 시 조리실 전송 / 저장: 오늘의 매출로 기록 / 출력: 스크린 표시 또는 영수증 인쇄.
- 해설(p.66): 기본 원리는 같아도 단계별 차이 — 부팅(PC는 BIOS가 HW 검사·OS 불러오기에 시간, 스마트 가전은 매우 짧음; BIOS 정의), OS·응용 프로그램(PC·모바일은 GUI와 다양한 앱 환경, 키오스크·스마트 가전은 특정 기능 특화).
- 동작 이상 확인(p.66): 전원 연결(전원 공급 장치·배터리·배선), 부팅(BIOS·HW 문제), OS 실행(오류 메시지·손상 부분 확인), 응용 프로그램 실행(호환성·버그·메모리 부족), 종료(비정상 종료·**좀비 프로세스** → 작업 관리자 확인).

### 활동
#### 활동 플러스 "컴퓨팅 시스템으로 해결할 수 있는 문제 찾아보기" (p.63)

- 예시: 학교 태블릿(AI 디지털 교과서, 검색·데이터 수집) / 운동하는 사람의 스마트워치(거리·운동량 계산·저장, 심박수로 몸 상태) / 대도시 공공 교통 관리(실시간 차량 수, 신호 체계 관리).

#### 활동 플러스 "입력 장치, 출력 장치 관찰하고 토론하기" (p.65)

- 예시: 휴대용 게임기(입력: 십자 키·조이스틱·버튼 / 출력: 스크린·스피커), 음료 자판기(입력: 버튼·현금·카드 인식 / 출력: 가격 LED·음료 배출), 버스 교통카드(입력: 카드 인식 / 출력: 결제 화면·스피커).

#### 활동 플러스 "생활 속 컴퓨팅 시스템의 동작 원리 비교해 보기" (p.66)

- 예시: 데스크톱 vs 스마트폰(스마트폰은 한 번 부팅 후 종료보다 잠자기 모드 유지) / 스마트 TV(멀티미디어 오락 특화 OS, 리모컨 입력) / 은행 ATM(보안·정확성 위해 엄격한 OS, 통장·돈 관리 최적화).

#### 활동으로 쑥쑥 1 "컴퓨팅 시스템 이해하기" (교 19쪽, p.67) — 개인→모둠, 조사·분석
- **목표**(지도 목표): 구성 요소를 알고 동작 원리를 이해해 주변 다양한 시스템을 파악.
- **단계**
  1. "내가 사용하는 컴퓨팅 시스템의 하드웨어와 소프트웨어 종류와 사양을 찾아보자." — 예시 답: CPU Intel Core i5 5300U / 메모리 16GB / SSD 1TB / 운영체제 windows 11.
  2. "내가 사용하는 컴퓨팅 시스템을 찾아보고, 컴퓨팅 시스템의 동작 원리에 맞춰 어떤 문제를 해결하는지 조사해 보자." — 칸: ① 내가 사용하는 컴퓨팅 시스템은? ② 해결하려는 문제는? + 표 [입력 | 처리 | 저장 | 출력].
     - 예시: 스마트워치 / "내가 평소에 잠을 잘 자고 있을까?" / 입력: 자는 동안 움직임·코 고는 소리 감지 / 처리: 코 고는 소리가 들리면 횟수 추가 / 저장: 코 고는 소리와 시간대 저장 / 출력: 그래프 등 시각적 데이터로 상태 알림.
  3. "우리 일상의 다양한 분야에서 새로운 컴퓨팅 시스템이 등장하고 있다. 최근에 발견했거나 앞으로 새롭게 등장하면 좋을 것 같은 컴퓨팅 시스템을 생각해 보고, 하드웨어와 소프트웨어에 어떤 기능이 있으면 좋을지 토론해 보자." — 표 [컴퓨팅 시스템 | 하드웨어 | 소프트웨어].
     - 예시: 서빙 로봇 / 모터·카메라·스피커 / 테이블 번호로 위치 파악, 장애물 회피.
- **지도상의 유의점**: 기본 구성·동작 원리가 종류에 따라 다양한 모습으로 적용됨을 설명, 이를 바탕으로 주변 시스템을 살펴보도록 유도.
- **활동 평가 항목**: "컴퓨팅 시스템의 하드웨어와 소프트웨어를 구분할 수 있는가?" / "컴퓨팅 시스템의 동작 원리를 자신이 사용하는 컴퓨팅 시스템에서 특정 응용 소프트웨어를 활용하여 수행하는 과정을 예로 들어 설명할 수 있는가?"
- 평가 도구: 수행 평가 활동지(p.96~97), 시험 대비(p.104~107).

### 형성 평가 · 핵심 개념 정리하기 (p.67)
- 형성 평가 1 (빈칸): 하드웨어를 활용해 특정 작업을 수행하는 프로그램의 모음 → **소프트웨어** / 시스템 **소프트웨어**, 응용 **소프트웨어**.
- 형성 평가 2 (OX): "모니터와 스피커는 대표적인 입력 장치이다." → X (출력 장치).
- 핵심 개념 정리: 다양한 컴퓨팅 시스템(스마트워치~자율주행차·스마트 홈) / HW와 SW 정의·상호 작용 / 기본 동작 원리 '전원 연결 → 부팅 → 운영체제 실행 → 응용 프로그램 실행 → 원하는 작업 수행 → 응용 프로그램 종료 → 운영체제 및 컴퓨팅 시스템 종료', 작업 수행 시 '입력 → 처리 → 저장 → 출력' 반복.

### 활동지 제작 아이디어 (제안)
1. **컴퓨터 시간 여행 카드**: 씨앗 심기 1~5 사진(1956년 5MB 디스크, 아폴로 1.024MHz, CDC-6600 1메가플롭스 vs 라즈베리파이 42메가플롭스)을 카드로 → 변한 점/변하지 않은 점 T차트 → "미래의 컴퓨팅 시스템은 어떻게 변화할까?" 한 문장 예측.
2. **우리 집 컴퓨팅 시스템 지도**: 작은 것(스마트워치)~큰 것(스마트 시티) 동심원에 기기 배치 → 각 기기의 입력/처리/기억/출력/통신 장치 분류표 → 정리 OX(모니터·스피커는 입력 장치?).
3. **키오스크 해부 활동지**: 키오스크 그림에 HW 부위 이름 붙이기 → 주문 시나리오를 입력·처리·저장·출력 4칸으로 → 스마트폰 앱 하나로 같은 표 작성(모둠) → 공통점·차이점 발표.
4. **고장 탐정**: 전원/부팅/OS/응용/종료 각 단계에서 생긴 증상 카드(예: 프로그램이 종료 버튼에 반응 없음)를 단계와 연결하고 해결책(작업 관리자 등) 쓰기.

## 소단원 02 운영체제의 기능 (교 20~25쪽, p.68~73)
### 수업 흐름 (차시별 지도 계획)
#### 3~4차시 (p.56) — 교 20~25쪽, 지도서 68~73쪽, 2시간
- **학습 목표**: "운영체제의 개념과 역할을 이해하고, 운영체제의 기능을 분석할 수 있다." / "운영체제가 컴퓨팅 시스템을 효율적으로 활용하기 위해 수행하는 작업을 설명할 수 있다."
- 수업 형태: 협동 학습, 문제 기반 학습, 탐구 학습 / 준비물: 교과서, 노트와 필기도구, 컴퓨터, 스마트폰
- **도입**: 전시 학습 확인[컴퓨팅 시스템의 동작 원리] → 새싹 틔우기로 다양한 운영체제의 존재 인식 → 각자 쓰는 데스크톱·스마트폰의 운영체제 알아보기. 유의점: 데스크톱과 스마트폰 OS의 유사점·차이점 인식.
- **전개**
  - ➊ 운영체제의 정의와 필요성: 대표적 시스템 SW로 HW와 응용 SW 간 상호 작용을 돕는다는 개념, 시스템마다 역할에 최적화된 OS가 있음, 기본 역할과 필요성 숙지.
  - ➋ 운영체제의 기능 이해: 사용자 인터페이스, 프로세스 관리, 주기억 장치 관리, 입출력 장치 관리, 파일 관리 영역별 설명. (활동으로 쑥쑥 2) 데스크톱과 모바일에서 해당 기능의 차이점·공통점 구분 지도.
  - ➌ 내가 사용하는 운영체제 분석: 본인 OS에서 어떤 기능을 쓰는지 모둠별 조사.
  - 유의점: 학생이 경험한 시스템 기준으로 설명 후 다른 OS 특징 소개 / 평소 OS에서 문제가 발생했을 때 어떤 기능과 연관되는지 토의.
- **정리**: 모둠별 조사 기능 발표·공통 부분 정리, 차시 예고. 유의점: 학생 경험 중 다양한 기능 사례를 영역별로 나눠 찾게 함.
- 소단원 지도상의 유의점(p.68): OS가 시스템 SW로서 HW·SW를 상호 작용시키는 역할임을 설명하고, 시각적으로 보이는 부분 외의 다양한 기능을 이해하게 함. "※학생들은 사용자 입장에서 경험하는 운영체제의 기능과 내부적으로 이뤄지는 역할들과 그 필요성을 함께 이해할 수 있어야 한다."
- (참고) 차시 구분: 지도서는 한 장의 계획(2시간)만 제시. 3차시 = 새싹·운영체제의 이해·기능(1)~(2), 4차시 = 기능(3)~(5)·활동 2·쉬어가기·중단원 마무리로 나누는 것을 권함 (제안).

  - 리눅스(펭귄) 로고 앞: "리눅스는 대체 왜 귀여운 펭귄을 로고로 쓸까? 리누스 토르발스가 동물원에서 펭귄에게 물린 사건 때문일까?"
  - 마지막 칸: "만약 내가 운영체제를 만든다면 로고를 어떻게 만들까?" → "다양한 기능을 쌓았다는 의미로 햄버거로 해야지."
- 해설(p.68): 윈도(MS)·맥 OS(애플)·리눅스(오픈 소스)는 로고만큼 추구 가치·동작 방식이 다르지만 기본 역할·기능은 동일. "내가 만약 운영체제를 만든다면 어떤 로고를 만들 건지 상상해 보고, 어떤 가치를 담고 있는 로고인지 이야기 나누어 보도록 한다."

### 전개 — 본문 흐름과 핵심 개념
**1 운영체제의 이해 (교 20쪽, p.68)**
- 운영체제(OS) = 기기를 시작할 때 사용자와 컴퓨팅 시스템 간 상호 작용을 돕는 시스템 SW. PC: 윈도, 맥 OS, 리눅스 / 모바일: 안드로이드, iOS.
- 잠깐 "운영체제의 역할과 필요성은 무엇일까?": 응용 SW 실행을 돕고 자원을 효율적으로 관리 / 아이콘·메뉴 같은 UI 제공 / 파일 관리·네트워크 등 필수 서비스 / 사용자와 HW 사이 중개자, 드라이버와 펌웨어로 입출력 제어(펌웨어: HW에 내장되어 장치 동작을 관리하는 SW).
- 해설(p.68): 한 컴퓨터에서 여러 OS 경험 — 가상 머신 SW(VirtualBox, VMware, QEMU).

**2 운영체제의 기능 이해 (교 21~22쪽, p.69~70)**
- 대표 기능 = 사용자 인터페이스 + 자원 관리(응용 프로그램에 필요한 HW 자원 할당·회수). 자원(resource) = CPU, 메모리, 입출력 장치, 주변 장치.
- (1) 사용자 인터페이스: CLI(키보드로 명령어 직접 입력, DOS·리눅스) / GUI(마우스로 선택, 윈도·맥 OS) / NUI(사람의 행동·음성). [그림 Ⅰ-7] 데스크톱은 키보드·마우스로 GUI(겹치는 윈도 화면, 메뉴, 아이콘, 포인터), 모바일은 터치스크린 GUI(스크롤, 줌).
  - 해설 장단점(p.69): CLI 배우기 어렵지만 안정적·빠름 / GUI 직관적이지만 세세한 조작 제한 / NUI 자연스럽지만 인식률·정확도 문제.
- (2) 프로세스 관리: 여러 프로세스가 충돌 없이 실행되게, 우선순위에 맞게 CPU에 할당. [그림 Ⅰ-8] 동시에 실행 중인 여러 프로그램(앱).
  - 해설(p.69): 생성·종료·일시 정지, 교착 상태 방지를 위한 CPU 스케줄링, 메모리 공정 배분. 스케줄링 표 — FIFO(먼저 요청 먼저), 우선순위, 라운드로빈(짧게 분할해 번갈아), SJF(가장 짧은 작업 먼저).
  - 해설 "사용자를 위한 프로세스 관리 도구": 윈도 작업 관리자, 맥 OS 활동 모니터, 리눅스 top → 자원을 많이 쓰는 프로그램, 비정상 프로세스 원인 파악. (작업 관리자 실행 화면)
- (3) 주기억 장치 관리: 한정된 용량에 여러 프로그램을 효율적으로 할당, 보조 기억 장치의 프로그램을 언제 어디에 배치할지 결정. [그림 Ⅰ-9] RAM 용량 예.
  - 보조단 QnA: "내 컴퓨터에서 어떤 프로세스가 주기억 장치(메모리)를 얼마나 쓰고 있을까요? 각 운영체제에서 프로세스와 메모리의 사용 내용을 확인할 수 있는 프로그램을 실행해 보세요." → 윈도: 작업 관리자, 맥 OS: 활성 상태 보기.
  - 해설(p.70): 메모리 할당, 메모리 보호(서로의 메모리 접근 금지), 가상 메모리(부족 시 하드 디스크 일부를 메모리처럼).
- (4) 입출력 장치 관리: 연결된 입출력 장치 제어·관리, 입출력 제어. [그림 Ⅰ-10]. 해설: 장치별 드라이버로 관리, 데스크톱은 다양한 주변 장치 지원 / 모바일은 내장 장치 최적화.
- (5) 파일 관리: 파일 시스템으로 생성·변경·삭제·공유·보안. [그림 Ⅰ-11] 말풍선 "디렉터리(폴더)에 파일을 분류 및 보관하여 사용자가 파일을 쉽게 유지 및 관리할 수 있어요." 해설: 데스크톱은 외장 기억 장치 추가 쉬움, 모바일은 내장 메모리·클라우드.
- 보조단 "보안의 중요성": 비밀번호 등 개인 정보 보호, 업데이트, 백업 / 모바일 앱별 카메라·파일 접근 권한 제어.
- 지식 플러스 "운영체제로 컴퓨터 성능 관리하기"(p.70): 불필요한 프로세스 종료·시작 프로그램 관리 / 디스크 정리·조각 모음 / OS 업데이트 / 모바일 백그라운드 앱 관리·캐시 삭제 / 악성 SW 검사·보안 업데이트 즉시 / 시스템 복구 방법·백업 생활화.

### 활동
#### 활동으로 쑥쑥 2 "운영체제의 기능 분석하기" (교 23쪽, p.71) — 조사·비교 분석·토론, 모둠
- **지도 목표**: 운영체제의 역할을 사례로 이해하고 데스크톱·모바일 OS 기능을 분석해 공통점·차이점 설명 / 운영체제 관련 문제 상황을 분석하고 기능을 활용해 해결 방안 제시.
- **단계 1** "데스크톱 컴퓨터와 모바일 기기에서 사용하는 운영체제의 비슷한 점과 다른 점을 찾아보자." — 표 [비교 분석 | 비슷한 점 | 다른 점] × [데스크톱 / 모바일].
  - 예시: 비슷한 점 — GUI가 있다, 다양한 앱 설치·삭제, 파일 저장·삭제, 통신 기능으로 인터넷. 다른 점 — 데스크톱: 마우스·키보드로 GUI, 여러 앱 동시 실행 편리 / 모바일: 터치스크린으로 손으로 GUI, 주로 1~2개 앱 실행·조작.
- **단계 2** "운영체제를 사용하면서 발생한 문제를 조사하고, 운영체제의 어떤 기능과 관련이 있는지 토론해 보자." — 표 [문제점 | 운영체제의 기능] 3행.
  - 예시: 프로그램 실행 속도가 느려짐 → 프로세스·메모리 관리(사용량 많으면 느려짐) / 용도를 모르는 파일이 삭제되지 않음 → 파일 관리(중요한 시스템 파일은 아무나 삭제 불가) / 새 무선 헤드셋에서 음악이 안 들림 → 입출력 장치 관리(드라이버 설치, 블루투스 통신 장치 켜졌는지 확인).
- **지도상의 유의점**: 조사·토론에서 적극적 의견 교환과 협업으로 결론 도출 / OS 기능을 바탕으로 실질적 해결 방안 모색.
- **활동 평가 항목**: "운영체제의 개념을 이해하고 간단하게 설명할 수 있는가?" / "운영체제를 구성하는 시스템 소프트웨어와 응용 소프트웨어의 특징과 종류를 설명할 수 있는가?" / "운영체제의 주요 기능을 설명할 수 있는가?"
- 평가 도구: 수행 평가 활동지 p.98~99, 시험 대비 p.104~107.

### 형성 평가 · 핵심 개념 정리하기 (p.71)
- 형성 평가 1 (빈칸): 기기를 시작할 때 사용자와 시스템 간 상호 작용을 돕는 시스템 SW, 예: 윈도·맥 OS·리눅스 → **운영체제**.
- 형성 평가 2 (빈칸): 운영체제는 실행 중인 여러 (**프로세스**)가 충돌 없이 실행되도록 관리.
- 핵심 개념: OS 정의 / 기능 = UI 기능 + 자원 관리 기능(프로세스, 주기억 장치, 입출력 장치, 파일 관리).

### 활동지 제작 아이디어 (제안)
1. **나만의 OS 로고 디자인**: 새싹 만화의 로고 추측 발문 → 내 OS의 이름·로고·담은 가치 그리기 → OS의 역할 4가지 중 내 OS가 가장 잘할 것 체크.
2. **작업 관리자 탐험 실습지**: 작업 관리자/활성 상태 보기 실행 → 메모리 사용 상위 3개 프로세스 기록 → 브라우저 탭 10개 연 뒤 변화 비교 → "주기억 장치 관리"와 연결해 해석.
3. **OS 119 상담소**: 증상 카드(느려짐, 파일 삭제 안 됨, 헤드셋 무음, 업데이트 알림 끔, 프로그램 멈춤)를 기능 6종(UI/프로세스/주기억/입출력/파일/보안)으로 분류하고 처방 쓰기 — 수행 평가 활동지 03과 연계.
4. **스케줄링 줄서기 놀이**: 학생 4명이 작업 시간 카드를 들고 FIFO·SJF·라운드로빈 순서대로 "CPU 책상"을 이용 → 평균 대기 시간 비교 (확장 활동).

  - [구성 요소] 7개: 입력 장치, 응용 소프트웨어, 운영체제, 드라이버, 출력 장치, 그래픽 처리 장치, 통신 장치.
  - 정답 요지: 지도서에 고정 정답 없음 — "학생들이 [상황]을 어떻게 분석하는지에 따라 학생마다 각 [상황]에 연결되는 [컴퓨팅 시스템 구성 요소]가 모두 다를 수 있다." 예상 연결(제안): 프린터→드라이버·출력 장치·운영체제 / 친구 스마트폰→운영체제(UI)·응용 SW / 아버지 컴퓨터→그래픽 처리 장치 / 화상 통화→입력(카메라·마이크)·출력·통신·응용 SW / 손동작→입력 장치(터치스크린)·운영체제(NUI·GUI).
- 지도 목표: 각 구성 요소 설명 / 상황과 시스템의 관련을 논리적으로 설명. 유의점: 구성 요소의 역할을 생각하게 함, 분석 상황에 따라 답이 다를 수 있음, 다양한 의견 존중·창의적 접근 장려.
- 성취 수준 A~E는 위 "성취기준과 학습 목표" 참조. (p.73)

## 쉬어가기 · 진로 디자인 궁금해요! · 창의·융합 프로젝트
### 쉬어가기 "운영체제(OS)는 왜 다양할까?" (교 24쪽, p.72)
- 삽화: 원탁에 앉아 서로의 특징을 이야기하는 다양한 운영체제(의인화).
  - 윈도: "개인용 데스크톱 컴퓨터에서 가장 많이 사용해요." "다양한 소프트웨어와 게임을 지원해요."
  - 맥 OS: "아름다운 디자인과 직관적인 사용자 인터페이스가 있어서 창작자들이 많이 사용해요." "애플에서 만든 데스크톱 운영체제예요."
  - 리눅스: "오픈 소스로 발전한 자유로운 운영체제예요." "컴퓨팅 시스템을 더 깊이 이해하고 있는 고급 사용자(파워 유저)들이 많이 사용해요."
  - 안드로이드: "리눅스를 기반으로 구글에서 만든 모바일 운영체제예요. 사용자의 필요에 따라 다양한 모습으로 맞춤화하기 좋아요." "여러 기업에서 만든 스마트폰에서 동작해요."
  - iOS: "맥 OS처럼 애플에서 만든 모바일 기기에서 동작해요." "오늘날 널리 사용되는 터치스크린 기반 스마트폰의 표준을 제시했어요."
- 오픈 소스: 누구나 소스 코드를 읽고 수정·공유할 수 있는 방식.
- 지도서 해설(p.72): 윈도(호환성 뛰어남·비즈니스·게임, 보안 문제로 잦은 업데이트) / 맥 OS(일관 인터페이스·멀티미디어 성능, HW·OS 통합으로 안정성·보안성, HW 선택 제한) / 리눅스(비용 효율·배포판 맞춤 설정·서버, 학습 필요·호환성 제한) / 안드로이드(다양한 기기·맞춤형, 기기마다 경험 상이·구형 업데이트 지연) / iOS(일관된 경험·엄격한 앱 관리로 보안·안정, 커스터마이징 폭 좁음) / 로봇 OS ROS(모듈식 설계, 센서 데이터 수집·경로 계획·SLAM; 자율주행차·드론·가정용 로봇). SLAM = 로봇이 미지 환경을 탐색하며 스스로 위치 인식 + 지도 구축.

## 오개념 · 지도 유의점 모음
- "하늘의 구름도 컴퓨팅 시스템?" — 클라우드 컴퓨팅은 인터넷으로 자원을 제공하는 기술임을 바로잡음. (p.62)
- 모니터·스피커를 입력 장치로 혼동(형성 평가 2). 터치스크린은 입력+출력 동시. (p.64, p.67)
- 블루투스를 출력 장치로 혼동 → 통신 장치. 마우스는 입력 장치. (대단원 마무리 02, p.90)
- CPU가 데이터를 영구 저장한다는 오개념 → 저장은 기억 장치. RAM은 휘발성. (p.65, p.93)
- 응용 SW = OS라는 혼동 → OS는 시스템 SW. 드라이버도 시스템 SW. (p.64, p.93)
- CPU는 OS가 정기적으로 "개선"할 수 있는 대상이 아님(HW 사양 고정). (p.90)
- NUI(음성 인식)는 모든 OS 공통 기능이 아님. (p.105)
- 데스크톱/모바일 HW 차이: 모바일은 통합되어 교체 어려움. (p.64)
- 시스템 SW 설명 시 운영체제를 미리 소개해 02로 연결. (p.54)
- 체험한 시스템(데스크톱·스마트폰·키오스크) → 다른 시스템으로 확장하는 순서. (p.55)
- 중단원 마무리 선 잇기는 정답이 하나가 아님. (p.73)
