### 활동으로 마무리하기 (교 237쪽, p.403)
- 지시문(원문): "다음 글을 읽고, 인공지능 로봇이 사람과 협업하여 개인과 사회에 어떤 영향을 미칠 것인지 작성해 보자."
- 제시글 요지: 로봇이 사람의 일을 대신하는 경우가 늘어 제조업에서는 로봇 비중이 더 높음, 서비스 로봇·의료 서비스 로봇(수술실 소독, 침구 교체)·가정용 로봇이 일상으로 들어옴, 앞으로 일상의 반복 작업 대부분을 로봇이 수행할 것으로 예측.
- 예시 답안 5가지(p.403):
  1. 효율 — 청소·요리 보조, 공장의 반복·세밀 조립, 건설 현장 지원으로 더 빠르고 효율적
  2. 위험한 일 대체 — 소방관과 화재 진압·구조, 수술 보조·정확한 진단 지원; 단 안전과 윤리적 문제 항상 고려
  3. 노동 시장 재구성 — 일부 일자리 감소와 새 직업 생성, 생산성·경제 성장·국가 경쟁력 강화
  4. 부정적 측면 — 사회적 고립감·윤리적 논란, 의료·돌봄 로봇이 인간적 접촉을 줄여 정서적 만족도 저하 위험
  5. 개인의 과제 — 새로운 기술 학습, 교육과 평생 학습의 중요성

## 쏙쏙 요약 정리
> 원문은 빈칸 없이 완성된 요약문 형태다. 아래 **굵게**는 같은 쪽의 똑똑 형성 평가 빈칸 정답 낱말이다. (p.404, p.406)

### 01 디지털 사회와 직업 (p.404)
- **디지털 사회**: 인터넷, 컴퓨터·스마트폰 같은 컴퓨팅 시스템, 데이터 등 디지털 기술이 사회 모든 영역에 깊숙이 통합된 것 / 통합된 디지털 환경에서는 정보의 **접근**과 **공유**가 실시간 → 사회 전반의 변화.
- **디지털 기술**: 컴퓨터·인터넷·모바일 기기·SW 같은 기술로 데이터를 디지털 형태로 생성·처리·저장·전송, 디지털 사회의 핵심 역할 / **자율주행 자동차**(센서 데이터 분석·처리로 스스로 주행) / 맞춤형 추천(개인 활동 데이터 → 맞춤형 서비스) / 일상의 디지털화(사물에 센서·네트워크 → 스마트 홈).
- 디지털 사회의 특성: **네트워크** 기반 실시간 접근·공유 / AI 활용 / 소셜 네트워크로 협업 다양화·일하는 방식 변화 / **디지털 경제**가 새 직업·시장 창출 / VR·AR·MR / IoT 기기 / **데이터** 분석으로 유용한 정보 도출·사회 문제 해결 / 개인 정보 보호·안전 관심 증가 / 디지털 윤리·도덕적 책임감 강조.
- 디지털 사회의 변화 모습: **사물 인터넷, 클라우드 컴퓨팅, 빅데이터** 등의 영향으로 변화 가속 / AI로 학습자 맞춤형 교육·개별화 서비스 / 끊임없이 변하며 새 기술 계속 등장 / 적극 대응·수용으로 가치 창출.
- 직업의 변화 모습(현재 → 미래): 소프트웨어 개발자(오픈 소스 협력·AI 도구) / 요리사(로봇 조리사·자동화 → 창의적 요리·고객 서비스) / 운동선수(데이터 분석 전략) / 경찰관(CCTV·빅데이터·예측 분석).
- 디지털 사회의 직업: 새 직업이 생기고 기존 직업의 역할은 강화 / 빅데이터와 보안 분야는 더 전문화·세분화.

### 02 디지털 시민과 윤리 (p.406)
- **디지털 윤리**: 감정 조절·타인 존중·배려로 긍정적 사회관계를 형성하는 기본 소양 / 건강한 디지털 생활 실천 자세.
- AI 윤리 기준 3대 기본 원칙('인간성' 구현): ① **인간의 존엄성 원칙**(생명·정신적·신체적 건강에 해가 되지 않는 범위) ② 사회의 공공선 원칙(사회적 약자·취약 계층의 접근성 보장) ③ 기술의 합목적성 원칙(인류의 삶에 필요한 도구라는 목적·의도에 부합, 과정도 윤리적).
- **사이버 폭력**(언어·영상 등으로 피해·불쾌감) 유형: 사이버 명예 훼손 / **사이버 스토킹** / 사이버 갈취 및 강요 / 신상 정보 유출 및 폭로 / 사이버 언어 폭력 / 사이버 따돌림 (정의는 ch11 표와 동일).

## 원문 오류 의심
- p.407 똑똑 형성 평가 02 O/X 3번: "사회의 공공선 원칙은 인공지능은 인간의 생명은 물론 정신적 및 신체적 건강에 해가 되지 않는 범위에서…"에 정답 (O) 표기 — 이 정의는 인간의 존엄성 원칙이고, 바로 아래 해설도 공공선 정의를 따로 제시하므로 정답은 X여야 함.
- p.407 빈칸 8번·p.406 요약 "인적 사항, 재산적 정보 사회적 정보" — 쉼표 누락(경미).
- p.402 대단원 마무리 06 보기 ㉢ 해설 부재 — 정답 ②의 근거(㉢이 '영리 가능'이라 틀림)가 해설 문장에서 직접 언급되지 않음(경미).
- p.401 창의·융합 프로젝트 "나만의 평가 점검표 … Link 238쪽" — 교과서 238쪽은 이 대단원 범위(234~237) 밖 부록으로 지도서에 해당 쪽이 없음(확인 불가).
- p.414 02-02 해설 "SNS에서의 영향력은 … 사회적 약자의 영향력과는 무관하다" — 교과서 교 206쪽은 'SNS로 개인이 목소리를 낼 수 있게 되었다'고 하므로 '무관'은 다소 단정적 서술.
- p.416 출처 목록 "385쪽: 공개 범위 설정(instagram)" — 실제 SNS 공개 범위 설정 활동은 p.389(교 223쪽)에 있음.
- p.376·p.386·p.396 수행 평가 안내 쪽(408 / 409~410 / 411)과 실제 활동지 배치는 일치함(오류 아님, 확인 기록).
