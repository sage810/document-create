### 활동으로 마무리하기 (교 197쪽, p.341)
- 지시문: "다음 물음에 답해 보자."
  1. "인공지능 소프트웨어가 활용되는 실제 사례를 한 가지 들고, 어떤 인공지능 특성이 있는지 작성해 보자." (서술 칸 1개)
     - 예시 답안(인공지능 특성 찾기): 자율주행 자동차 — 주변 환경을 실시간 분석하고 도로 상황·보행자·장애물을 인식해 안전한 경로를 예측·결정. 학습과 추론 특성으로 데이터를 바탕으로 최적 판단, 자율 운행.
  2. "일상생활 속 문제를 한 가지 찾아보고, 그 문제를 해결하기 위한 인공지능 시스템 만들기 과정을 구체적으로 서술해 보자." (서술 칸 1개)
     - 예시 답안(일상생활 속 문제 인공지능 시스템으로 해결하기): 도심 교통 소음 문제 → 교통 소음을 감지·분류하고 기준 초과 시 경고하는 시스템.
       ① 문제 정의하기: 교통 소음을 효과적으로 감지·분류하는 시스템 만들기
       ② 데이터 준비하기: 도로·공사 현장·기차역 등에서 녹음한 소리를 교통 소음·자연 소음·기타 소음 등으로 분류·정리
       ③ 인공지능 모델 만들기: 자동차·기차·공사 소리 등을 클래스로 하는 소리 분류 모델 학습 후 실제 데이터로 정확도 테스트
       ④ 모델 사용하기: 실제 환경에서 소음 감지·분석, 기준 초과 시 경고와 원인 정보 제공
       ⑤ 문제 해결하기: 도심 교통 소음 관리, 주민 삶의 질 개선, 소음 저감 정책 수립 지원
- **나의 학습 성장 일기**:
  1. "이 단원을 배우면서 가장 흥미로웠던 점이나 느낀 점을 적어 보고, 배운 내용을 생활 속에 어떻게 활용할 수 있을지 생각해 보자." — 지도서 권장 발문: "배운 내용 중에서 새롭게 알게 된 것이나 흥미로웠던 점, 재미있었던 점을 생각해 보자." / "실생활의 사례와 연결할 수 있는 부분이 있었는지 생각해 보자."
  2. "이 단원을 배우고 나서 어떤 교과 역량이 향상되었는지 체크해 보자." — 체크 상자 9개: 컴퓨팅 사고력(추상화 능력, 자동화 능력, 창의·융합 능력) / 디지털 문화 소양(디지털 의사 소통·협업 능력, 디지털 윤리의식, 디지털 기술 활용 능력) / 인공지능 소양(인공지능 문제 해결력, 데이터 문해력, 인공지능 윤리의식). (p.341)

#### 단계와 지시문
- **단계 1 문제 정의하기** — 예: SDG 15번 '육상 생태계 보전' 관련 문제를 선택해 우리나라 멸종 위기 동물의 울음소리를 식별하는 시스템 구성. 국립생태원에 따르면 우리나라 멸종 위기 포유류는 호랑이, 늑대, 여우, 산양, 수달 등 20종 → 그중 호랑이·늑대·여우 세 종의 울음소리를 식별해 알려 주는 시스템. (교 192쪽)
  - 지식 플러스 "우리나라의 멸종 위기종은?": 국립생태원 홈페이지 '멸종위기 야생생물' → '멸종위기종 검색', 자료실 '이달의 멸종 위기종'(출처 https://www.nie.re.kr/). (p.337)
- **단계 2 데이터 준비하기** (교 193쪽)
  1. "인터넷 검색 등으로 멸종 위기 동물 중 호랑이, 늑대, 여우의 울음소리 데이터를 수집한다." (그림: 호랑이 울음소리 '어흥' → 클래스)
  2. "동물 울음소리를 분류하는 인공지능 모델을 만들기 위해 내려받은 각 동물의 울음소리 데이터들을 각 폴더에 담아 놓는다. 이때 폴더에 담긴 데이터는 소리 분류 모델이 학습할 학습 데이터이다." (호랑이/늑대/여우 울음소리 폴더 = 학습 데이터)
  3. "생성한 소리 분류 모델을 테스트할 테스트 데이터도 동물별로 준비하도록 한다."
  - 추가 발문: "소리 분류 모델을 만들기 위해 또 어떤 종류의 소리 데이터를 수집할 수 있는지 찾아보자."
  - 보조단 "동물의 소리 데이터 수집 방법": 방법 1 — 검색창에 'animal sounds download' 같은 검색어 입력 / 방법 2 — FindSounds(https://www.findsounds.com/), Pixabay-음향 효과(https://pixabay.com/ko/sound-effects/search/) 등에서 무료로 내려받기. 말풍선: "소리 데이터의 크기가 클 경우에는 다음 단계의 학습 모델 생성 시 시간이 오래 걸릴 수 있어요."
  - 지도서 보충: 다양한 출처의 양질 데이터 수집, 학습 데이터와 테스트 데이터로 나누기 지도. 데이터 수집은 구체적 지침보다 학생 스스로 계획·실행하도록 격려하고 출처·신뢰성 평가 조언. 클래스별(카테고리별) 정확한 분류가 중요(예: 개·고양이·새). 자연의 소리·교통 소음 등 일상 소리는 환경 보호·교통 관리·감정 인식에 활용 가능. (p.337)
- **단계 3 (소리 분류) 인공지능 모델 만들기** (교 194쪽, 화면 라벨 ㄱ~ㄹ)
  1. "엔트리 사이트에 접속한 후 [블록]-[인공지능]에서 학습할 모델 선택하기 중 '분류: 소리'를 선택한다." (소리 분류 모델 선택하기)
  2. "'데이터 입력' 부분에 3개의 클래스를 추가한 후 각 클래스명을 '호랑이', '늑대', '여우'로 변경한다." (ㄴ '+ 클래스 추가하기'로 총 3개 클래스명 정하고 소리 데이터(학습 데이터) 입력)
  3. "각 클래스에 해당하는 소리 데이터를 전 단계에서 준비한 폴더(학습 데이터)에서 선택하여 업로드한다."
  4. "[모델 학습하기]를 실행하면 소리 분류 모델이 데이터를 학습함으로써 학습 모델이 생성된다." (ㄷ)
  5. "생성된 소리 분류 모델이 소리를 잘 분류하는지 테스트해 보기 위해서는 '결과'에서 전 단계에서 준비한 테스트 데이터를 업로드하고 분류 결과가 잘 되었는지 확인한다." (ㄹ 테스트할 새로운 데이터(테스트 데이터)를 입력하여 결과 살펴보기) / ㄱ 모델 이름 정하기
  - 지도서 단계 해설: ① 모델 선택(무엇을 분류할지 명확히) ② 데이터 입력(클래스명별로 잘 나눠 업로드해야 정확히 학습) ③ 모델 학습하기 ④ 모델 테스트 — 테스트 데이터는 학습 데이터와 달라야 하며 이를 통해 **일반화 능력**을 평가, 테스트 데이터의 필요성과 활용 방법 강조. (p.338)
  - 지식 플러스 "머신러닝과 딥러닝": 머신러닝(기계학습) = 데이터를 학습해 스스로 결정(개·고양이 사진 구별 예). 딥러닝(심층 학습) = 머신러닝의 한 분야, 인간 뇌를 모방한 여러 층의 '인공 신경망'으로 음성 인식·이미지 분류·자율주행 등 복잡한 작업. (p.338)
- **단계 4 모델 사용하기** (교 195쪽) — "생성한 소리 분류 모델을 이용하여 울음소리 데이터를 통해 동물의 종류를 분류하여 알려 주는 코드를 작성해 보자." [오브젝트 추가하기] 기능으로 '소놀 AI로봇', '호랑이', '늑대', '여우' 오브젝트 추가. 코드 구조(그림 확인):
  ```
  [소놀 AI로봇]
  ```

## 쏙쏙 요약 정리
### 쏙쏙 요약 정리 01 — 인공지능과 데이터 (p.342)
(빈칸이 아닌 개조식 요약. 핵심 낱말을 **굵게** 표시)
- 인공지능의 개념: **인공지능(AI: Artificial Intelligence)** = 인간의 지적 능력을 모방해 소프트웨어로 만드는 것 / 특히 **학습 능력**을 많이 활용 / **인공지능 모델** = 데이터를 학습해 만든 모델로 분류·예측 등 수행.
- 인공지능의 특성: 일반 소프트웨어와 다른 **학습**(패턴 인식→성능 향상), **추론**(기존 지식으로 새 상황 결론·예측·문제 해결), **인식**(입력 데이터 해석→환경 이해→판단·행동 결정).
- 인공지능 시스템의 구성 원리와 문제 해결: **인공지능 시스템** = 인공지능 소프트웨어로 사용자의 요구·목적을 달성해 주는 컴퓨팅 시스템 / 모델·응용 소프트웨어·외부 시스템·클라우드·하드웨어·센서로 구성 / 학습된 모델은 인간 개입 없이 지능적으로 문제 해결.
- 인공지능 시스템의 문제 해결 사례: **예측, 분류**(주가·집값·질병 예측, 멸종 위기 동물 분류) / **군집(그룹화)**(상품·영화 추천, 고객 세분화) / **인식, 이해**(이미지·음성 인식, 자연어 채팅, 번역, 자율주행 인식) / **생성**(채팅, 연습 문제 생성, 문서 요약, 이미지 생성).
- 인공지능과 학습 데이터: 데이터 기반 학습이므로 데이터가 매우 중요 / **품질과 양**이 중요 / 잘못된 정보·오류, 대표성 부족으로 **편향**된 불량 데이터나 양이 적은 데이터는 성능 저하·부정확한 판단 초래.
- 학습 데이터의 수집 및 분류: **학습 데이터** = 학습을 위해 입력하는 데이터 / 유형 **수치·이미지·소리·텍스트** / 목적에 맞게 수집·분류 / 수집 방법: 직접 수집, 인터넷 검색, 공공 기관·기업의 공개 데이터.
- 학습 데이터의 준비: 수치 — 꼭 필요한 속성만, 불필요·중복은 **전처리**로 제외 / 이미지 — 대상이 명확히 드러나게 / 소리 — 또렷하고 잡음 적게 / 텍스트 — 목적에 맞게 충분히 / 개인 정보·사회 질서 위해 내용은 사전에 제거(윤리).

### 쏙쏙 요약 정리 02 — 인공지능과 문제 해결 (p.344)

  | 장점 | 유출 위험 감소, 합법적 처리 확산 | 우려 완화, 이해·신뢰 촉진 | 책임감 있는 개발·사용 장려 |

### 활동지 04 "나의 데이터는 안전할까?" (p.351)
- 연계: 단원명 인공지능의 윤리적 문제, 교과서 184~187쪽 (활동으로 쑥쑥 5 연계, ★수행 평가 연계)

- **1 "윗글에서 알 수 있는 윤리적인 문제는 무엇인지 작성해 보자."** (칸 1개) — 예시: 사용자들이 대화 데이터의 학습 활용 사실을 몰랐고 명확한 동의 절차가 없었음, 익명화 데이터라도 역추적으로 개인 정보 노출 위험.
- **2 "이 문제를 해결하기 위한 법적·사회적·윤리적 해결 방안을 모둠원과 토의하여 작성해 보자."** — 표 머리 3칸(법적 해결 방안 | 사회적 해결 방안 | 윤리적 해결 방안), 빈칸 3개
  - 예시: 법적 — 데이터 활용 시 사용자의 명확한 동의를 의무화하는 법률 제정 / 사회적 — 투명성을 높이기 위해 데이터 사용 내역을 사용자와 공유 / 윤리적 — 개발자는 수집·활용 시 항상 사용자의 권리를 최우선으로 고려.
- **평가 기준** (평가 요소: "인공지능 학습 데이터의 수집과 활용 과정에서 발생하는 윤리적 문제를 이해하고, 법적·사회적·윤리적 해결 방안을 구상할 수 있다.")

## 원문 오류 의심
- p.347 수행 평가 활동지 01의 두 번째 항목 제목이 "2 학습 데이터로 이미지 데이터 사용하기"로 인쇄됨 — 내용은 텍스트 데이터이므로 "텍스트 데이터 사용하기"의 오기.
- p.348 수행 평가 활동지 02의 단계 순서가 "[단계 4] 문제 해결하기 / [단계 5] 모델 사용하기"로 인쇄되어 교과서(단계 4 모델 사용하기 → 단계 5 문제 해결하기)와 반대. 또 단계 4 설명 "이상의 단계에 따라 문제를 해결한다"와 단계 5 설명도 서로 바뀌어 있음.
- p.353 수행 평가 활동지 05의 [단계 5] 예시 답안이 "분실물 접수 결과를 안내하는 인공지능 시스템…"으로 활동지 03 문장이 잘못 복사됨.
- p.356 시험 대비 02 06번 선택지 ⑤ "ㄴ, ㄱ, ㅁ, ㄷ, ㄴ"에서 ㄴ이 중복되고 ㄹ이 빠짐(오답 선택지라 정답에는 영향 없음).
- p.354 시험 대비 01 06번: 발문 상황이 "질환 여부를 판단 및 예상"이라 '예측'(①)도 그럴듯하며, 교과서는 '예측, 분류'를 한 과업으로 묶어 "안구 이미지로 질환을 예측"하는 사례를 듦(교 163쪽). 정답 ②(분류)만 인정하기에는 논란 소지.
- p.359 시험 대비 03 09번 정답 ③ "대중의 의견을 개선한다"는 표현이 부자연스러움(교과서·같은 단원 평가 01-10번은 "대중의 인식을 개선"). 해설은 "의견을 수렴하고 개선"으로 설명.
- p.344 쏙쏙 요약 정리 02 사회적 측면 "정책을 지시하고 홍보"의 '지시'는 '제시'의 오기로 보임(교 187쪽 [표 Ⅳ-3]도 동일 표현).
- p.358 시험 대비 03 01번은 문제 상자 안에 정답 연결선이 이미 그려진 채 인쇄되어 있음(지도서용 정답 표시로 보이나, 학생용 문제로 복사 시 선 제거 필요).
- p.340 대단원 마무리 06번 정답칸은 '데이터 ( )' 뒤 3칸으로 "편향성"이고, 시험 대비 03-03번은 "데이터 편향성"을 정답으로 함 — 같은 개념의 정답 표기가 다름(채점 시 둘 다 인정 필요).
