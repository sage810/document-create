### 활동으로 마무리하기 (교 43쪽, p.91)
1. "지금도 계속 발전하는 컴퓨팅 시스템은 미래에는 어떤 모습으로 등장할까? 또한 우리 삶에 어떤 변화를 가져올지 그리고 어떤 새로운 일들이 가능하게 될지 토론해 보자."
   - 지도 방안: 퍼스널 시스템 → 도시·국가 수준 시스템까지 확대해 상상 / 인터페이스 발전이 끼칠 영향 생각.
   - 예시 답안: 초소형 컴퓨터 — 안경·렌즈에 화면을 띄우거나 손목시계만으로 모든 일을 처리, 집안일·공부·일을 더 쉽고 효율적으로.
2. "일상의 물건에 피지컬 컴퓨팅 시스템이 추가되면 어떤 일이 벌어질까? 어떤 입출력 장치가 필요할지 상상해 그려 보고, 일상의 문제를 어떻게 해결할지 토론해 보자."
   - 지도 방안: 마이크로비트보다 작고 다양한 입출력 장치를 가진 시스템을 가정해 주변 사물에 적용.
   - 예시 답안: 화분이 마르면 버저 울리기 — 입력 온습도 센서 / 출력 버저 / 설정 습도 이하로 떨어지면 알람, 적절한 때 물 주기.

## 쏙쏙 요약 정리
### 01 컴퓨팅 시스템의 구성과 동작 (p.92)
- 내 주변의 컴퓨팅 시스템
  - **컴퓨팅**(computing): 수행하고자 하는 일을 컴퓨터를 이용하여 처리하는 과정
  - **컴퓨팅 시스템**: 컴퓨팅 작업을 수행하기 위한 하드웨어와 소프트웨어의 모음
  - **하드웨어**: 눈에 보이거나 만질 수 있는 물리적 전자 장치(외부 키보드·모니터, 내부 전자 장치)
  - **소프트웨어**: 하드웨어를 활용하여 특정 작업을 수행하는 프로그램의 모음
- 소프트웨어
  - **시스템 소프트웨어**: 하드웨어 제어, 응용 SW가 잘 작동하도록 환경 제공 — 예) 운영체제, 드라이버
  - **응용 소프트웨어**: 특정 목적의 다양한 작업을 돕는 SW — 예) 워드 프로세서, 그래픽 편집, 웹 브라우저, 게임
- 하드웨어
  - **입력 장치**(카메라, 마이크, 키보드, 마우스, 터치스크린) / **처리 장치**(CPU, GPU) / **기억 장치**(주기억 RAM — 임시, 보조 HDD·SSD — 전원 없어도 저장) / **출력 장치**(모니터, 터치스크린, 스피커, 프린터) / **통신 장치**(유선, 와이파이, 블루투스)
- 컴퓨팅 시스템의 동작 원리 이해
  - ① **전원 켜기 및 부팅** 작업: 시스템 점검·준비 → ② **운영체제** 실행: 하드웨어 관리 준비 → ③ **응용 프로그램** 실행 → ④ 원하는 작업 수행: 처리하여 출력 또는 저장 → ⑤ 응용 프로그램 종료 → ⑥ 컴퓨팅 시스템 종료
- 운영체제
  - **운영체제**(OS): 기기를 시작할 때 사용자와 시스템 간 상호 작용을 돕는 시스템 SW / PC: 윈도, 맥OS, 리눅스 / 모바일: 안드로이드, iOS
- 운영체제의 역할: 응용 SW 실행 지원 + 시스템 **자원** 효율적 관리 / **사용자 인터페이스**(UI) 제공 / 파일 관리·네트워크 등 필수 서비스 / HW와 사용자 사이 **중개자**, 드라이버·펌웨어로 입출력 제어
- 운영체제의 기능
  - **사용자 인터페이스**: 화면·메뉴로 상호 작용, 종류 CLI·GUI·NUI
  - **프로세스 관리**: 여러 프로세스가 충돌 없이 실행, 우선순위에 맞게 CPU 할당
  - **주기억 장치 관리**: 한정된 용량에 효율적 할당, 보조 기억 장치의 프로그램을 언제 어디에 배치할지 결정
  - **입출력 장치 관리**: 연결된 입출력 장치 제어·관리
  - **파일 관리**: 파일 시스템으로 생성, 변경, 삭제, 공유, 보안

### 02 피지컬 컴퓨팅 (p.94)
- 피지컬 컴퓨팅의 이해
  - **피지컬 컴퓨팅 시스템**: (**입력**) 센서로 외부 환경 데이터 수집 → (**처리**) 마이크로컨트롤러로 프로그램 실행 → (**출력**) 액추에이터 제어로 실제 세계에 물리적 변화(빛, 소리, 움직임)
  - 활용 분야: 3D 프린터, 드론, 사물 인터넷(IoT) / 대표 개발 환경: **아두이노**, **마이크로비트**
- 입력 장치: **센서**로 밝기(조도, 빛)·소리·입력·온도 등을 감지·측정해 처리 장치로 전달
- 출력 장치: 정보 전달 장치나 **액추에이터**로 빛·소리·움직임 출력
- 동작 원리: '입력-처리-출력' / 특정 작업을 위해 목적에 맞는 입출력 장치로 구성 / 필요한 입출력 장치를 선택하고 명령을 마이크로컨트롤러에 프로그래밍
- 처리 장치: **마이크로컨트롤러** — 센서 데이터를 처리해 결과를 출력 장치로
- **마이크로비트**: 손쉽게 물리적 장치를 만들고 프로그래밍하는 보드, 아두이노보다 쉽고 편리
- (p.94 오른쪽에는 교과서 31쪽 새싹 틔우기·마이크로비트 V2 그림이 축쇄로 재수록됨)

## 똑똑 형성 평가
### 01 컴퓨팅 시스템의 구성과 동작 (p.93)
- O, X 퀴즈
  1. 컴퓨팅은 컴퓨터를 이용하여 작업을 처리하는 과정 — O
  2. 컴퓨팅 시스템은 하드웨어만으로 이루어진다 — X (HW+SW)
  3. 소프트웨어는 하드웨어 제어·정보 처리에 사용 — O
  4. CPU는 데이터를 영구 저장하는 장치 — X (처리 장치, 저장은 기억 장치)
  5. 응용 소프트웨어는 운영체제와 같은 역할 — X (특정 작업용 프로그램)
  6. 시스템 SW의 예로 운영체제와 드라이버 — O
  7. 운영체제는 실행 중인 여러 프로세스를 효율적으로 관리 — O
  8. 파일 관리는 OS의 주요 기능(생성·변경·삭제) — O
- 빈칸 채우기
  1. 하드웨어와 (**소프트웨어**)
  2. 시스템 SW는 HW 제어 및 (**응용**) SW 작동 지원
  3. 데스크톱처럼 고성능이면서 휴대가 간편한 시스템 — 정답란 (**입력 장치**)로 인쇄됨 (원문 오류 의심: 문장은 노트북 컴퓨터 설명)
  4. CPU·GPU 등이 사용하는 것 — (**처리 장치**)
  5. 아이콘·메뉴 같은 (**사용자 인터페이스(UI)**)
  6. 컴퓨터의 (**자원**)을 관리
  7. 안드로이드와 iOS는 (**모바일 기기**)용 OS
  8. 여러 프로세스를 (**충돌**) 없이 관리
  9. 주기억·보조 기억 장치 간 데이터 (**이동**) 관리
  10. 파일 (**생성, 변경, 삭제, 공유, 보안**)

### 02 피지컬 컴퓨팅 (p.95)
- O, X 퀴즈
  1. 센서 수집→마이크로컨트롤러 처리→액추에이터로 물리적 변화 = 피지컬 컴퓨팅 — O
  2. 3D 프린터·드론·IoT에서 활용 — O
  3. 입출력 장치를 선택하지 않아도 마이크로컨트롤러가 알아서 처리 — X (선택하고 프로그래밍해야 함)
  4. 센서 데이터를 처리해 출력 장치로 보내는 장치 = 처리 장치 — O
  5. 센서로 환경 변화를 감지해 처리 장치로 전달하는 장치 = 출력 장치 — X (입력 장치)
  6. 마이크로비트는 필요한 "출력 장치"를 따로 구해 회로를 구성했던 아두이노보다 쉽다 — O (본문은 "입출력 장치")
- 빈칸 채우기: (**피지컬 컴퓨팅**) / (**입력 장치**) / (**처리 장치**) / (**출력 장치**) / (**마이크로비트**)

## 수행 평가 활동지
### 활동지 01 "내 주변의 컴퓨팅 시스템은 어떤 문제를 해결할까?" (p.96)
- 연계: 단원명 컴퓨팅 시스템의 동작 원리, 교 12~17쪽. 머리칸: 작성자 학년·반·번·이름.
- 학습 목표: "생활 속 컴퓨팅 시스템의 활용 사례를 이해하고 구성 요소를 분석할 수 있다."
- 목표 지시문: "크고 작은 컴퓨팅 시스템이 우리 주변에서 발생하는 다양한 문제를 해결해 주고 있다. 생활 속에서 발견할 수 있는 컴퓨팅 시스템의 구성 요소를 하드웨어와 소프트웨어로 나눠 분석해 보고, 어떤 문제를 해결하는지 정리해 보자."
- 칸 구조: 표 [종류 | 하드웨어 | 소프트웨어 | 해결하는 문제] × 3행
- 예시 답안
  - 반려동물 홈캠 | 카메라, 스피커, SD 메모리 카드, 와이파이, 모터 | 영상 기록 SW, 반려동물 인식 SW | 반려동물의 행동을 추적하고 기록

## 원문 오류 의심
- p.93 빈칸 채우기 3번: 문장은 "데스크톱 컴퓨터처럼 고성능을 가지면서도 휴대가 간편한 컴퓨팅 시스템"(= 노트북 컴퓨터)인데 정답이 "( 입력 장치 )"로 인쇄됨.
- p.93 빈칸 4번·p.92 요약 "처리 장치 … 등이 사용함/사용한다" — 문장 호응 어색("등이 있다"가 자연스러움).
- p.95 OX 6번 "필요한 출력 장치를 따로 구해서" — 본문(교 31쪽)은 "입출력 장치". 정답 O 처리는 수용 가능하나 표현 불일치.
- p.101 활동지 05 단계 4: 알고리즘은 "0~9까지 범위의 난수"인데 예시 MakeCode는 "1 부터 8 사이 랜덤" — 이렇게 하면 0(X)과 9(네모)가 절대 나오지 않음. 블록을 0~9로 고쳐야 함.
- p.103 활동지 06: 소문항 번호 "3-2"가 두 번 나옴(두 번째는 3-3이어야 함). p.102 지시문 "손뼉 라이트"룰"(오타 "를"), 처리 칸 "lightOn"과 코드 변수 "lightsOn" 표기 불일치.
- p.90 대단원 마무리 01 해설 "소프트웨이다" → "소프트웨어이다" 오타.
- p.104 04 해설 ㄷ "RAM은 처리 결과를 일시적으로 저장하는 단계로" — RAM은 장치이지 단계가 아님(표현 부정확).
- p.105 06 발문 "운영체제 대한" → "운영체제에 대한" 조사 누락.
- p.106 05 해설 "음성, 등을" 쉼표 오류.
- p.71·98·99 등 평가 기준 상/중/하 문장이 성취 수준 A/B/C 문장을 그대로 재사용 — 활동지 01의 평가 기준 항목("생활 속 가치를 판단")과 상 문장("활용 사례를 분석")의 초점이 다름(경미).
