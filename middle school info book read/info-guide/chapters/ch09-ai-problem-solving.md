# ch09 인공지능과 문제 해결
> 대단원: Ⅳ. 인공지능 | 지도서 p.300~303(차시별 지도 계획), p.315~335(각론) | 교과서 171~191쪽 (창의·융합 프로젝트 192~195쪽은 u4-appendix) | 성취기준: [9정04-03], [9정04-04], [9정04-05] | 차시: 10차시 (01 인공지능 시스템의 활용 2차시, 02 인공지능을 이용한 문제 해결 6차시, 03 인공지능의 윤리적 문제 2차시)

## 핵심 한 줄
- 인공지능은 개인~국가의 다양한 문제(기후·졸음운전·회의록·챗봇)를 해결하며, **문제 정의하기 → 데이터 준비하기 → 인공지능 모델 만들기 → 모델 사용하기 → 문제 해결하기** 5단계로 시스템을 만든다. 엔트리 AI 블록으로 수치 예측(모기 활동 지수, 선형 회귀)·이미지 분류(폐렴)·텍스트 분류(관심 분야) 모델을, 티처블 머신으로 이미지 분류(나비·나방) 모델을 만들고, 학습 데이터의 **편향·개인 정보·투명성·저작권** 문제를 **법적·사회적·윤리적** 측면에서 해결 방안과 장단점으로 토의한다. (p.315~333)

## 중단원 도입 — 생각의 씨앗 심기
(p.315, 교 171쪽)
- **도입 글 요지**: 인공지능 시스템은 개인·사회·국가의 다양한 문제 해결에 쓰이며, 데이터를 기반으로 만들어지므로 **편향된 데이터가 학습되지 않도록** 주의해야 함.
- **만화** (그림 확인, p.315):
  - 칸 1: 두 아이가 모기에 물려 "짜악!", "짝!" 손뼉을 치며 "모기, 잡아랏!"
  - 칸 2: 곱슬머리 아이가 팔을 긁으며("긁적") — "왜, 나만 물어! 모기의 활동성을 예측해 보겠어."
  - 칸 3: 아이가 돋보기로 모기를 관찰하고 집 안 온습도계(온도 27℃, 습도 71%)를 보며 — "데이터 수집 끝! 이제 모델을 만들 수 있어."
  - 칸 4: 다른 아이가 지적 — "너희 집만 조사하면 어떡해." (데이터 편향 문제 제기)
- **교과서 발문(원문)**: "Q 인공지능 시스템을 이용하여 해결할 수 있는 문제로는 무엇이 있을까? 그리고 인공지능이 학습하는 데이터가 편향되지 않게 하려면 어떻게 해야 할까?" (p.315, 교 171쪽)
- **지도 방안**: 모기 활동성 예측에 어떤 데이터가 필요한지 생각하게 한 뒤, 사례의 문제점(한 집만 조사)을 이야기 나눔. 모기 활동성 예측 프로그램처럼 인공지능으로 해결 가능한 문제와, 편향되지 않게 하는 방법을 생각하게 함. (p.315)
- **예시 답안**: ① 의료 진단, 금융 사기 감지, 교통 관리 등. ② 여러 출처에서 다양한 데이터를 모으고, 불공정한 요소가 없는 공정한 데이터를 사용. (p.315)
- 이 만화는 02의 '모기 활동성 예측 시스템 만들기' 실습, 03의 데이터 편향 논의를 동시에 예고하는 장치임 — 중단원 전체의 앵커로 반복 활용하면 좋음 (제안).

  - 인공지능이 학습하는 데이터가 편향된다면 어떤 일이 발생할지 이야기 나누게 하여 동기 유발.
  - 새싹 틔우기로 수집·분류한 데이터가 문제 해결에 어떻게 사용될지 생각하게 하여 동기 유발.
  - 유의점: "인공지능이 학습하는 데이터가 편향되지 않게 하려면 어떻게 해야 할지 발문하여 사고를 유도한다."
- **전개**
  - ➊ 문제 해결을 위한 인공지능 적용 사례 알아보기: 기후 변화 위기 대응, 졸음운전 문제 대응, 회의록 정리, 챗봇 개발 등 개인~국가의 활용 사례 설명.
    - (활동으로 쑥쑥 3) 인공지능 적용 사례 찾기 — 특정 문제를 해결하기 위해 개별·협동으로 다양한 사례를 조사하고, 적용된 구체적 방법을 조사 → 인공지능이 어떤 방식으로 문제 해결에 기여했는지 발표.
  - ➋ 생성형 인공지능 이해하기: 학습한 데이터와 연관된 글·그림·음성·영상 등을 생성하는 생성형 인공지능 설명 / 여러 유형의 데이터를 동시에 처리하는 멀티 모달을 사례로 설명.
  - 유의점: 친숙한 예시와 발문으로 다양한 활용 분야 이해 / 사례를 스스로 이해·발표하도록 적극적 질문과 피드백 / 어려운 용어는 간단한 실생활 사례로 설명, 직접 경험한 사례 공유 / 발표 시 서로 의견을 존중하며 토론.
- **정리**: 조사 내용을 종합하고 피드백으로 정리 / 다음 차시 예고. 유의점: 인공지능이 특정 분야에 국한되지 않고 다양한 분야에서 활용됨을 강조.

- **지도서 해설**: 기후 변화뿐 아니라 질병, 교통 혼잡, 자원 관리 등 다양한 문제가 있음. 인공지능 시스템으로 이런 문제를 어떻게 해결할 수 있는지 다양한 사례를 찾게 함. (p.316)

### 전개 — 본문 흐름과 핵심 개념
1. **문제 해결을 위한 인공지능 적용 사례** (교 172~173쪽, p.316~317)
   - 인공지능은 일상·산업·공공·교육 분야에서 활용. 본문 예: 빅데이터를 이용한 기후 변화 위기 대응, 이미지 인식 기술을 이용한 졸음운전 대응, 음성 인식 기술을 이용한 회의록 정리, 자연어 처리 기술을 이용한 챗봇 개발.
   - 보조단: "'빅데이터'는 디지털 환경에서 생성되는 아주 방대한 규모의 데이터이다."
   - 소제목 발문: "문제 해결에 인공지능이 적용된 사례를 탐색해 볼까?" (교 172쪽)
   - **사례 1 빅데이터 활용으로 기후 변화 위기 문제 대응**: 국립수산과학원이 빅데이터·인공지능 기반 '단기 수온 예측 시스템'을 구축해 예측 시간을 획기적으로 단축(그림: 동해·울릉도·독도 해역 수온 지도 2장). 지도서 보충: 해양 환경 데이터를 분석해 단기 수온 변화를 예측 → 어업·해양 생태계 보호에 정보 제공, 어민의 위험 대비, 해양 자원 관리·보존. (p.316)
   - **사례 2 이미지 인식 기술로 졸음운전 문제 대응**: 오스트리아의 한 대학 연구 팀이 딥러닝 이미지 인식으로 운전자의 하품·머리 꾸벅임·눈 깜박임을 녹화한 영상을 기반으로 졸음 정도를 파악하는 알고리즘 개발. (교통사고 예방, p.317)
   - **사례 3 음성 인식 기술을 활용한 회의록 정리**: 국내 한 인터넷 서비스 회사가 음성 인식으로 대화·회의 내용을 주제별로 나눠 핵심을 자동 요약·정리하는 서비스 제공. (업무 효율, p.317)
   - **사례 4 자연어 처리 기술을 이용한 대화 전문 인공지능 챗봇 개발**: 미국의 한 인공지능 회사가 질문·요청에 정확·신속하게 답하고, 보고서·프로그램 코드도 작성해 주는 챗봇 개발. (정보 접근성, p.317)
   - 지도서 추가 예시: 교통 분야 자율주행 자동차 — 실시간 도로 분석, 장애물·보행자 인식, 최적 경로 선택으로 교통사고 감소. (p.317)
2. **쉬어가기 "생성형 인공지능이란?"** (교 174쪽, p.318)
   - 인공지능이 만든 글·그림·음악·영상을 쉽게 접하는 시대. 생성형 인공지능(Generative AI) = 입력 데이터를 학습해 연관된 새 글·그림·음성·영상을 생성. 딥러닝으로 방대한 데이터를 학습해 새 데이터를 만듦.
   - **멀티 모달(multi modal)**: 여러 유형의 데이터를 동시에 처리. 예) 이미지를 글로 설명, 이야기를 짧은 동영상으로 제작.
   - 그림: 프롬프트 "우주에서 고양이와 농구를 하는 것" → AI 생성 이미지(출처: OpenAI).
   - 도입 질문(원문): "인공지능은 어떻게 창의적인 작품을 만들 수 있는 것일까?"
   - 지도서 보충 "생성형 인공지능의 발전과 윤리적 과제": 창작물 저작권, 데이터 편향성으로 인한 불공정 결과물, 생성 콘텐츠의 사회적 영향 고려 필요. 사례: 제이슨 앨런이 '미드저니'로 만든 '스페이스 오페라 극장'이 2022년 8월 콜로라도 주립 박람회 미술전 디지털 아트 부문에서 우승해 논란(출처: 중앙일보 https://www.joongang.co.kr/). (p.318)

  - 유의점: 각 단계로 학습 데이터 준비→모델 활용→실제 문제 해결 시스템 구성·적용 과정을 알게 함 / 실습(예측·분류) 외에 더 많은 데이터와 연구가 있어야 정교한 결과를 얻을 수 있음을 이해시킴.
- **정리**: 실생활 문제 해결 기여 강조, 목표 달성 확인 / 어려웠던 점 공유 / 정리 및 자기 평가 / 다음 차시 예고. 유의점: 자기 평가로 성취한 것과 개선할 부분 파악. (p.302)

### 동기 유발 — 새싹 틔우기
- **제목 발문(원문)**: "인공지능은 어떻게 만들어질까요?" (p.319, 교 175쪽)
- **그림 [그림 Ⅳ-8] 인공지능 시스템을 이용한 문제 해결 과정** — 5칸 만화식 흐름 (그림 확인, p.319):
  - 단계 1 문제 정의하기: TV 뉴스 "전 세계 곤충 개체 수 급감"을 보는 학생 — "일상생활에서 문제를 발견하고, 무엇을 해결해야 할지 문제를 명확하게 정의하는 단계이다."
  - 단계 2 데이터 준비하기: 책상 위 모니터(세계 지도·막대그래프)와 자료를 정리하는 학생 — "문제 해결에 필요한 데이터를 수집하고, 이 데이터를 기반으로 인공지능 학습 모델이 학습할 수 있도록 준비한다."
  - 단계 3 인공지능 모델 만들기: 학생 주위에 '이미지 분류 모델', '소리 분류 모델', '텍스트 분류 모델', '수치 예측 모델' 아이콘, 말풍선 "어떤 모델을 선택할까?" — "앞에서 준비한 데이터의 유형에 따라 적절한 인공지능 모델의 종류를 선택하고 데이터를 학습시켜 인공지능 모델을 생성한다."
  - 단계 4 모델 사용하기: 엔트리 블록 코드 화면 — "만든 모델을 문제 해결을 위한 소프트웨어나 시스템에 적용한다."
  - 단계 5 문제 해결하기: 지구 온도 상승 그림과 학생 — "단계에 따라 문제를 해결한다." 말풍선 "자연을 아끼고 사랑해야겠어!"

3. **인공지능 모델** (교 177쪽, p.321)
   - 다양한 모델로 인공지능 시스템을 구성. 학습 모델: 수치 예측, 이미지 분류, 군집 등.
   - **(1) 수치 예측 모델**: 수치 데이터를 학습·패턴 분석해 새 수치를 예측. 예) 온도·습도·풍속 등에서 기상 요소와 기온의 관계 학습 → 미래 기온 예측 / 광고비와 매출 관계 학습 → 매출 예측. [그림 Ⅳ-9] 지구의 평균 기온 편차 예측. 보조단 "접속해서 확인해요! https://www.kma.go.kr/cpd/index.html '기후 감시 예측 정보 서비스'로 지구의 기후를 알아봐요."
   - **(2) 이미지 분류 모델**: 이미지를 학습한 뒤 각 이미지의 범주를 구분. 예) 개·고양이 분류 [그림 Ⅳ-10], 엑스레이(X-ray)·자기 공명 영상(MRI) 이미지로 질병 판단.
   - **(3) 군집 모델**: 여러 데이터를 비슷한 특징 그룹으로 나눔. 예) 구매 습관이 비슷한 고객 묶기 [그림 Ⅳ-11] 고객 세분화(A·B·C 그룹), 교통 상황 분석으로 통행 패턴 찾기.
   - 지도서 보충 "그 외의 인공지능 모델": 숫자 분류(손글씨·디지털 숫자), 소리 분류, 텍스트 분류(주제·감정) 모델.

### 활동
#### 실습 "티처블 머신을 이용해 나비와 나방을 분류하는 인공지능 모델 만들기" (교 176쪽, p.320) — 문제 기반 학습
- 형태: 짝 / 도구: **티처블 머신(Teachable Machine)** 이미지 프로젝트, 웹 브라우저 / 실습 파일: 176쪽 티처블머신_나비 나방.zip(T셀파)
- **지도 목표**: "정의한 문제의 해결을 위해 나비와 나방 데이터를 수집하고 티처블 머신을 이용해 나비와 나방을 분류하는 인공지능 모델을 만들 수 있다."
- **문제 상황(지시문 원문)**: "기후 변화 위기 문제를 분석하는 과정에서 나비와 나방이 생태에 어떤 영향을 미치는지 조사하고자 한다. 나비와 나방의 이미지를 수집하여 각각을 분류하는 인공지능 모델을 만들어 보자." (화면 옆 삽화: AI 캐릭터와 '기온 상승', '곤충 감소' 생각 풍선)
- **단계(원문 + 화면 조작)**:
  1. 데이터 수집 — "인터넷 검색 엔진에서 '나비'와 '나방' 이미지들을 검색하여 충분히 내려받는다(대략 20장 정도)."
  2. 프로젝트 시작 — "티처블 머신 사이트에 접속하여 '이미지 프로젝트'를 실행한다." 링크 https://teachablemachine.withgoogle.com/ — '새 프로젝트' 화면에서 이미지 프로젝트/오디오 프로젝트/포즈 프로젝트 중 **이미지 프로젝트** 클릭.
  3-1. 클래스 설정·데이터 업로드 — "'Class 1'과 'Class 2'의 클래스명을 '나비'와 '나방'으로 각각 변경하고, 수집한 이미지들을 각 클래스에 올린다." (화면 표시: 'Class 1' 옆 연필 → '나비'로 수정, 'Class 2' → '나방'으로 수정, 각 클래스의 [업로드] 버튼으로 데이터 업로드)
  3-2. 학습 — "학습을 실행한다." (가운데 '학습' 패널의 [모델 학습시키기] 버튼 클릭)
  4. 평가·적용 — "다시 새로운 이미지 데이터를 올린 후 학습시키면 해당 이미지가 '나비'와 '나방' 중 어디에 속하는지 분류 결과를 알 수 있다." (오른쪽 '미리보기' 패널: ➊ 새로운 데이터(입력을 파일로 바꿔 새 이미지 업로드) → ➋ 분류 결과(클래스별 확률 막대))
- **단계 대응(데이터 수집–학습–평가–적용)**: 1·2 = 데이터 수집·준비 / 3-1·3-2 = 학습 / 4 = 평가(새 데이터로 확률 확인) / 적용은 모델 내보내기(활동 플러스 3단계)로 확장 가능.
- **예시 결과**: 새 나비 이미지 업로드 시 '나비' 클래스 확률 막대가 높게 표시됨(그림).
- **지도상의 유의점**: 사용법을 단계별로 설명하고 필요하면 시연 / 수집 이미지가 분류에 적합한지 사전 확인. (p.320)
- **활동 평가 항목**: "문제 해결에 적합한 데이터를 수집하여 학습 데이터로 입력하였는가?" / "인공지능 모델이 분류한 결과를 설명할 수 있는가?"
- 지식 플러스 "인공지능 모델의 예측 확률을 높이는 방법": 예측 확률이 낮은 것은 모델이 확신하지 못할 때. 원인 = 학습 부족 또는 데이터 질이 낮음 → 다양하고 충분한 학습 데이터 제공으로 확률을 높임. (그림 예: 장미 사진 입력 시 Rose/Sunflower/Tulip 확률 막대) (p.320)
- **활동 플러스 "티처블 머신 이용해 보기"**: 티처블 머신 = 머신러닝 모델을 쉽고 빠르게 만드는 웹 기반 도구, 이미지·소리·자세 인식 학습 가능. 공식 사이트 사용 방법: 1 모으기(예시를 수집해 학습할 클래스·카테고리로 그룹화) → 2 학습시키기(모델 학습 후 새 예시를 올바르게 분류하는지 즉시 테스트) → 3 내보내기(사이트·앱 등 프로젝트에 사용, 다운로드 또는 온라인 호스팅). 과제: 강아지·고양이 분류 모델 만들기. (p.320)

- **문제 상황(원문)**: "여름과 가을 사이에 출현하는 모기 탓에 불편한 용현이는 기상과 모기의 활동성이 관계가 있음을 알게 되었다. 기상 정보를 바탕으로 모기의 활동성을 예측하는 시스템을 만들기 위해서는 어떤 데이터가 필요할까? 그리고 어떤 인공지능 모델을 써야 할까?"
- **단계 1 문제 정의하기**: 서울시 모기 활동 지수와 기상 정보로 모기 활동성에 큰 영향을 주는 요인을 찾고, 그 요인으로 활동성을 예측하는 시스템을 만듦.
- **단계 2 데이터 준비하기**
  1. 엔트리 접속 → [블록]-[데이터 분석]에서 '[테이블 불러오기]-[테이블 추가하기]-[테이블 선택]' → '서울시 모기 활동 지수' 데이터 추가.
     - 데이터 정보(지도서): 2020~2022년 서울시 모기 활동 지수 + 기상 정보 통합. 일자, 평균 모기 활동 지수, 수변부 모기 활동 지수, 평균 기온, 평균 지면 온도 등 **13개 속성, 1090개 행**. 우측 하단 '자세히 보기'에 개요·활용법.
  2. 차트에서 '점 산점도' 선택 → 가로축 '평균 지면 온도', 세로축 '평균 모기 활동 지수', 계열 '구분하지 않음' → 관계가 높음을 확인("평균 지면 온도에 따른 평균 모기 활동 지수의 관련성이 높다.").
  - 보조단: 산점도 = 데이터를 점으로 찍어 두 변수 관계를 한눈에 보는 그래프. 말풍선 "평균 지면 온도 값이 상승할수록 평균 모기 활동 지수도 올라가는 것을 확인할 수 있어요." / "모기 활동성을 정확히 예측하는 것은 실제로 어려워요. 우리가 실습한 것 이외에도 훨씬 더 많은 데이터와 연구가 있어야 더 정확한 결과를 얻을 수 있음을 명심하세요." (p.322)
- **단계 3 (수치 예측) 인공지능 모델 만들기** (화면 라벨 ㄱ~ㅅ)
  1. [블록]-[인공지능]-[인공지능 모델 학습하기] → 학습할 모델 선택하기 중 **'예측: 숫자(선형 회귀)'** 선택, 작성한 테이블 연결. (ㄱ 모델 이름 정하기, ㄴ 데이터 연결하기)
  2. 핵심 속성 '평균 지면 온도', 클래스 속성(예측 속성) '평균 모기 활동 지수' 선택. (ㄷ, ㄹ)
  3. [모델 학습하기] 실행 → 좌표 평면에 점과 회귀선(추세선) 표시. (ㅁ)
  4. 결과 해석: 가로축 평균 지면 온도, 세로축 평균 모기 활동 지수, 주황색 점 = 각 데이터 분포, 파란 직선 = 분포 경향을 나타내는 회귀선. (ㅂ 결과 확인하기) → ㅅ 모델 적용하기.
  - 말풍선: "수치 예측 모델의 학습 결과에 나타난 회귀선은 새로운 수치에 대한 예측에 활용할 수 있어요."
  - 지도서 보충: 핵심 속성 = 예측 결과에 영향을 미치는 입력 데이터, 예측 속성 = 예측하려는 목표 변수. 핵심 속성 선택에 따라 정확도가 크게 달라짐(예: 주택 가격 예측의 '위치'·'면적'). 지식 플러스 "선형 회귀": 독립 변수와 종속 변수의 선형 관계를 가장 잘 나타내는 직선을 찾는 통계 방법. 특징 ① 간단·해석 쉬움 ② 관계가 선형일 때 효과적 ③ 예측·영향력 분석에 사용. 습도·강수량 등을 함께 고려하면 더 정확. (p.323)
- **단계 4 모델 사용하기** — "평균 지면 온도를 묻고 그 값에 대한 대답을 수치 예측 모델의 예측값으로 입력하여 예측 결과를 나타내는 코드를 작성한다." 대답의 예측값은 [블록]-[인공지능]의 '평균 지면온도 (대답) 의 예측 값' 블록 사용. 코드 구조(그림 확인):
  ```
  시작하기 버튼을 클릭했을 때
    "평균 지면 온도를 입력해 주세요." 을(를) 묻고 대답 기다리기
    ("예상되는 모기 활동 지수는" + (평균 지면온도 (대답) 의 예측 값) + "입니다.") 을(를) 10초 동안 말하기
    만일 <(평균 지면온도 (대답) 의 예측 값) < 25> 이라면  "모기 발생 예보 1단계 '쾌적'입니다." 10초 동안 말하기
    아니면 만일 < … < 50> 이라면  "모기 발생 예보 2단계 '관심'입니다."
      아니면 만일 < … < 75> 이라면  "모기 발생 예보 3단계 '주의'입니다."
        아니면  "모기 발생 예보 4단계 '불쾌'입니다."
  ```
  - 모기 예보 단계 표: 1단계(쾌적) 0 이상~25 미만 / 2단계(관심) 25 이상~50 미만 / 3단계(주의) 50 이상~75 미만 / 4단계(불쾌) 75 이상~100 미만.
  - 말풍선: 모델 생성 후 '모델 다시 학습하기', '모델이 학습되었는가?', '모델 보이기' 등의 블록이 나타남.
- **단계 5 문제 해결하기** — 사용자에게 시스템을 쓰게 함. 실행 예: ① 평균 지면 온도 입력(32) → ② "예상되는 모기 활동 지수는? 77.4입니다." → ③ "모기 발생 예보 4단계 '불쾌'입니다." (삽화 "드디어 모기에서 해방이다.") (p.324)
- **지도상의 유의점**: 테이블 속성 간 관계성을 고려해 핵심 속성 선택 / 단계 1~5를 따라 데이터 준비→수치 예측 모델→실제 문제 해결 과정을 알게 함. (p.322)
- **활동 평가 항목**: "데이터에서 핵심 속성을 적절히 추출하여 인공지능 모델에 효과적으로 학습시켰는가?" / "인공지능 모델을 활용하여 주어진 문제를 성공적으로 해결하였는가?"
- 지식 플러스 "엔트리의 내장 데이터 이용하기": 계절별 기온, 공유 자전거, 붓꽃, 시도별 인구, 서울시 모기 활동 지수 등 30개 이상 내장. 수정·추가·삭제, 차트, 통계, 모델 학습 데이터로 바로 사용. (p.322)
- 지식 플러스 "수치 예측 모델의 정확도": 예측값이 실제 결과와 얼마나 비슷한지. 그러나 정확도만으로 성능을 판단하면 안 됨 — 잘못되거나 편향된 데이터로 학습하면 결과가 왜곡. (p.324)
- 활동 플러스 "선형 회귀로 모기 활동 지수 예측기 만들기": 엔트리 공식 블로그의 '서울시 모기활동지수' 예측기 참고(평균 모기 활동 지수와 기온의 라인 그래프 보기, 일별 입력된 데이터 전처리하기 등 메뉴). (p.324)

#### 실습 "이미지로 폐렴 분류 시스템 만들기" (교 181~183쪽, p.325~327) — 프로젝트 기반 학습
- 형태: 개인/짝 / 도구: **캐글(kaggle)** 데이터셋 + **엔트리** [인공지능] '분류: 이미지' / 실습 파일: 181쪽 실습 이미지 분류.zip, (엔트리·데이터) 181~183쪽 실습 이미지 분류.zip, QR https://dtqr.kr/q2bRJ6a
- **지도 목표**: "이미지 데이터를 활용하여 폐렴을 분류하는 인공지능 시스템을 구성하고 적용할 수 있다."
- **문제 상황(원문)**: "주희는 병원에서 흉부 CT(Computed Tomography) 이미지로 폐렴 여부를 판단하는 의사 선생님의 모습을 보고 '인공지능을 이용해 폐렴 여부를 분류할 수 있을까?'라는 생각을 하였다. 흉부 정보를 바탕으로 폐렴 여부를 판단하는 시스템을 만들려면 어떤 데이터가 필요할까? 그리고 어떤 인공지능 모델을 사용해야 할까?"
- **단계 1 문제 정의하기**: 흉부 CT 이미지로 폐렴 환자 여부를 분류하는 시스템을 만듦.
- **단계 2 데이터 준비하기**: 인터넷 검색 등으로 폐렴·정상 흉부 엑스레이 이미지 수집 — 여기서는 캐글에서.
  1. 캐글 접속 → '데이터셋'에서 검색어 'Chest X-Ray Images'(흉부 엑스레이 이미지) 입력. 주소 https://www.kaggle.com/datasets
  2. 원하는 데이터 내려받기(첫 화면의 [내려받기] 버튼). 데이터셋 직접 주소: https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia
  3. 내려받은 데이터셋(chest_xray)은 train(학습 데이터), test(테스트 데이터), val(검증 데이터) 폴더로 구분.
  4. [train]·[test] 폴더에 각각 NORMAL(정상), PNEUMONIA(폐렴) 이미지가 들어 있음.
  - 말풍선: 캐글 내려받기는 (무료) 회원 가입·계정 연결 후 로그인 / 영어 사이트는 '웹 페이지 한국어로 번역하기' 사용 / "폐렴 진단에 관한 연구 역시 어려운 문제입니다. … 훨씬 더 많은 데이터와 연구가 있어야 폐렴 진단에 대해 더 정확한 결과를 얻을 수 있어요." 보조단: 데이터셋 = 컴퓨터에서 쓸 수 있게 저장된 데이터의 집합체.
  - 지도서 보충: **테스트 데이터** = 학습 후 성능 평가용, 학습하지 않은 새 데이터 / **검증 데이터** = 학습 중간에 모델이 특정 데이터에 지나치게 의존하지 않고 잘 학습되는지 확인·최적화. 지식 플러스: 캐글은 인공지능·데이터 과학 경진대회 플랫폼, 'pollution' 검색 시 csv·xlsx·jpg 등 다양한 유형 확인 가능. (p.325)
- **단계 3 (이미지 분류) 인공지능 모델 만들기** (화면 라벨 ㄱ~ㅂ)
  1. [블록]-[인공지능]-[인공지능 모델 학습하기] → **'분류: 이미지'** 선택 → 모델 이름 정하기. (ㄱ)
  2. '데이터 입력'에서 클래스명을 '정상'과 '폐렴'으로 바꾸고 각 클래스에 train 폴더 이미지 업로드. (ㄴ)
  3. [모델 학습하기] 실행 → 학습 모델 생성. (ㄷ)
  4. '결과'에서 test 폴더의 적당한 이미지를 업로드해 분류가 잘 되는지 확인. (ㄹ, ㅁ 테스트한 결과 예) → ㅂ 모델 적용하기.
  - 지도서 보충: 다양한 이미지 조건을 학습하도록 충분한 양 입력 / 테스트 데이터는 학습에 쓰지 않은 새 이미지. (p.326)
- **단계 4 모델 사용하기** — 코드 구조(그림 확인):
  ```
  시작하기 버튼을 클릭했을 때
    "흉부 엑스레이 이미지 데이터를 입력해 주세요." 을(를) 4초 동안 말하기
    학습한 모델로 분류하기
    만일 <분류 결과 = 폐렴> 이라면  "폐렴 소견입니다. 정밀 진단이 필요합니다." 말하기
    아니면  "폐렴으로 보이지는 않습니다. 항상 건강 관리에 힘쓰세요." 말하기
  ```
  - 말풍선: 이미지 분류 모델 생성 후 '학습한 모델로 분류하기', '비디오 화면을 학습한 모델로 분류 시작하기', '분류 결과' 등의 블록이 나타남.
- **단계 5 문제 해결하기**: 폐렴 여부를 알고자 하는 사용자가 시스템 사용. 실행 예: [데이터 입력] 창 → 업로드 → [적용하기] → 의사 캐릭터가 정상 폐 이미지면 "폐렴으로 보이진 않습니다. 항상 건강 관리에 힘쓰세요.", 폐렴 이미지면 "폐렴 소견입니다. 정밀 진단이 필요합니다." (p.327, 그림 확인)
- **지도상의 유의점**: 폐렴·정상 이미지를 폴더별로 명확히 구분했는지 확인 / 단계 1~5를 따라 이미지 분류 시스템 구성·적용 방법 이해. (p.325)
- **활동 평가 항목**: "이미지 데이터를 올바르게 분류하고, 인공지능 모델에 정확히 학습시켰는가?" / "학습된 인공지능 모델을 사용하여 폐렴 여부를 정확하게 분류하고 문제를 해결하였는가?"
- 활동 플러스 "'EDU AI'로 이미지 분류 모델 체험하기": 한국교육학술정보원 인공지능 학습 플랫폼 EDU AI(https://keris-eduai.co.kr)에서 성별·나이 이미지 분류 모델 체험. (p.326)
- 의료 진단 결과는 참고용이며 실제 진단은 의사가 한다는 점, 성별·나이 분류 체험 시 얼굴 사진 사용의 윤리 문제를 함께 짚기 (제안).

   - 인공지능은 데이터로 만들어지므로 인간·사회에 부정적 영향을 줄 수 있는 수집·분석·활용을 윤리적으로 평가해 올바르게 써야 함. 인간의 사회적 편견·선입견이 데이터에 담기고, 이를 학습한 인공지능은 인종·성별 차별 문제를 일으킴.
   - 지도서 보충 "주의할 점": 데이터가 편향되지 않게 / 다양한 출처·배경을 반영해 공정성 유지 / 민감한 개인 정보는 명확한 동의와 철저한 관리. (p.328)
   - **사례(교과서)**: 세계적 IT 기업 A사의 인공지능 채용 프로그램이 남성 지원자를 우대 — 여성보다 남성 직원 비율이 높은 회사의 직원 이력을 학습했기 때문 → A사는 프로그램 폐기. 편향 데이터 학습 → 불공정 결과. (p.329)
   - **사례(지도서 보충)** "데이터 편향 문제 사례": 해외 유명 IT 회사의 신용 카드가 동일 조건에서 남성에게 더 높은 신용 한도를 부여해 금융 당국 조사 — 알고리즘이 사회적 편견을 반영한 것으로 보임. (p.329)
   - **인공지능의 사회적 역할과 가치**: 긍정(의료·교통·환경 보호·교육·사회 서비스) vs 부정(프라이버시 침해, 고용 감소, 편향과 차별, 의사 결정의 투명성 부족). 해결: 데이터 윤리, 책임 있는 개발, 공정성 확보, 사회적 대화 + 법적 규제·표준, 지속적 교육, 사회적 협력으로 혜택을 공평하게. (p.329)
2. **인공지능 서비스의 데이터 활용 문제** (교 186쪽, p.330)
   - [표 Ⅳ-2] 생활 속 인공지능 서비스의 편리함과 윤리적인 문제:
     | 서비스 | 편리함 | 윤리적 문제 |
     |---|---|---|
     | 콘텐츠 추천 서비스의 덫 | 시청 데이터로 유사 콘텐츠 관심을 가정, 맞춤형 광고·영상 추천으로 선택 고민·시간 절약 | 사용자에게 피로감, 다양한 아이디어에 노출될 기회를 줄여 개인 성장 방해 |
     | 개인 정보를 유출하는 챗봇 | 자연어 처리로 대규모 텍스트 학습, 질문·요청에 빠른 응답·정보 제공 | 대화로 얻은 개인·민감 정보를 그대로 학습하면 개인 정보 유출 사고 |
     | 편향된 학습 데이터로 인한 차별 | 컴퓨터 비전으로 대량 이미지·영상 학습, 사진·동영상을 여행·가족·행사 등으로 자동 분류 | 학습 데이터가 편향·부족하면 특정 국가 사람 얼굴이나 성별을 잘못 인식해 부정확한 분류 |
   - 보조단: 컴퓨터 비전 = 컴퓨터가 이미지·영상을 분석·이해해 인간처럼 시각 정보를 처리하게 하는 인공지능 분야.
   - 지도서 보충: 추천 서비스는 취향 제한·무분별 수집에 따른 사생활 침해 우려, 챗봇·음성 비서는 동의 없는 수집 시 심각한 침해 + 편향 데이터로 특정 인종·성별 차별 위험 → 사용자 권리 보호 방안 필요.
   - 지식 플러스 "추천 알고리즘의 함정": 한 동영상 플랫폼의 개인화 추천으로 특정 유형 콘텐츠에 몰입 → 편향된 가치관·피로감. 한 연구에서 이용자들이 다양한 주제·의견을 접하기 어려워졌다고 밝힘, 시청 내역 삭제·로그아웃 시청으로 피하는 사람도 있음 → 알고리즘 설계·운영의 책임과 윤리적 고려 필요. (p.330)
3. **윤리적 문제의 해결 방안** (교 186~187쪽, p.330~331)
   - 학습 데이터 수집·활용의 현실적 문제에 대해 법적·사회적·윤리적으로 타당한 해결 방안 제시. 예) **얼굴 인식 시스템**: 정확도 향상·편리성·신속성으로 스마트 기기 잠금 해제·구매 결제 인증에 쓰이지만, 개인 고유 생체 데이터 기반이므로 문제 발생 가능.
   - 보조단 "얼굴 인식 시스템의 사용에서 발생할 수 있는 문제":
     - 법적: 수집·처리 중 관리 부실로 얼굴 데이터 유출 시 「개인정보보호법」 위반 가능.
     - 사회적: 법적 문제·오남용 사례 발생 시 사회적 파장과 인공지능에 대한 불신.
     - 윤리적: 개발 시 윤리적 책임 의식 부족, 사용자의 무분별한 사용으로 본 목적 저해.
   - 지도서 보충: 적절한 규제, 지속적 감시, 사용자 동의와 데이터 보호 정책 필요. (p.330)
   - [표 Ⅳ-3] 다양한 측면에서의 윤리적 해결 방안 및 장단점 (얼굴 인식 시스템 예시, 교 187쪽):
     | 관점 | 법적 측면 | 사회적 측면 | 윤리적 측면 |
     |---|---|---|---|
     | 해결 방안 | 데이터 수집과 처리의 전 과정에서 「개인정보보호법」 준수 여부를 지속적으로 확인 | 인공지능 사용과 한계에 대한 대중의 인식을 개선시키는 정책을 지시하거나 홍보 | 개발자와 사용자를 위한 인공지능 윤리 지침 제공, 윤리 교육 강화 |
     | 장점 | 데이터 유출 위험 감소, 합법적 데이터 처리 과정 확산 | 대중의 우려 완화, 이해와 신뢰감 촉진 | 책임감 있는 개발과 사용 장려 |
     | 단점 | 시스템 개발의 성능과 효율성 저하, 비용 증가 | 상당한 시간·자원 필요, 변화하는 기술 환경에서 대중 이해 불완전 | 개발자·개발사·사용자의 이해관계 충돌 |
   - 지식 플러스 "생성형 인공지능 윤리 가이드북": 2023년 12월 방송통신위원회·한국지능정보사회진흥원 공동 발간. 저작권, 개인 정보, 오남용 등 법적·사회적·윤리적 이슈와 이용 지침, 제삼자 권리 침해 가능성과 법적 책임 강조, 향후 입법·사회적 논의 필요 시사. (p.331)

4. **AI 윤리 10대 기준 매칭**: 사례 카드 ↔ 위배된 기준(프라이버시 보호, 데이터 관리, 투명성 등) 연결하기.

  4. "올바른 인공지능을 만들기 위해서는 (**윤리**)적인 측면을 고려해야 한다."

## 오개념 · 지도 유의점 모음
- "실습 결과 = 실제 예측·진단 가능" 오개념: 모기 활동성·폐렴 진단 모두 "훨씬 더 많은 데이터와 연구"가 필요함을 강조(교과서 말풍선, p.302 유의점). (p.322, p.325)
- 모델 이름 혼동: 군집 모델 ↔ 이미지 분류 모델 / 수치 예측 모델 ↔ 군집 모델 — 형성 평가에서 반복 출제. (p.327, p.345)
- 문제 해결 5단계 순서 혼동(특히 '모델 사용하기'와 '문제 해결하기'의 순서) — 수행 평가 활동지 02에도 순서가 뒤바뀐 채 인쇄되어 있어 주의. (p.327, p.348)
- 핵심 속성 vs 예측 속성 구분: 입력(평균 지면 온도) vs 목표(평균 모기 활동 지수). (p.323)
- 테스트 데이터는 학습에 쓰지 않은 새 데이터여야 함(일반화 능력 평가). train/test/val 폴더 의미 지도. (p.325, p.338)
- 엔트리 텍스트 분류: 클래스당 5개 이상, 쉼표 구분. (p.333)
- 정확도가 높아도 편향 데이터면 결과가 왜곡될 수 있음 — 정확도만으로 성능 판단 금지. (p.324)
- 클래스별 데이터 개수 불균형도 '편향'임(장미 100 : 튤립 10). (p.329)
- 윤리 토의는 한쪽 의견에 치우치지 않게 다양한 시각 소개, "AI 전면 금지" 같은 극단적 결론은 부적절(시험 대비 문항에서도 오답 처리). (p.331, p.359)
- 해결 방안마다 장점과 단점이 함께 있음(법적 규제 → 성능·효율 저하, 비용 증가)을 인식시킴. (p.331, p.357)
