### 01 데이터의 표현과 관리 (p.152)
- 디지털 데이터로 변환: **아날로그**(시간 흐름에 따라 연속적으로 변화하는 값) / **디지털**(연속 데이터를 일정 간격으로 끊어 유한 개수의 숫자로 표현) / 컴퓨터는 **0과 1**만 인식하므로 아날로그 → 디지털 변환 필요.
- 문자 데이터의 표현: **문자 코드**로 이진수로 변환해 처리하고, 출력 요청 시 다시 문자로 변환해 출력 장치로 보여 줌 / **아스키코드**: 미국표준화협회, 한 문자 **7비트** / **유니코드**: 국제 표준, **16비트(2바이트)** 기준 **65,536(2^16)**개.
- 수치·소리·동영상: 실생활 **십진수** ↔ 컴퓨터 **이진수** 변환 필요 / 소리는 **표본화, 양자화, 부호화**로 이진수 변환 / 동영상은 다중 매체 정보, **프레임**을 빠르게 보여 주면 **잔상 효과**로 움직임 인식.
- 데이터 관리–데이터 분류: 이용 목적에 따라 **그룹화**·**정렬** / 분류가 잘되면 검색·보호·저장 등 관리가 편리.
- 디지털 데이터의 특징: 검색·관리 쉽고 빠른 처리 / 대량 저장·기기 간 공유 용이 / 복제·백업, 전송 손실 최소화 / 인터넷이 되면 언제 어디서나 활용 / 분석 도구로 효과적 분석 / **실시간 업데이트**.
- 이미지 데이터의 표현: **픽셀(화소)** / **비트맵**(픽셀 단위, 다양한 색상, 사진에 적합, 해상도에 따라 품질 변화, 확대 시 **계단 현상**) / **벡터**(점·선·곡선 등 수학적 정보, 단순 그래픽·도형에 적합, 해상도 무관, 확대·축소해도 품질 유지, 파일 크기 작음).
- 데이터 수집 계획: **목적 정하기** → **종류와 형태 정하기** → **검색과 수집하기** / 수집 방법: 직접 수집, 인터넷 검색, 공공 기관·기업 공개 데이터.
- 데이터 관리–저장과 공유: 보존과 지식·정보 전달·협업·재생산에 중요 / 인터넷·SNS 발달은 저장·공유·보안 기술과 맞물려 사회·문화적 변화 → 기술의 영향을 이해하고 **책임감** 있게 사용.

### 02 데이터의 구조화와 분석 (p.154)
- 데이터 구조화: 내용 요소들을 특성에 맞게 정리·배열해 **통일된 모양**으로 표현 / 잘 된 구조화는 의미 파악·체계적 관리가 쉬움 / 과정: **데이터 파악 → 내용 요소 추출 → 내용 요소 분류 및 정리 → 구조화**.
- 데이터 분석과 활용: 문제 해결·더 나은 **의사 결정** / 숨겨진 가치로 새 지식 발견 / 활용 예: 환자 데이터(질병 원인·치료), 교육 데이터(최적 교육), 시장 분석(홍보 전략), 금융 데이터(투자 전략), 경기 데이터(선수 관리·팀 전략).
- 데이터 구조화의 종류: 먼저 종류·특징·활용 목적 파악 / **목록(리스트)**: 일정 기준에 맞춰 순서대로 나열, 관계가 복잡하면 관리가 어려움 / **표(테이블)**: 세로줄·가로줄 두 기준, 중복 요소 정리에 효율적 / **다이어그램**: 그림·도형·점·선·화살표로 상호 관계를 시각화.
- 데이터 분석하기: 필요한 데이터를 수집·분석해 답을 찾는 과정(데이터 수집 → 데이터 구조화 → 데이터 분석 → 데이터 활용) / 문제 해결 과정: **문제 정의 → 계획 수립 → 데이터 수집 → 데이터 구조화 및 분석 → 결론 정리**.

### 활동지 01 "아날로그 소리 디지털화하기" (p.156)
- 연계: 디지털 데이터 표현 방법, 교 52쪽
- 학습 목표(원문): "아날로그 소리를 디지털 데이터로 변환하는 과정을 정확히 이해하고, 이를 단계별로 디지털 값으로 변환하여 표현할 수 있다."
- 칸 구조: 작성자(학년·반·번·이름) / 단원명·쪽 수·학습 목표 / 그래프 3개(가로축 시간 1~6, 세로축 신호 0~5, 아날로그 파형이 그려져 있음)
  1. 표본화 — "세로 점선을 따라 선을 그어서 선과 파형이 겹치는 부분에 점을 찍어 보자."
  2. 양자화 — "가로선과 세로선이 만나는 지점의 값을 가까운 정숫값으로 표현해 보자." (시간 1~6에 값 쓰는 칸 6개)
  3. 부호화 — "위에서 찾은 정숫값을 3비트의 디지털 값으로 표현해 보자." (괄호 1칸)
- 예시 답안: 양자화 값 2, 4, 5, 4, 2, 3 → 부호화 ( 010100101100010011 ) (= 010 100 101 100 010 011)
- 평가 기준(원문): 평가 기준 "아날로그 소리를 디지털 데이터로 변환하는 과정을 정확히 이해하고, 이를 단계별로 디지털 값으로 변환하여 표현할 수 있다." / 상 "아날로그 소리를 디지털 데이터로 변환하는 과정을 정확히 이해하고, 표본화, 양자화, 부호화 단계를 거쳐 디지털 값으로 표현할 수 있다." / 중 "아날로그 신호인 소리가 디지털 값으로 바꾸는 과정을 설명할 수 있다." / 하 "소리 디지털 데이터는 0, 1로 이루어진 디지털 값임을 이해할 수 있다."

### 활동지 02 "우리 반 추억 앨범 만들기" (p.157)
- 연계: 디지털 데이터 표현 방법, 교 53쪽 (활동 플러스 '영상 편집하기'와 연결)
- 학습 목표(원문): "실생활의 다양한 디지털 데이터를 편집하여 동영상으로 만들 수 있다."
- 목표 지시문(원문): "우리 반 친구들과 함께 학급 활동, 주요 행사, 다양한 추억들을 모아 추억 앨범 동영상을 만들어 보자. 모둠원끼리 역할을 분담하여 영상 촬영, 배경 음악, 자막 등을 활용해 각자의 소중한 기억을 담아내고 협력 작업을 통해 멋진 결과물을 완성해 보자(응용 소프트웨어는 프레젠테이션, 무료 동영상 제작 사이트 등 다양하게 활용할 수 있다.)."
- 칸 구조: 표 '구성 | 내용' 4행
  - 인트로: '우리 반 추억 앨범' 제목 첫 화면, 학년·반·참여 학생 이름
  - 주요 활동 구성: 소풍·운동회·체험 학습 등 장면 구성, 사진·영상·짧은 설명·자막 또는 내레이션
  - 친구들의 소감 한마디: 영상 또는 자막
  - 엔딩: 팀원 감사 메시지 또는 반 전체 소감, 배경 음악과 마무리 화면
- 평가 기준(원문): 평가 기준 "실생활의 다양한 디지털 데이터를 편집하여 동영상으로 만들 수 있다." / 상 "추억 앨범 동영상 제작에 필요한 이미지, 소리, 동영상을 촬영하고 배경 음악과 자막을 삽입하여 동영상 데이터로 만들 수 있다." / 중 "추억 앨범 동영상 제작에 필요한 이미지, 소리, 동영상을 만들 수 있다." / 하 "추억 앨범 동영상 제작에 필요한 디지털 데이터를 모을 수 있다."

### 활동지 03 "나의 진로 계획서" (p.158)
- 연계: 데이터 수집과 관리, 교 56~61쪽
- 학습 목표(원문): "실생활에 필요한 데이터를 수집하고 구조화할 수 있다."
- 목표 지시문(원문): "내가 희망하는 직업이 무엇인지 적고, 목표를 이루기 위해 필요한 것들을 조사해 보자."
- 칸 구조(표): 희망 직업명 / 희망 직업에 필요한 능력(학력, 자격증, 핵심 능력 1·2·3) / 직업의 개요 및 특성 / 현재 준비해야 하는 것 / 앞으로 준비해야 하는 것 / 다짐
- 예시 답안: 희망 직업 컴퓨터 프로그래머 / 학력 컴퓨터 관련학과 졸업 우대(학과 상관 없음) / 자격증 정보 관리 기술사, 정보 처리 기사, 정보 기술 산업 기사, 정보 보안 기사, 빅데이터 분석 기사 등 / 핵심 능력 논리적 사고·문제 해결 능력, 기획력·학습력, 협업 능력 / 개요: 프로그램의 논리·알고리즘을 설계하고 프로그래밍·테스트 / 현재: 컴퓨터 동아리 팀 프로젝트, 파이썬 심화·간단한 앱 제작, IT 관련 고등학교 진학 준비, 프로그래밍 대회 참가 / 앞으로: 대학 컴퓨터공학과 입학, 인턴십·실무 경험, 글로벌 IT 기업 개발자 / 다짐: 단기 목표를 충실히 하며 장기 목표로 나아가겠다.
- 평가 기준(원문): 평가 기준 "실생활에 필요한 데이터를 수집하고 구조화할 수 있다." / 상 "다양한 수집 방법을 활용하여 희망하는 직업에 대해 필요한 능력들이 무엇인지 찾고, 다양한 형식의 보고서를 작성할 수 있다." / 중 "인터넷 검색 등을 활용하여 희망 직업을 찾고, 표로 구조화할 수 있다." / 하 "희망하는 직업이 무엇인지 찾고, 어떤 일을 하는지 작성할 수 있다."

### 활동지 04 "다양한 다이어그램의 특징 조사하기" (p.159)
- 연계: 데이터 구조화, 교 63~67쪽
- 학습 목표(원문): "데이터 구조화에서 사용되는 다양한 모양의 다이어그램의 특징을 조사하여 정리할 수 있다."
- 목표 지시문(원문): "아래에 제시된 다양한 다이어그램의 특징을 조사하여 정리해 보자."
- 칸 구조: 표 '종류 | 특징 | 사용 예시' 4행(막대 / 선 / 원 / 산점도 그래프(차트))
- 예시 답안
  - 막대: 양을 막대 길이로, 크고 작음을 한눈에 / 월 평균 기온, 강수량 파악
  - 선: 수량을 점으로 찍고 선분으로 연결, 시간에 따른 변화 기록에 유용 / 2030년 기대수명 추이, 코로나 19에 따른 온오프라인 매출 변화
  - 원: 전체에 대한 비율을 원으로, 백분율에 편리 / 1인 가구 비중, 친구들이 좋아하는 게임 비중
  - 산점도: X·Y축 좌표 평면에 관찰값을 점으로, 두 변량의 분포를 쉽게 파악 / 더우면 아이스크림이 더 팔리는지, 공부 시간이 늘면 점수가 오르는지
- 평가 기준(원문): 평가 기준 "데이터 구조화에서 사용되는 다양한 모양의 다이어그램의 특징을 조사하여 정리할 수 있다." / 상 "다양한 모양의 다이어그램의 특징을 조사하여 정리하고, 사용 예시를 3가지 이상 들 수 있다." / 중 "다양한 모양의 다이어그램의 특징을 간단하게 적고, 사용 예시를 2가지 이상 들 수 있다." / 하 "다양한 모양의 다이어그램의 특징을 간단하게 적고, 사용 예시를 1가지 이상 들 수 있다."

### 활동지 05 "고려 시대 태조 왕건 가계도 구조화하기" (p.160)
- 연계: 데이터 구조화, 교 63~67쪽 (역사 융합)
- 학습 목표(원문): "문장으로 표현된 데이터를 표, 다이어그램 등 다양한 형태로 구조화할 수 있다."
- 목표 지시문(원문): "다음은 고려 시대 왕가의 가계에 대한 글이다. 잘 읽고 물음에 답해 보자."
- 제시 글 요지: 태조 왕건(918~943)은 6왕후 23부인, 34자녀. 장화 왕후 → 2대 혜종(943~945) / 신명 왕후 → 3대 정종(945~949), 4대 광종(949~975) / 광종+대목 왕후 → 5대 경종(975~981) / 신정 왕후 → 대종(6대 성종의 아버지), 대목 왕후(경종의 어머니) — 광종은 이복남매 대목 왕후와의 사이에서 경종을 낳음 / 정덕 왕후 → 선의 왕후(성종의 어머니) — 대종+선의 왕후 → 성종(981~997), 헌애 왕후, 헌정 왕후 / 경종+헌애 왕후 → 7대 목종(997~1009) / 신성 왕후 → 안종, 안종+헌정 왕후 → 8대 현종(1009~1031).
- 칸 구조
  1. "고려 시대 왕의 재위 기간을 연도순으로 정렬하여 표로 구조화해 보자." — 표 3행(왕의 계보 / 왕 / 재위 기간) × 8열
  2. "고려 시대 왕가의 가계도를 다이어그램으로 구조화해 보자." — 빈 공간
- 예시 답안 1:

| 왕의 계보 | 제1대 | 제2대 | 제3대 | 제4대 | 제5대 | 제6대 | 제7대 | 제8대 |
|---|---|---|---|---|---|---|---|---|
| 왕 | 태조 | 혜종 | 정종 | 광종 | 경종 | 성종 | 목종 | 현종 |
| 재위 기간 | 918~943 | 943~945 | 945~949 | 949~975 | 975~981 | 981~997 | 997~1009 | 1009~1031 |
- 예시 답안 2(그림 확인): 태조와 왕후들(장화·신명·신정·정덕·신성)을 윗줄에, 자녀(혜종·정종·광종·대목 왕후·대종·선의 왕후·인종)를 둘째 줄에, 경종·헌애 왕후·성종·헌정 왕후를 셋째 줄에, 목종·현종을 맨 아래에 두고 혼인·출생을 선으로 연결한 가계도. 왕에는 대수 번호 1~8 표기.
- 평가 기준(원문): 평가 기준 "문장으로 표현된 데이터를 표, 다이어그램 등 다양한 형태로 구조화할 수 있다." / 상 "문장으로 표현된 데이터를 이해하기 쉽도록 표, 다이어그램 등 다양한 형태로 구조화할 수 있다." / 중 "문장으로 표현된 데이터를 표와 다이어그램으로 구조화할 수 있다." / 하 "문장으로 표현된 데이터를 표로 구조화할 수 있다."

### 활동지 06 "피벗 테이블을 활용하여 구조화하고 분석하기" (p.161)
- 연계: 데이터 분석(쪽 수 표기 63~67쪽)
- 학습 목표(원문): "스프레드시트의 피벗 테이블 기능을 활용해 데이터를 구조화하고 분석할 수 있다."
- 도입 문장: 피벗 테이블은 주로 스프레드시트에서 쓰는 구조화·분석 도구로, 대량 데이터를 효과적으로 분석·구조화.
- 단계(원문): 1 "데이터를 입력한다." 2 "피벗 테이블을 사용하여 학급별 문해력과 수리력의 평균을 구조화하고 분석해 보자." 3 "피벗 테이블을 사용하여 과목별 최고점, 최저점 등을 구조화하고 분석해 보자."
- 데이터셋:

| 학생 이름 | 학급 | 문해력 | 수리력 |
|---|---|---|---|
| 김민수 | 1 | 85 | 80 |
| 이지은 | 1 | 78 | 88 |
| 박준혁 | 1 | 92 | 85 |
| 홍길동 | 2 | 75 | 70 |
| 최유리 | 2 | 88 | 90 |
| 김영서 | 2 | 60 | 75 |
| 유서연 | 3 | 95 | 99 |
| 정재훈 | 3 | 90 | 85 |
| 한유주 | 3 | 80 | 70 |
- 예시 답안(그림 확인): 2 행 레이블=학급, 값=평균 — 1반 85.0 / 84.3, 2반 74.3 / 78.3, 3반 88.3 / 84.7, 총합계 82.6 / 82.4 (문해력/수리력). 3 최대: 문해력 95.0, 수리력 99.0 / 최소: 문해력 60.0, 수리력 70.0.
- 평가 기준(원문): 평가 기준 "스프레드시트의 피벗 테이블 기능을 활용해 데이터를 구조화하고 분석할 수 있다." / 상 "스프레드시트의 피벗 테이블 기능을 알고, 다양한 방법으로 데이터를 구조화하고 분석할 수 있다." / 중 "스프레드시트의 피벗 테이블 기능을 활용할 수 있다." / 하 "스프레드시트의 피벗 테이블 기능이 있음을 알고 있다."

### 활동지 07 "지구를 살리자! [데이터 분석 프로젝트]" (p.162~163)
- 연계: 데이터 분석, 교 68~70쪽 (과학·환경 융합)
- 학습 목표(원문): "지구 환경에 대해 문제를 정의하고, 데이터 분석 프로젝트 절차에 따라 데이터를 수집하고, 분석하여 지구를 살리는 방안에 대해 의견을 제시할 수 있다."
- 목표 지시문 요지: 환경 위기 데이터를 직접 수집·구조화·분석해 원인과 영향을 이해하고 해결 방안을 제시. 주제는 기후·오염·생태계 등에서 선택.
- 칸 구조(5단계): 1 문제 정의 / 2 계획 수립 / 3 데이터 수집 / 4 데이터 구조화 및 분석 / 5 결론 정리
- 예시 답안
  - 1 제목 "지구 온난화와 이산화 탄소 배출량의 관계 분석" — CO₂ 배출량 변화가 지구 평균 기온 상승에 어떤 영향을 주는지 분석.
  - 2 수집 방법: 신뢰할 수 있는 기관(기상청, 환경부, NASA)의 CO₂ 배출량·평균 기온 데이터 / 분석 도구: 스프레드시트(엑셀, 구글 시트)와 그래프 / 역할 분담: 인터넷 설문, 신문 기사 검색, 통계 자료 수집 등.
  - 3 수집 데이터: 연도별 전 세계 CO₂ 배출량, 지구 평균 기온 변화, 우리 학급 환경 인식 설문, 실천할 수 있는 일 인터뷰 등.
  - 4 표:

  | 연도 | CO₂ 배출량(십억 톤) | 지구 평균 기온 상승(℃) |
  |---|---|---|
  | 2000 | 25 | +0.42 |
  | 2005 | 28 | +0.55 |
  | 2010 | 31 | +0.63 |
  | 2015 | 33 | +0.87 |
  | 2020 | 34 | +1.02 |
    - 그래프: 2000~2020년 CO₂ 배출량 막대(단위 Mt, 25,234 / 29,603 / 33,343 / 34,974 / 34,807 / 35,496 / 36,703 등 표기), 1850~2000년대 지구 평균 기온의 변화 선 그래프(13.5~14.5℃). (그림, 연도별 정확한 대응은 확인 불가)
  - 5 결론: 2000~2020년 CO₂ 배출량과 평균 기온이 함께 상승 / 강한 양의 상관관계 확인 / CO₂ 증가는 온난화의 주요 원인 중 하나 / 개인 노력(에너지 절약, 대중교통, 재활용)과 사회적 노력(재생 에너지 확대, 친환경 정책, 국제 협력) 모두 필요.
- 평가 기준(원문): 평가 기준 "지구 환경에 대해 문제를 정의하고, 데이터 분석 프로젝트 절차에 따라 데이터를 수집하고, 분석하여 지구를 살리는 방안에 대해 의견을 제시할 수 있다." / 상 "지구 환경에 대해 문제를 정의하고, 데이터 분석 프로젝트 절차에 따라 지구를 살리는 방안에 대해 의견을 제시할 수 있다." / 중 "지구 환경에 대해 문제를 정의하고, 필요한 데이터를 수집하여 간단하게 의견을 제시할 수 있다." / 하 "지구 환경에 대한 문제를 정의하고, 문제 해결을 위한 데이터를 검색할 수 있다."

### 활동지 08 "사람들의 관심사는 무엇일까?" (p.164~165)
- 연계: 데이터 분석, 교 68~71쪽
- 학습 목표(원문): "사례를 중심으로 데이터 간의 관계를 파악하고, 데이터에 기반하여 의미를 해석할 수 있다."
- 목표 지시문(원문): "다양한 플랫폼의 데이터 활용 키워드 분석 결과를 살펴보며 질문에 답해 보자."
- 칸 구조와 예시 답안 (그래프는 그림으로만 제시)
  1. 네이버 데이터랩 검색어 트렌드 '캠핑장'·'카라반' 지난 1년(https://datalab.naver.com/) — '그래프를 통해 알 수 있는 정보' 칸. 예시: 캠핑장은 봄·가을 관심도가 높고 특히 가을 최고 / 카라반은 계절 영향이 적고 겨울에는 캠핑장보다 카라반을 더 찾음.
  2. 네이버 데이터랩 지역 통계 '강원도' 관광지 관심도 지난 1년 — '검색 결과를 통해 알 수 있는 정보' 칸. 예시: 강원도 전체 지역 통계 / 강릉시가 계절에 상관없이 가장 관심 높음 / 가을 홍천, 봄 춘천 관심 급증.
  3. 구글 트렌드 '수영복'·'래시가드' 지난 5년(https://trends.google.co.kr/) — "결과 그래프로 어떤 사실들을 알 수 있는지 적어 보고, 바이러스 ‘코로나19’ 발생 시점을 찾아 비교 설명해 보자." 예시: 매년 여름 급증, 겨울 방학(휴가)에 소폭 상승 / 겨울에는 래시가드보다 수영복 관심이 높음 / 2019년 12월 코로나 발생 이후 거리두기·심리적 영향으로 관심 하락, 실내 물놀이 선호 / 거리두기 해제 후 회복.
  4. "구글 트렌드에서 관심 있는 키워드로 지난 1년간 검색 추이를 알아보고, 그 결과를 다양하게 분석해 보자." — 표 '검색어 1 | 검색어 2 | 해석' 3행. 예시: 겨울 코트/코트 — 가을부터 오르다 12월 최고, 2월에 다시 오름, 역시즌 여름에도 오름 / 코로나/백신 — 전체 하향이지만 코로나 검색이 오르면 백신 관심도 오름 / 북극곰/지구 온난화 — 비슷한 곡선.
- 평가 기준(원문): 평가 기준 "사례를 중심으로 데이터 간의 관계를 파악하고, 데이터에 기반하여 의미를 해석할 수 있다." / 상 "다양한 플랫폼의 데이터 활용 키워드 분석 결과를 살펴보며 그 결과를 다양하게 분석하고, 의견을 제시할 수 있다." / 중 "다양한 플랫폼의 데이터 활용 키워드 분석 결과를 분석할 수 있다." / 하 "다양한 플랫폼의 데이터 활용 키워드 분석 결과를 이해할 수 있다."

## 원문 오류 의심
- p.171 시험 대비 03-08 해설 "학교 수업과 학원 및 숙제 시간을 합하면 총 55.5%" — 40%+15% = 55%. 계산 결과(8.8시간 = 8시간 48분)는 55% 기준으로 맞으므로 55.5%는 오기.
- p.168 시험 대비 02-05 문제에 묻는 말(발문)이 없음. "다음은 과제에 대한 학생들의 대화 내용이다."로 끝나고 보기 ①~⑤만 있음. 정답·해설로 보아 "대화에 나타나지 않은 데이터 수집 방법은?"이 빠진 것으로 보임.
- p.168 시험 대비 02-03 해설 "아스키코드는 국제 표준화 기구에서 개발하고 미국 표준화 협회에서 제정한" — 교과서 본문(교 49쪽)은 "미국 표준화 협회에서 만든 표준 코드"라고만 함. 개발 주체 서술이 본문과 다름.
- p.161 활동지 06 단원명은 '데이터 분석'인데 쪽 수가 63~67쪽(데이터 구조화 쪽)으로 표기됨. 피벗 테이블은 교 58~59쪽 해설(p.129)·교 68~70쪽 실습과 관련.
