# ch08 인공지능과 데이터
> 대단원: Ⅳ. 인공지능 | 지도서 p.294~314 (대단원 개관·차시별 지도 계획 p.294~303 포함) | 교과서 160~170쪽 | 성취기준: [9정04-01], [9정04-02] | 차시: 6차시 (01 인공지능 시스템 3차시, 02 학습 데이터 3차시)

## 핵심 한 줄
- 인공지능은 인간의 지적 능력(특히 학습)을 흉내 낸 소프트웨어이며, 데이터를 학습한 **인공지능 모델**이 분류·예측·군집·생성을 수행함. 일반 소프트웨어와 달리 **학습·추론·인식** 특성이 있고, 성능은 **학습 데이터의 양과 질**에 좌우되므로 목적에 맞는 데이터를 수집·분류·전처리해야 함. (p.305~313, 교 161~169쪽)

## 대단원 개관
### 대단원 소개 (p.294)
- 디지털 사회 핵심 기술인 인공지능의 기초 개념·특성, 인공지능이 데이터를 활용해 문제를 해결하는 과정, 인공지능의 윤리적 측면을 학습함. 실생활 활용 기초 능력과 윤리적 태도 함양이 목표. (p.294)

### 대단원 지도 목표 (원문, p.294)

2. "인공지능 학습에서 데이터의 중요성을 인식하고, 학습에 필요한 데이터를 수집하고 분류할 수 있다."
3. "다양한 데이터를 활용하여 인공지능 시스템을 구성하고 적용할 수 있다."

5. "인공지능 학습에 필요한 데이터의 수집과 활용에서 발생할 수 있는 윤리적 문제를 이해하고, 이를 해결하기 위한 방안을 구상할 수 있다."

## 소단원 01 인공지능 시스템 (교 161~165쪽, p.305~309)

### 수업 흐름 (차시별 지도 계획)
#### 1차시 (p.296, 교 160~162쪽, 지도서 304~306쪽, 소요 1차시)
- **학습 목표**: "인공지능의 개념과 특성을 설명하고, 인공지능 소프트웨어를 구별할 수 있다."
- 수업 형태: 협동 학습, 탐구 학습, 토의·토론 학습 / 준비물: 교과서, 노트와 필기도구, 컴퓨터 또는 태블릿
- **도입**
  - 생각의 씨앗 심기로 일상에서 활용되는 인공지능에는 무엇이 있을지 생각하도록 유도함.
    - 내 주변에서 사용되는 인공지능은 어떤 것이 있으며, 인공지능이란 무엇인지 생각해 보게 함.
    - 인공지능의 높은 성능에는 데이터가 중요한 역할임을 설명하고, 실생활 인공지능이 어떤 데이터를 쓰는지 예상해 보게 함.
  - 새싹 틔우기를 보고, 여러 인공지능을 접하면서도 그것이 인공지능인지 생각해 보지 않는 경우가 많음을 설명하며 내 주변 인공지능을 한 번 더 생각하게 함.
  - 유의점: 실생활 인공지능의 구체적 사례를 쉽게 떠올리도록 다양한 예시 제공 / 인공지능과 데이터를 연결해 생각하도록 발문으로 사고 유도.
- **전개**
  - ➊ 인공지능의 개념 이해하기: 인간의 지적 능력을 모방해 만든 소프트웨어가 인공지능임을 설명. 특히 데이터를 학습해 만든 인공지능 모델로 분류·예측·군집·생성 등을 수행할 수 있음을 설명.
  - ➋ 인공지능의 특성 이해 및 인공지능 소프트웨어 구분하기: 인공지능 모델·기능을 쓰는 인공지능 소프트웨어는 규칙·순서 기반 일반 소프트웨어와 다른 특성이 있음을 설명. 특성으로 학습·추론·인식을 각각 사례로 설명. 인공지능 소프트웨어 여부를 사례로 구분하도록 설명.
    - (활동으로 쑥쑥 1) 실생활 기술·제품 중 인공지능이 활용된 사례를 구별해 보게 함.
  - 유의점: 실생활 사례로 개념·특성을 쉽게 설명 / 활동을 일찍 끝낸 학생은 교과서 외에 직접 경험한 다른 인공지능 사례를 나누게 함.
- **정리**: 인공지능의 개념·특성을 상기시키고 실생활 적용 사례로 개념을 명확히 정리 / 발표 내용 종합·요약으로 학습 목표 달성 확인 / 다음 차시 예고.
  - 유의점: 혼란스러워하는 부분은 간단·명확한 예시로 재설명.
- **성취 수준**: [9정04-01] A/B/C (위 '성취기준과 학습 목표' 참조). (p.296)

#### 2~3차시 (p.297, 교 163~165쪽, 지도서 307~309쪽, 소요 2차시)

- 수업 형태: 협동 학습, 탐구 학습, 토의·토론 학습 / 준비물: 교과서, 노트와 필기도구, 컴퓨터 또는 태블릿

  - 유의점: 온라인 게임 소프트웨어 시스템에 대해 자유롭게 이야기 나누게 하여 동기 유발.
- **전개**
  - ➊ 인공지능 시스템의 구성 원리와 문제 해결 사례 조사하기: 인공지능 소프트웨어로 특정 목적을 달성하는 인공지능 시스템은 인공지능 모델, 응용 소프트웨어, 외부 시스템, 클라우드, 하드웨어, 센서 등으로 구성됨을 설명. 예측·분류·군집(그룹화)·인식·이해·생성 과업의 적용 사례 제시.
    - 인공지능 시스템을 이용한 문제 해결 사례를 개별·협동으로 조사해 발표하게 함.
  - ➋ (활동으로 쑥쑥 2) 인공지능 소프트웨어의 특징 확인하기: 인공지능 스피커의 특징을 확인(단계별 작성 안내) → 실생활의 다른 인공지능 서비스·제품의 특징을 단계적으로 확인 → 작성 내용을 발표하고 인공지능이 아닌 것과의 차이점, 사용된 기술을 토론.
  - 유의점: 조사 사례 발표 시 서로의 견해 공유, 발표 후 피드백 / 친숙한 인공지능 스피커 사례로 단계적 확인 / 친구 발표를 들으며 우리 모둠 작성 내용과 비교.
- **정리**: 발표 내용 종합·요약으로 학습 목표 확인 / 인공지능 시스템의 구성 원리와 문제 해결 과정 개념 정리 / 다음 차시 예고. 유의점: 다양한 사례로 쉽게 정리. (p.297)

### 전개 — 본문 흐름과 핵심 개념
1. **인공지능의 개념** (교 161쪽, p.305)
   - 인간의 지적 능력(학습, 언어 이해·구사, 이미지·소리 인식, 추론, 합리적 판단, 문제 해결)을 흉내 내어 소프트웨어로 만든 것 = 인공지능(AI: Artificial Intelligence).
   - 특히 **학습 능력**이 많이 활용됨: 숫자를 배운 사람 머릿속에 숫자를 읽는 지능적 모델이 생기듯, 컴퓨터는 알고리즘으로 숫자 데이터를 학습해 숫자 분류 인공지능 모델을 만듦.
   - **인공지능 모델**: 데이터를 학습하여 만들어진 모델. 사물의 분류·예측·군집·생성 등에 사용.
   - 지도서 보충: 모델은 학습된 데이터를 바탕으로 더 나은 결과를 내도록 돕는 구조. (p.305)
2. **인공지능의 특성** (교 162쪽, p.306)
   - 인공지능 소프트웨어 = 인공지능 모델 혹은 기능을 사용하는 소프트웨어. 미리 정해진 규칙·순서대로 동작하는 일반 소프트웨어와 다름.
   - 비교 그림: "▲ 리모컨으로 제어하는 로봇"(리모컨으로만 움직임, 움직임 이외 기능 없음) vs "▲ 헬스케어용 스마트워치"(운동량 감지·건강 상태 학습, 맞춤형 운동·건강 관리법 제안).
     - 예시 답: 리모컨 로봇은 데이터로 만든 지능 모델로 판단·행동하지 않으므로 인공지능이 아님 / 스마트워치는 운동량 데이터를 학습한 모델을 쓰므로 인공지능. (p.306)
   - 특성 3가지:
     - **학습**: 데이터를 분석해 패턴을 인식하고 모델 성능을 지속 향상. 예) 개·고양이 이미지를 많이 학습해 특징을 파악, 새 이미지 구분.
     - **추론**: 기존 지식으로 새 상황의 결론 도출·예측·문제 해결. 예) 고양이 특징을 학습했다면 새로 발견한 작은 동물이 고양이일 가능성을 추론.
     - **인식**: 입력 데이터를 해석해 주변 환경·상황을 이해하고 판단·행동 결정. 예) 자율주행차가 센서·카메라 데이터로 차량·신호등·보행자를 인식해 속도·방향 조정. (보조단 "학습, 추론, 인식의 예", p.306)
3. **인공지능 시스템의 구성 원리와 문제 해결** (교 163쪽, p.307)
   - 인공지능 시스템 = 인공지능 소프트웨어를 사용해 사용자의 요구·사용 목적을 달성해 주는 컴퓨팅 시스템. 인공지능 모델, 응용 소프트웨어, 외부 시스템, 클라우드, 하드웨어, 센서 등으로 구성·연결된 하나의 집합.
   - 보조단 "인공지능 시스템과 인공지능 소프트웨어": 큰 규모의 인공지능 소프트웨어를 인공지능 시스템으로 보기도 함.
   - 일반적 흐름: 문제 데이터로 모델 학습 → 학습된 모델로 지능적으로 문제 해결(인간 개입 없이). [그림 Ⅳ-1] 데이터 → 학습 → 인공지능 모델 → 인공지능 시스템 → 문제 → 문제 해결.
   - 과업 4가지와 사례(교과서 표):
     - **예측, 분류**: 주어진 값에 따라 수치 예측·클래스 분류. 안구 이미지로 질환 예측·치료 방법 결정, 멸종 위기 동물 분류. (◀ ○○대병원 녹내장 진단·소견 제시 인공지능)
     - **군집(그룹화)**: 비슷한 특성끼리 묶음. 상품·영화 추천, 고객 구분 마케팅. (◀ 자주 검색·즐겨보는 영화 추천)
     - **인식, 이해**: 이미지·자연어 인식·이해. 이미지·음성 인식, 자연어 채팅, 번역, 자율주행 인식. (◀ 음성으로 전등·냉장고·자율주행 제어)
     - **생성**: 문맥에 맞는 문장·이미지 생성. 채팅, 연습 문제 자동 생성, 문서 요약, 이미지 생성. (◀ "노을, 강, 배가 있는 풍경"과 같은 단어만으로 그림을 그려 주는 인공지능) (p.307)
   - 지식 플러스 "인공지능은 어떻게 발전해 왔을까?": 1950년대 등장 당시는 규칙 기반 시스템으로 논리 연산·간단한 체스 등 제한된 작업만 함 → 오늘날 머신러닝·딥러닝으로 자율 판단·문제 해결, 음성 인식·자율주행·이미지 인식 등에 활용. (p.307)
4. **인공지능 시스템의 적용 사례** (교 164쪽, p.308)
   - 지시문: "인공지능의 특성에 관한 내용을 알고, 우리 주변에서 볼 수 있는 인공지능 시스템의 적용 사례를 살펴보자."
   - [그림 Ⅳ-2]:
     - **음성 인식 서비스**: 스마트폰·태블릿에 말하면 이해·반응. 예) "오늘의 날씨는 어때?"라고 물으면 날씨를 알려 줌. 목소리의 음향 패턴을 처리·분석해 텍스트·실행 명령으로 변환. (지도서: 스마트 홈 제어, 차량 내비게이션, 고객 서비스에 활용)
     - **추천 시스템**: 시청 기록·선호도 분석, 행동·선호 패턴 파악으로 취향 콘텐츠 예측·추천. (지도서: 쇼핑몰 상품 추천, 음악 플레이리스트, 동영상 플랫폼)
     - **자동 번역기**: 다국어 번역·방대한 문서 데이터 학습, 문맥·의미·문법을 이해해 복잡한 문장도 번역. (지도서: 국제 비즈니스, 여행, 학술 연구의 언어 장벽 완화) (p.308)
   - **말랑말랑 정보 이야기 "지능형 에이전트란?"**: 에이전트 = 센서로 환경을 인식하고 행동을 취해 외부와 상호 작용하며 어려운 문제를 해결. 그중 지능형 에이전트는 역동적인 외부 환경을 인지해 지능적으로 판단·의사 결정하고 자율적으로 행동해 목적을 이루는 시스템. 음성 인식 서비스, 추천 시스템, 자동 번역기, 적응형 게임(사용자 수준에 따라 난이도·전략 조절), 헬스케어 앱 모두 지능형 에이전트. 삽화 말풍선: "오후에 비가 내린대요. 우산 챙기세요.", "사물 인지 정지!", "오늘 오후 2시 병원 가는 시간이에요.", "휴......", "그러면 사람도 지능형 에이전트일까요?" (p.308)
   - 지식 플러스 "지능형 에이전트란?": 복잡·동적인 환경을 인식하고 목표 달성을 위해 자동으로 행동하도록 설계된 인공지능 소프트웨어. 자율주행차 예: 카메라·센서로 도로 환경 인식 → 다른 차량·보행자 정보 분석 → 속도 조절·차선 변경을 자동 수행. (출처: TTA 정보 통신 용어 사전, p.308)

  - 범용 챗봇: 새로운 정보 학습·지속 업데이트, 질문 내용·의도 이해 후 답변 생성 → (O, X) 빈칸

### 형성 평가 · 핵심 개념 정리하기
- **형성 평가(O/X)** (p.309)

  3. 모든 인공지능 시스템은 동일한 방식으로 문제를 해결한다 → X (다양한 모델·방식)

  - 데이터 유형 알아보기: 수집 데이터의 유형 점검.

  - 유의점: 주제·목표에 맞는 데이터를 선택하도록 충분한 피드백 / 분류 기준을 세우도록 질문과 예시 활용.
- **정리**: 결과물 공유·피드백 / 어려웠던 점 공유 / 학습 내용 정리 및 자기 평가 / 다음 차시 예고. 유의점: 배운 내용 정리, 형성 평가로 스스로 정리. (p.299)

### 동기 유발 — 새싹 틔우기
- **제목 발문(원문)**: "인공지능은 어떻게 학습할까요?" (p.310, 교 166쪽)
- **만화 4칸** (그림 확인, p.310):
  1. 책상에서 책·노트북으로 공부하는 학생 — "사람은 책, 인터넷 등을 통해 학습해요."
  2. 칠판 앞 학생이 수학 문제를 풀고 "정답! 50125" — "사람의 뇌는 학습한 내용을 분석하거나 처리하지요."
  3. 'AI' 캐릭터가 여러 데이터(그림·문서·소리 등)를 빨아들이는 장면 — "인공지능은 다양하고 방대한 데이터를 통해 학습을 해요."
  4. 사람이 고양이를 가리키며 "무슨 동물이게?"라고 묻고 AI가 답하는 장면 — "인공지능은 학습한 내용을 인공지능 알고리즘으로 분석하거나 처리해요."
- **지도서 해설**: 인공지능은 사람이 책·인터넷으로 학습하듯 방대한 데이터로 스스로 학습해 문제를 해결함. 학습에서 데이터는 어떤 역할을 하고, 학습 데이터를 수집·분류하는 방법에는 어떤 것이 있을지 생각하게 함. (p.310)

### 전개 — 본문 흐름과 핵심 개념
1. **인공지능과 학습 데이터** (교 166쪽, p.310)
   - 모델 학습은 데이터 기반이므로 데이터가 중요. 좋은 인공지능 = 목적에 맞는 충분한 양의 질 좋은 데이터. 예) 인공지능 기상 예보 시스템은 기온·강수량·바람·습도 등을 충분히 학습해야 함.
   - [그림 Ⅳ-3] 일기 예보 시스템 문제 해결 과정 (4단계):
     - 학습 데이터 수집 — **관측**: 풍향, 풍속, 기온, 습도, 강수량, 구름 양, 구름 높이, 안개 등 날씨 데이터 수집
     - 인공지능 모델 생성과 학습 — **수치 예보 모델**: 공기 움직임과 날씨를 시간마다 예측하는 컴퓨터 프로그램
     - 인공지능 모델 사용 — **예보**: 초단기~장기 예보, 기후 전망 생산
     - 문제 해결 및 활용 — **통보 활용**: 예보를 다양한 매체에 전달, 여러 분야에서 활용
   - 품질과 양이 중요: 잘못된 정보·오류, 대표성 부족으로 **편향된 불량 데이터**, **양이 적은 데이터**는 성능을 떨어뜨리고 의도치 않은 부정확한 판단·예상 못한 결과를 초래.
   - 지도서 보충: 의료·금융·교통 같은 중요한 분야에서 잘못된 예측·판단은 매우 큰 문제. 정확성 + 다양한 상황을 반영할 충분한 양이 필요. (p.310)
2. **학습 데이터의 수집 및 분류** (교 167~168쪽, p.311~312)
   - 학습 데이터 = 인공지능 학습을 위해 입력하는 데이터. 유형: 수치, 이미지, 소리, 텍스트 등. 목적에 맞게 수집·분류해야 함.
   - 보조단 "데이터 수집 방법": 직접 데이터 수집 / 인터넷 검색을 통한 수집 / 공공 기관이나 기업에서 제공하는 공개 데이터 수집. (교 167쪽)
   - **(1) 수치 데이터 준비** — 본문 발문: "미래의 연평균 기온을 예측하려면 어떤 유형의 학습 데이터가 필요할까?"
     - [그림 Ⅳ-4] '엔트리-데이터 분석-테이블 불러오기-테이블 추가하기'의 '계절별 기온' 데이터 (우리나라 연평균 기온과 계절별 평균 기온). 미래 연평균 기온 예측을 위해 수치형 '연도'와 '연평균' 기온을 속성으로 설정.
     - 말풍선: "열 방향의 항목들을 속성이라고 해요." / "속성은 데이터를 이해하거나 분석하는 데 핵심이 되는 요소입니다." / "이 외에도 비어 있는 수치(결측치)가 없는지, 정상 범위를 벗어난 수치(이상치)는 없는지도 확인해 보아야 해요." / "수집한 데이터를 학습 데이터로 사용하기 위해 정제하는 작업을 '데이터 전처리'라고도 해요." 그림 표기: 속성명 / 데이터(속성값).
     - 꼭 필요한 속성만 쓰고 불필요·중복 데이터 제외.
     - 엔트리 조작(지도서 보충): ❶ 테이블 추가하기 — [데이터 분석] → [테이블 불러오기] → [테이블 추가하기] 순으로 클릭(테이블 추가, 데이터 파일 올리기, 새로 만들기 가능). ❷ '계절별 기온 데이터' 적용 — [테이블 선택]에서 '계절별 기온' 선택 후 [추가하기] → [적용하기]. (p.311)
     - 지식 플러스 "결측치와 이상치": 결측치 = 누락된 값(그대로 쓰면 학습 오류 → 다른 값으로 대체하거나 해당 데이터 제거). 이상치 = 다른 값들을 크게 벗어난 비정상 값(입력 오류·특이 상황에서 발생, 잘못된 패턴 학습 → 식별·처리 필요). 그림: 테이블에서의 결측치, 박스 플롯(최솟값·1사분위수·중앙값·3사분위수·최댓값, 사분위수 범위 밖 이상치). (p.311)
   - **(2) 이미지 데이터, 소리 데이터 준비**
     - 이미지: 대상이 명확히 드러나는 이미지 선택. 인물 구분 목적이면 인물이 이미지 대부분을 차지하고 배경 객체가 적게. [그림 Ⅳ-5] "토끼가 명확히 드러나는 이미지 데이터" vs "토끼 외에도 다른 물체들이 두드러진 이미지 데이터".
     - 소리: 중점 음성이 또렷하고 잡음이 적은 것이 질 좋은 데이터. [그림 Ⅳ-6] 깨끗한 소리 데이터 vs 잡음이 있는 소리 데이터.
     - 지도서 보충: 동물 인식용 이미지는 **다양한 각도**에서 촬영한 것을 수집하는 것이 바람직. (p.312)
   - **(3) 텍스트 데이터 준비**
     - 영화·드라마 긍정/부정 반응 분류 → 댓글 텍스트 데이터 필요. 문자·단어·기호로 구성. 목적에 맞게 충분히 수집하고 일정 기준(긍정/부정)으로 분류해 놓음. [그림 Ⅳ-7] 댓글 예: "강아지 너무 귀엽다.", "이런 날씨 너무 싫어.", "너무 추울 것 같아요.", "추운데 왜 나가지?", "춘천의 온도가 영하 11도라니!" (수치·이미지·텍스트 데이터가 섞인 SNS 화면).
     - 말풍선: "자동 번역 시스템이나 챗봇 시스템을 만들기 위해서도 많은 양의 텍스트 데이터가 필요해요."
     - 말풍선(윤리): "데이터 수집 및 분류를 할 때는 데이터에 개인 정보가 노출되어 있거나 사회 질서를 어지럽힐 수 있는 등의 내용이 담겨 있을 경우, 사전에 제거하여 심각한 윤리적 문제가 발생하지 않도록 유의해야 합니다."
     - 지도서 보충: 뉴스·대화·SNS에서 수집 → 불필요한 기호·오류 제거, 단어·문장을 잘게 나눠 학습하기 쉬운 형태로 정리. (p.312)
   - 지식 플러스 "데이터 증강 기법": 기존 데이터에 약간의 변화(회전·확대 등)를 주어 새 데이터를 만들어 양을 늘리고 성능을 높임. 데이터가 부족할 때 유용, 얼굴 인식·자율주행·의료 영상 분석에 사용. (p.312)
   - 지식 플러스 "윤리적 문제 고려하기": 개인 정보나 사회 질서를 어지럽힐 민감 내용은 적절히 처리하지 않으면 심각한 윤리 문제. 데이터 사용 영향을 미리 생각하고 조치. (p.312)

### 활동
#### 선택 활동 "인공지능 학습 데이터 수집하기" (교 169쪽, p.313) — 문제 기반 학습, 역량: 탐색·협력
- 형태: 모둠 / 도구: 검색 엔진, 캐글(kaggle) 등 데이터 사이트, 폴더 정리
- **지도 목표**: "모둠별로 협력하여 주제를 정하고, 주제에 맞는 학습 데이터를 수집하고 분류할 수 있다."
- **지시문(원문)**: "우리 모둠에서 정한 주제를 가지고 학습 데이터를 수집한 후 토의해 보자."
- **단계(원문)**:
  1. "주제를 정해 보자." — 해결하고 싶은 문제나 재미있는 주제를 선정한다.
  2. "데이터 수집 방법을 찾아보자." — 데이터를 직접 수집하거나 인터넷 사이트에서 수집하는 방법 등을 이용한다.
  3. "데이터를 분류해 보자." — 수집한 데이터들은 각 특성이나 범주에 따라 알맞게 분류한다.
  4. "데이터의 유형을 알아보자." — 수집한 데이터 유형이 무엇인지 점검한다. (그림: 텍스트·수치·이미지·소리 데이터 아이콘)
  5. "토의해 보자." — 수집한 데이터는 어떤 의미가 있을지 자유롭게 토의한다.
- **교과서 예시**: 주제 "강아지와 고양이 구분하기" → 검색 엔진이나 캐글 같은 사이트에서 '강아지(dog)'와 '고양이(cat)'를 검색해 이미지 내려받기 → 내려받은 이미지를 '강아지'·'고양이' 폴더별로 구분. 유형: 이미지 데이터.
- **예시 답안 및 해설**: 모둠별로 주제를 정하고 주제에 맞는 수집·분류를 수행한 뒤 자유 토의.
- **지도상의 유의점**: 모둠별로 자유롭게 주제를 정하되 서로 의견을 존중해 결정하게 함 / 수집·분류 과정에서 윤리적 문제를 고려하게 함.
- **평가하기(교과서, 상·중·하)**: "모둠원과 하나의 주제를 선정하고 주제와 관련된 데이터 수집 방법을 조사하였는가?" / "수집한 데이터를 분류하고 데이터의 유형을 파악하였는가?"
- **평가 후 지도 방법**: "인공지능 학습에서 데이터의 중요성을 설명할 수 있는가?" → 데이터의 중요성을 이해할 수 있게 / "학습에 필요한 데이터를 수집하고 분류할 수 있는가?" → 수집할 수 있게, 분류할 수 있게. (p.313)
- 평가 도구: 수행 평가 — 지도서 346~347쪽 수행 평가 활동지 01 / 지필 — 354~359쪽. (p.313)

### 형성 평가 · 핵심 개념 정리하기
- **형성 평가(O/X)** (p.313)
  1. 데이터를 학습할 때 양보다 질이 더 중요하다 → X (양과 질 모두 중요)
  2. 이미지를 수집할 때 특정 각도·조명 조건에서만 촬영된 이미지만 쓰는 것이 좋다 → X (다양한 각도)
  3. 소리 데이터는 음성 인식·소리 분류에 쓰이며 배경 소음이 최소화된 데이터가 좋다 → O
- **핵심 개념 정리하기**: 학습 데이터(인공지능 학습에 쓰는 다양한 형태의 데이터) / 학습 데이터의 수집과 분류(목적에 맞게 선별·수집 → 정리·분류 → 적절한 형태로 전처리, 윤리 문제 고려). (p.313)

### 활동지 제작 아이디어 (제안)
1. **"좋은 데이터 vs 나쁜 데이터" 판별 활동지**: 토끼 사진 2장, 깨끗한/잡음 소리 설명, 결측치·이상치가 숨은 작은 기온 표를 제시 → 문제점 표시·고치기 → 정리 문항(형성 평가 3문항 재사용).
2. **엔트리 '계절별 기온' 테이블 탐색 활동지**: 테이블 추가 절차 따라 하기 → 속성명/속성값 표시 → 미래 연평균 기온 예측에 필요한 속성만 동그라미 → 결측치·이상치 확인 체크박스.
3. **모둠 데이터 수집 계획서(선택 활동 양식)**: 주제 / 클래스(범주) / 수집 방법(직접·검색·공개 데이터) / 유형 / 윤리 점검(개인 정보·민감 내용) / 우리 데이터의 의미 칸. 수행 평가 활동지 01과 연결.
4. **일기 예보 4단계 흐름도 빈칸 채우기**: 관측→수치 예보 모델→예보→통보 활용을 '수집→학습→사용→활용'에 대응시키기.

## 오개념 · 지도 유의점 모음
- "센서가 있으면 인공지능"이라는 오개념: 마트 자동문은 센서로 감지만 하므로 인공지능 아님. 판단 기준은 데이터로 만든 지능 모델로 판단·행동하는지(학습·추론·인식). (p.306)
- "정해진 규칙에 따라 정확히 동작 = 똑똑함" 오개념: 계산기·조명 타이머·디지털시계는 규칙 기반 일반 소프트웨어. (p.306, p.354)
- "데이터는 많기만 하면 된다" / "질만 좋으면 양은 상관없다" 둘 다 오개념: 목적에 맞는 충분한 양 + 질 좋은(정확·대표성·비편향) 데이터. 형성 평가 1번(X)과 시험 대비 문항에서 반복. (p.310, p.313, p.358)
- 이미지 데이터는 대상이 명확하되 **다양한 각도·조건**으로 수집해야 함(특정 조건만이면 안 됨). (p.312~313)
- 인공지능 모델 / 인공지능 소프트웨어 / 인공지능 시스템 용어 구분 혼동 주의: 모델(학습 결과) ⊂ 소프트웨어(모델 사용) ⊂ 시스템(소프트웨어+하드웨어+센서+클라우드 등으로 목적 달성). 똑똑 형성 평가 5번이 이 혼동을 노림. (p.309, p.343)
