# 패턴 — 동기 유발·발문·활동 (지도서 전 단원에서 뽑음)

각 패턴 아래 예는 원문 인용이고 괄호 안은 ch 파일이다. 자세한 차시 흐름은 각 ch 파일의 "수업 흐름", 발문 전체는 "발문 모음" 표를 본다.

---

## 1. 도입–전개–정리 공통 틀 (차시별 지도 계획에서 반복되는 형식)

지도서의 차시별 지도 계획(대단원 앞쪽, 예: p.54~59, p.174~191, p.296~303)은 거의 모든 차시가 같은 틀이다.

| 단계 | 지도서가 반복하는 내용 | 활동지로 옮기면 (제안) |
|---|---|---|
| **도입** | ① 전시 학습 확인 `[지난 차시 주제]` ② 생각의 씨앗 심기(중단원 첫 차시) 또는 새싹 틔우기(소단원 첫 차시)로 동기 유발 ③ 학습 목표 제시 ④ 유의점: "자유롭게 이야기", "구체적 사례 제시", "발문으로 사고 유도" | 복습 1문항 → 만화/상황 + 제목 발문 → 오늘의 목표 |
| **전개** | ➊ 개념 설명(정의 → 실생활 사례) ➋ 구성 요소·원리 설명 또는 실습 따라 하기 ➌ `(활동으로 쑥쑥 N)` 또는 실습·프로젝트 ➍(있으면) 모둠 조사·토의·발표. 유의점: 학생 경험 기기부터 시작해 다른 사례로 확장, 일찍 끝낸 학생에게 추가 사례 | 개념 빈칸 → 분류·순서 활동 → 교과서 활동 변형 → (심화) 활동 플러스·선택 활동 |
| **정리** | 모둠 발표 공유·피드백 → 핵심 개념 정리 → 형성 평가 → "다음 차시를 예고한다" | 핵심 정리 빈칸 → 형성 평가 O/X·고르기 → 한 줄 성찰 |

- 2차시 묶음(예: Ⅳ 2~3차시, Ⅴ 전부)은 한 표에 도입–전개–정리가 한 번만 있다. ch10·ch11은 차시 나누는 안을 (제안)으로 덧붙였다.
- 프로그래밍·AI 실습 차시는 도입에서 **완성 결과물을 먼저 시연**한다(골든벨·장애물 게임·바닷속 게임, 티처블 머신 가위바위보).

| 유형 | 형식 | 대표 예 (원문) |
|---|---|---|
| **새싹 제목 발문** | "~은 무엇인가요? / 어떻게 ~할까요? / 왜 ~할까요? / ~을 알아볼까요?" | "다양한 컴퓨팅 시스템을 알아볼까요?" · "디지털 데이터가 뭐예요?" · "데이터 분석은 왜 하나요?" · "어떻게 하면 문제를 잘 해결할까요?" · "수많은 데이터, 어떻게 처리할까요?" · "인공지능은 어떻게 학습할까요?" · "디지털 윤리는 왜 중요할까요?" |

| **가치 판단·토론** | "장점/주의할 점, 논리적 근거" | "디지털 데이터 사용했을 때 편리한 점과 주의해야 할 점에는 무엇이 있는지 친구들과 토론해 보자."(ch03) · "친구와 의견이 다른 경우 자신의 의견이 타당함을 논리적인 근거를 가지고 주장해 보자."(ch09) |
| **자기 점검 체크** | 예/아니요 질문 목록 | "데이터로 해결할 수 있는 문제인가?" · "출처가 명확하고 신뢰할 수 있는 데이터인가?"(ch04) |

**발문 쓰는 요령 (지도서에서 반복되는 것, 제안 포함)**
- 도입 발문은 **학생 경험 기기·생활**에서 시작하고(스마트폰, 용돈, 급식, 축제), 전개에서 **사회·산업 사례**로 넓힌다.
- 활동 지시문은 거의 모두 "~해 보자."로 끝난다. 하위 질문은 2~3개 단계로 쪼갠다(AI 스피커: "일반 스피커와의 차이점은 무엇일까?" → "어떤 데이터로 학습되었을까?" → "우리 생활에서 어떤 도움을 받을 수 있을까?").
- 지도서 유의점 문장("~생각해 보도록 한다")은 그대로 발문으로 바꿀 수 있다 — ch 파일 발문 표에 (제안)으로 표시되어 있다.

## 5. 형성 평가·정리 패턴

- **형성 평가**(소단원 끝, 지도서 여백): 빈칸 1~3, O/X 2~5, 선 잇기, 짧은 서술. 정답은 각 ch 파일 "형성 평가" 절.
- **중단원 마무리**: 마인드 맵 빈칸(Ⅰ·Ⅱ·Ⅲ-1·Ⅴ), 주사위 보드게임(Ⅲ-3 — 뒤로 가는 칸이 "알고리즘 오류·프로그램 오류·목표와 다른 프로그램"), 짝끼리 용어 설명하기.
- **쏙쏙 요약 정리**: 중단원별 완성형 요약(일부 빈칸). 활동지 KEY_SUMMARY 빈칸으로 바로 쓸 수 있다(굵은 글씨 = 정답 낱말).
- **똑똑 형성 평가**: 빈칸 + O/X + 선택형. CHECK_UP 카드 재료.
- **대단원 마무리**: 선다·단답·코드 읽기·서술. 정답은 그림 체크 표시로 확인해 부록에 적었다.

## middle school info 활동지 카드 대응

`middle school info` 저장소의 4탭 활동지(`lessons/<단원>/<차시>/spec.md`)는 `도입 WARM_UP · TODAY_TOPIC → 전개 ACTIVITY_1~4 → 정리 KEY_SUMMARY · CHECK_UP` 카드로 짜여 있다. 지도서 장치와 대응시키면 다음과 같다 (제안).

| 활동지 카드 | 지도서에서 가져올 것 | 어디서 |
|---|---|---|
| `도입` WARM_UP | 새싹 틔우기 만화·제목 발문, 생각의 씨앗 심기 Q, 지도서 "인공지능 엿보기"·실물 시연, 체험 사이트 | ch 파일 "동기 유발", "중단원 도입" |
| `도입` TODAY_TOPIC | 차시 학습 목표 원문을 학생 말투로 / 씨앗 심기 Q | "수업 흐름"의 학습 목표 |
| `전개` ACTIVITY_1 | 전개 ➊ 개념: 본문 정의 → 빈칸, 보조단 용어 | "전개 — 본문 흐름과 핵심 개념" |
| `전개` ACTIVITY_2 | 전개 ➋ 분류·순서: 활동 플러스, 구별하기, 순서도·과정 단계 → 이름표 끌어 놓기·순서 배열 | "활동", 지도서 "활동 플러스" |
| `전개` ACTIVITY_3 | 활동으로 쑥쑥·실습·프로젝트(외부 도구 열기 버튼 + 결과 캡처 붙여넣기) | "활동" — 단계 지시문 원문, 예시 답 |
| `전개` ACTIVITY_4 | 선택 활동·심화·가치 판단 토의 / 수행 평가 활동지 양식 | "활동", `uN-appendix` 수행 평가 활동지 |
