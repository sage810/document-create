## Ⅰ-1 컴퓨팅 시스템의 구성과 동작 (ch01)
- **컴퓨팅** — 컴퓨터로 정보를 처리해 필요한 일을 해결하는 과정 (p.62)
- **컴퓨팅 시스템** — 사용자가 원하는 일을 처리하도록 하드웨어와 소프트웨어로 구성된 도구 (p.62)
- **하드웨어 / 소프트웨어** — 만질 수 있는 물리적 전자 장치 / 하드웨어로 특정 작업을 수행하는 프로그램의 모음 (p.62)
- **시스템 소프트웨어 / 응용 소프트웨어** — 하드웨어 제어·실행 환경 제공(운영체제, 드라이버) / 목적에 따른 작업(워드 프로세서, 웹 브라우저) (p.64~65)
- **드라이버 / 펌웨어** — 운영체제와 하드웨어 사이 입출력 제어 SW / 하드웨어에 내장되어 동작을 관리하는 SW (p.64, p.68)
- **클라우드 컴퓨팅** — 인터넷으로 컴퓨팅 자원을 제공하는 기술 (p.62)
- **CPU / GPU** — 인출·해석·실행을 반복하는 처리 장치 / 많은 코어로 그래픽을 병렬 처리 (p.64)
- **RAM / HDD·SSD** — 빠르지만 휘발성인 주기억 장치 / 비휘발성 보조 기억 장치(자기장 / 반도체) (p.65)
- **부팅 / BIOS** — 전원을 켠 뒤 사용 가능 상태까지의 과정 / 맨 처음 실행되어 하드웨어를 검사하는 프로그램 (p.66)
- **무어의 법칙** — 트랜지스터 수가 18~24개월마다 2배 (p.61)
- **운영체제(OS)** — 사용자와 시스템의 상호 작용을 돕는 대표적 시스템 SW (p.68)
- **CLI / GUI / NUI** — 명령어 입력 / 그래픽 선택 / 행동·음성 입력 인터페이스 (p.69)
- **프로세스 / 좀비 프로세스** — 실행되어 메모리에 올라간 프로그램 / 종료되지 않는 비정상 프로세스 (p.65~66)
- **CPU 스케줄링** — 프로세스 실행 순서를 정하는 방법(FIFO·우선순위·라운드로빈·SJF) (p.69)
- **가상 메모리 / 가상 머신** — 디스크 일부를 메모리처럼 사용 / OS 위에서 다른 OS 실행 (p.70, p.68)
- **오픈 소스** — 소스 코드를 누구나 읽고 수정·공유 (p.72)
