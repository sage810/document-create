# 빠른 참조표 — 수준 판정·가르는 말·세특 연결

(정리) = 원문을 표로 재구성, (제안) = 원문에 없는 판단 규칙. 원문 문장 전체는 각 영역 장(ch02~ch06)에 있다.

## 1. 수준 사다리 — 세 범주의 표지 (정리, 25개 성취기준 공통 경향)
| 범주 | A | B | C | D | E |
|---|---|---|---|---|---|
| 지식·이해 | 깊이를 더한 설명: 관련지어 / 구체적인 예시를 통해 / 단계별로 / 절차적으로 / 작동 방식까지 | A와 같은 설명이 많음 | 설명 | 설명 | **인지** |
| 과정·기능 | 목적 적합 + 효율: 문제 해결 목적에 맞게 / 적합한 / 효율적으로 / 정확하게 / 명확하게 / 체계적으로 + **설명**(동작·장단점·해결 방식) | 같은 활동, 목적어·수식어·설명이 빠짐 | 같은 활동 | 부분적으로 / 일부 / 단일 / 구분 / 탐색 / 구현 / 발견만 | D와 같은 활동, 범위가 더 좁음 |
| 가치·태도 | **내면화** | 인식 (가질 수 있다) | 인식 | **수용** / 공감 / 형성 | 수용 / 공감 / 형성 |
| 성취율 (표 Ⅰ-1) | 90% 이상 | 80~90% | 70~80% | 60~70% | 40~60% |

- **판정 규칙 (제안)**
  - 지식 표지만 보고 E인지 아닌지 가른다. "인지" 수준이면 E다.
  - 기능 표지로 D 이하와 C 이상을 가른다. "부분적으로", "일부", "단일", "구분" 수준이면 D 이하다.
  - "설명", "적합한", "효율적으로"로 A·B와 C를 가른다.
  - 가치·태도는 관찰 행동으로 판단한다. 스스로 기준을 세워 지속하면 내면화, 필요성을 말하면 인식, 받아들이거나 공감하면 수용·공감이다.
- **AB가 같은 낱말일 때**: 대부분 B는 A에서 수식어 하나(효율적으로, 적합한, 정확하게)나 덧붙인 설명 하나가 빠진다. 그 하나를 평가 문항이 확인하게 만든다(예: 정보-6 문항 3).

## 3. 평가 설계 결정 규칙 (원문 근거 + 제안)
| 상황 | 할 일 | 근거 |
|---|---|---|
| 한 학기 평가 계획을 짤 때 | 도구별 목표 수준을 섞어 A~E가 모두 갈리게 한다 | "모든 성취수준(A~E)을 평가할 수 있도록" (p.24) |
| 문항 하나로 A/B를 가르고 싶을 때 | A만 가진 말(위 2절)을 확인하는 하위 문항을 따로 둔다 | 정보-6 "A를 달성하기 위해서는 문항 3번을 정확하게" (p.72) |
| 답이 열린 서술(의견·해결 방안) | 질 판단 척도 + 구술 보충 | 정보-8 고려 사항 (p.93) |
| 디지털 도구·AI 사용 허용 | 같은 조건 보장, 복사·붙여넣기는 0점 | 정보-8 (p.93) |
| 블록 코딩 기준 문항을 텍스트 언어로 | 그 환경의 문법을 충분히 가르친 뒤 같은 기준 준용 | 정보-6·7 (p.77, 84) |
| 가치·태도가 성취기준에 없음 | 영역별 성취수준의 가치·태도 칸으로 평가 요소를 보탠다 | 개발 절차 ② (p.8) |
| 학기 결과를 진술할 때 | 학기 단위 성취수준 문장을 중심으로 학생이 실제 한 일을 쓴다 | p.24 |
| 못 푼 학생 | 개념 재확인 → 쉬운 실생활 예시 → 비슷한 사례 직접 찾기 | 각 도구 개발 방향 칸 |

## 4. 교과세특(info writing helper)과의 연결 (제안)
| 세특 요소 | 이 지식 베이스에서 가져올 것 |
|---|---|
| 파랑 (성취수준) | 학생 수준의 성취기준별 성취수준 문장에서 **가르는 말**만 살려 "~함"으로. 2015 상·중·하 대신 이 A~E 문장을 쓴다 |
| 초록 (수행 과정 및 결과) | 예시 도구의 **채점 요소**와 학생 답의 구체 내용(고른 기기, 고친 오류, 줄인 블록 수, 든 사례) |
| 빨강 (역량) | 영역별 성취수준의 **가치·태도** 칸 + 2022 교과 역량 이름(info-curriculum) |
| 검정 (교사 총평) | 학기 단위 성취수준(ch01)과 이어지는 수업 전체의 태도·변화 |

- **고칠 신호**
  - 파랑 문장이 성취수준 문장을 통째로 옮겼고 초록이 없다 → 기재 지침이 피하라는 "단순 서술"이다.
  - 인지할 수 있음, 부분적으로 구조화함처럼 하위 수준의 표지를 그대로 썼다 → 해낸 것을 구체적으로 다시 쓴다.
  - 문장에 수준 기호(A, B)나 성취율을 적었다 → 문장 속 차이(설명했는지, 적합하게 골랐는지)로 바꾼다.
