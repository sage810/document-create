# 용어집 — 가나다순

(chN, p.N) = 이 지식 베이스의 장, 원문 인쇄 쪽. "따옴표" = 원문 그대로.

- **가치·태도** — 내용 체계의 세 범주 중 하나. 수준은 "내면화와 실천과 참여 등으로" 구분한다. 성취기준 문장에 없어도 영역 안에서 반영한다 (ch00, p.7~8)
- **개발 방향 및 활용 시 고려사항** — 예시 도구 개요표의 칸. 무엇을 평가하는지, 목표 성취수준, 못 푼 학생을 위한 다음 단계를 적는다 (ch07)
- **고정분할점수** — 성취율 구간을 미리 정해 두고 성취도를 매기는 방식. 중학교는 고정분할점수를 적용한다 (ch01, p.24)
- **과정·기능** — 내용 체계의 세 범주 중 하나. 수준은 "수행 정도나 맥락과 상황 변인으로" 구분한다 (ch00, p.7)
- **기초학력 보장** — 성취수준 활용처 중 하나. 책임교육학년제(초3, 중1), 맞춤형 학업성취도 자율평가와 이어진다 (ch01, p.23)
- **내면화 · 인식 · 수용 · 공감 · 형성** — 성취수준 문장의 가치·태도 끝말. 대체로 A 내면화 → B·C 인식 → D·E 수용·공감·형성 (ch02~ch06, cheatsheet 1절)
- **목표 성취수준** — 예시 도구 개요표의 '성취수준' 칸(A~B, B~C, A~E, C 등). 그 문항이 주로 가르려는 수준 (ch07)
- **서·논술형 / 실험·실습** — 예시 평가 도구의 유형. 10개 중 서·논술형 8개, 실험·실습 2개 (ch07, p.48~49)
- **서술 조건** — 서술형 문항 아래 미리 주는 조건(㉠㉡㉢). 채점은 충족 개수로 한다 (ch06 정보-9)
- **성취기준** — 학생들이 영역별 내용 요소를 "학습한 결과 궁극적으로 할 수 있거나 할 수 있기를 기대하는 도달점"을 진술한 것 (ch00, p.3)
- **성취기준별 성취수준** — "성취기준 단위 성취수준". 중학교 정보는 25개 성취기준마다 A~E 다섯 문장 (ch00, p.3 / ch02~ch06)
- **성취수준** — "학생들이 각 교과목 성취기준(들)에 도달한 정도를 나타낸 것". 수준마다 "무엇을 알고 할 수 있는지를 기술" (ch00, p.3)
- **성취수준 구분의 원리** — 지식은 개념 위계와 이해의 깊이, 기능은 수행 정도와 맥락·상황, 태도는 내면화와 실천·참여로 수준을 나눈다 (ch00, p.7)
- **성취율** — 지필평가와 수행평가 점수를 합산한 비율. 5수준 기준 A 90% 이상, B 80%, C 70%, D 60%, E 40% 이상 (ch00, p.4 / ch01, p.24)
- **성취평가제** — 학기별 성취도를 성취수준에 따라 평정하는 제도. 학기 단위 성취수준이 그 근거가 된다 (ch01, p.22)
- **수행 특성** — 채점 기준표에서 점수(척도)마다 적은 진술문. 예: "명칭을 6개 이상 정확하게 기록하였다" (ch00, p.14 / ch07)
- **영역별 성취수준** — "영역 단위 성취수준". 영역 안 성취기준들을 포괄해 수준마다 지식·이해, 과정·기능, 가치·태도로 진술 (ch00, p.3, p.10~11 / ch02~ch06)
- **예시 답안** — 채점 기준 개발 ④단계. 예시 도구는 만점뿐 아니라 1점·0점 예시도 준다 (ch00, p.14 / ch07)
- **인지** — 성취수준 문장에서 지식·이해의 가장 낮은 표지(E). "개념을 인지하고", "존재함을 인지하고" (cheatsheet 1절)
- **지식 전이** — 일반적 특성 표의 지식·이해 기준. A "매우 높음" → B "높은 편" → C "보통" (ch00, p.4~5)
- **지식·이해** — 내용 체계의 세 범주 중 하나. 수준은 "개념 위계나 이해의 깊이"로 구분한다 (ch00, p.7)
- **채점 시 고려 사항** — 채점 기준 개발 ⑤단계. "유사 정답, 부분 점수 등" (ch00, p.14 / ch02~ch06 각 도구)
- **채점 요소** — 평가 요소를 채점용으로 압축한 이름. 예: "오류 발견 및 디버깅", "활용 가치 설명" (ch00, p.14)
- **책임교육학년제** — 초3·중1에 학력 진단과 지원을 강화하는 제도. 성취수준 기반 개별화 학습과 이어진다 (ch01, p.23)
- **척도(점수)** — 채점 요소별 점수 계단. "성취수준 단계에 따른 수행 정도 차이를 고려하여" 정한다 (ch00, p.14 / ch07 2절)
- **최소한의 성취기준** — 기초학력 진단과 지원에 쓰는 성취기준. 국어·수학·사회·과학·영어에만 있다 (ch01, p.23)
- **평가 과제** — 학생에게 주는 수행 과제의 이름. 예: "이동 경로를 추상화하여 다이어그램으로 나타내고, 문제 해결 알고리즘으로 해법 찾기" (ch07)
- **평가 요소** — "교육과정 성취기준 도달의 증거로 학생들이 보여주기를 기대하는 핵심 내용을 구체적으로 기술한 평가 내용" (ch01, p.23)
- **피드백** — "학생의 학습 상태에 대한 정보를 제공하여 학생의 학습과 성장을 지원하는 전체적인 과정". 준거는 성취수준과 채점 요소별 수행 특성 (ch00, p.14 / ch01, p.24)
- **학기 단위 성취수준** — 한 학기 성취기준들에 도달한 정도를 포괄해 A~E로 진술한 것. 수업·평가·기록의 준거 (ch01, p.22)
- **3수준 / 5수준** — 성취수준 체계. 중학교 정보는 5수준(ABCDE), 3수준(ABC)은 일부 과목의 성취기준별 성취수준에 쓴다 (ch00, p.4~6, p.9)
