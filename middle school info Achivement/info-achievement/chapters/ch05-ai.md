# Ch05: (4) 인공지능 — 성취수준과 예시 평가 도구 (인쇄 p.35~36, 45~46, 87~93)

## 핵심
성취기준 5개([9정04-01]~[9정04-05])의 A~E와 영역별 성취수준을 담았다. 이 영역에서 A를 가르는 말은 이렇다. **"구체적인 예시를 통해"** 설명하는가, **"차이점을 설명"**하는가, **"학습에 적합한 방식으로"** 분류하는가, **"절차적으로"** 설명하는가, **"문제 해결 상황에 적합한"** 시스템인가, 의견을 **"논리적으로 개진"**하는가. 윤리 성취기준([9정04-05])의 가치·태도는 끝말이 내면화 → 인식 → 공감이다. 예시 평가 도구는 정보-8(서·논술형, A~B) 하나다.

### [9정04-01] 인공지능의 개념과 특성을 설명하고 인공지능 소프트웨어를 구별한다.

| 수준 | 성취기준별 성취수준 (원문) |
|---|---|
| A | 인공지능의 개념과 특성을 구체적인 예시를 통해 설명하고, 인공지능과 인공지능이 아닌 소프트웨어를 구별하고 차이점을 설명할 수 있다. |
| B | 인공지능의 개념과 특성을 구체적인 예시를 통해 설명하고, 인공지능과 인공지능이 아닌 소프트웨어를 구별할 수 있다. |
| C | 인공지능의 개념과 특성을 설명하고, 인공지능과 인공지능이 아닌 소프트웨어를 구별할 수 있다. |
| D | 인공지능의 개념과 특성을 설명하고, 인공지능 소프트웨어를 인식할 수 있다. |
| E | 인공지능의 개념과 특성을 인지하고, 인공지능 소프트웨어를 인식할 수 있다. |

- **수준을 가르는 말 (정리)**: 지식은 "구체적인 예시를 통해" 설명(A·B) → 설명(C·D) → "인지"(E). 기능은 인공지능과 아닌 소프트웨어를 구별하고 **"차이점을 설명"**(A) → "구별"(B·C) → 인공지능 소프트웨어를 "인식"(D·E).

- **문항** (보고서 형식): 1. 사례 수집: AI 개발·사용에서 데이터 수집·활용 문제가 생긴 사례와 출처를 쓴다. 2. 사례 분석: 자료 수집에서 생긴 문제와 활용에서 생긴 문제를 요약하고 자기 의견을 쓴다. 3. 해결 방안 구상: 읽기 자료(SNS 얼굴 사진을 동의 없이 대량 수집한 안면 인식 기업 기사)의 문제에 대한 해결 방안을 쓴다. 각 칸에 "행동의 주체"와 문제·해결 방법이 드러나게 쓰라는 안내가 붙는다.
- **채점 기준**

  | 문항 | 채점 요소 | 척도 |
  |---|---|---|
  | 서1 | 사례 수집 | 2: AI 관련 사례 + 출처 올바름 / 1: 출처는 맞으나 AI와 관련성 적음 / 0: 출처 없음, 수집 방법만 씀 |
  | 서2 | 사례 분석 | 3: 문제점을 구체적으로 설명하고 의견을 논리적으로 / 2: 설명하고 의견 일부 / 1: 문제점 불명확, 논리 미흡 / 0: 둘 다 불명확 |
  | 서3 | 윤리적 문제 해결 방안 구상 | 3: 문제 상황을 정확히 파악하고 방안을 논리적으로 / 2: 일부 파악하고 논리적으로 / 1: 일부 파악했으나 논리 미흡 / 0: 못 함 |

- **1점 예시 답안이 보여 주는 것 (정리)**: "충분한 보상을 한다면 데이터를 수집하고 활용할 수 있도록 해야 한다"는 1점이다. 동의 없는 수집이라는 핵심 문제를 비켜 간 해결 방안은 논리 미흡으로 본다. 2점 예시는 동의 없는 수집을 문제로 짚고, 법적 방안과 가이드라인에 따른 시스템 선택을 제시했다.
- **채점 시 고려 사항**
  - 디지털 도구를 쓰게 할 수 있으나 모든 학생이 같은 조건에서 쓰게 한다. "검색이나 인공지능 서비스의 결과를 단순히 복사하여 붙여넣는 행위는 점수를 부여하지 않도록 한다."
  - 문제 발견과 해결 방안은 주관적일 수 있으므로, 판단이 어려우면 "구술 형태로 보충하여 평가에 반영"할 수 있다.
- **피드백**: 다양한 윤리 문제 사례를 안내하고 주변 학생과 논의해 문제점을 충분히 인식하게 한다.
- **수준과의 연결 (정리)**: 서2·서3의 "논리적으로"가 성취수준 A·B의 "자신의 의견을 논리적으로 개진"에 대응한다. C 이하는 "구체적인 해결 방안"까지만 요구한다.

## 세특·평가에 쓰기 (제안)
- **[9정04-01]~[9정04-04]는 예시 도구가 없다.** 성취수준 표의 가르는 말로 채점 요소를 만든다. 예: [9정04-02] A는 수집한 데이터를 '학습에 적합한 방식으로' 분류했는지 → 클래스별 개수 균형, 레이블 기준을 채점 요소로 삼는다(ch03 정보-4의 소재와 이어짐).
- **초록(수행) 재료**: 구별한 소프트웨어와 그 근거, 수집한 데이터의 종류와 개수, 만든 모델의 정확도를 높이려고 바꾼 것, 찾은 윤리 사례와 출처
- **가치·태도 끝말 고르기**: 관찰한 행동이 '스스로 기준을 세워 지킴'이면 내면화, '필요하다고 말함'이면 인식, '사례에 공감함'이면 공감에 가깝다. 세특에는 이 끝말 대신 관찰한 행동을 쓴다.
