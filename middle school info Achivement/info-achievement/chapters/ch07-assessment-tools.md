# Ch07: 예시 평가 도구 개관 (Ⅲ장 3절, 인쇄 p.48~102)

## 핵심
예시 평가 도구는 10개다. 서·논술형 8개, 실험·실습 2개다. 모든 도구가 같은 틀을 따른다. 개요표(성취기준과 A~E 문장, 평가 과제, 평가 요소, 유형, **목표 성취수준**, 배점, 개발 방향) → 평가 도구(문항) → 채점 기준표(문항·채점 요소·척도·수행 특성·예시 답안) → 채점 시 고려 사항 → 예시 답안 순서다. 목표 성취수준이 A~E 전부인 도구는 2개뿐이고, 나머지는 A~B, B~C, C로 좁혀 놓았다.

## 3. 도구들이 공통으로 지키는 것 (정리)
- **목표 수준을 미리 밝힌다**: "성취수준 A와 B를 고려하여 출제한 문항으로, 이 문항을 맞힌 학생들은 …할 수 있다"는 문장이 개발 방향 칸에 거의 다 있다.
- **못 푼 학생을 위한 다음 단계를 적는다**: 개발 방향 칸 끝에 "정답을 맞히지 못한 학생들을 위해 …" 같은 피드백 방안이 들어 있다.
- **텍스트 언어로 바꿔 쓸 길을 열어 둔다**: 정보-6·7은 블록 코딩 기준이지만 "텍스트 기반의 프로그래밍 환경"에서도 준용할 수 있다고 적었다.
- **복사·붙여넣기를 막는다**: 정보-8은 검색·AI 서비스 결과를 단순히 붙여넣으면 점수를 주지 않고, 필요하면 구술로 확인한다.
- **0점·1점 예시 답안을 준다**: 어떤 답이 왜 낮은 점수인지 보여 준다(정보-2 엘리베이터, 정보-8 보상 논리).

## Worked Example — 예시 도구가 없는 [9정03-06]에 도구 만들기 (제안)
같은 틀(정보-6·7)을 따라 만든다.
1. **목표 수준**: A~B. 가르는 말은 "작동 방식"(지식)과 "동작을 설명"(기능)이다.
2. **평가 요소**: ① 논리 연산과 중첩 제어 구조로 문제 해결 프로그램 작성하기 ② 프로그램의 동작 설명하기
3. **문항**: 1. 조건 두 개를 and/or로 묶는 프로그램 작성(예: 출입 가능 시간 판정) 2. 중첩 if로 등급을 나누는 프로그램 작성 3. 입력값 세 개를 주고 실행 경로와 출력을 표로 추적
4. **채점**: 수1·수2는 작동 + 효율 꼴(실행 2점, 조건 중복 없음 +1점). 수3은 정보-6 문항 3처럼 정확히 추적하면 2점, 일부 오류 1점. 문항 3이 A/B를 가른다.
5. **피드백**: 틀린 입력값에서 실행 경로를 함께 따라가는 활동지를 준다.
