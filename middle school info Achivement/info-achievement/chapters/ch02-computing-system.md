# Ch02: (1) 컴퓨팅 시스템 — 성취수준과 예시 평가 도구 (인쇄 p.27~28, 39~40, 50~57)

## 핵심
성취기준 3개([9정01-01]~[9정01-03])의 A~E와 영역별 성취수준을 담았다. 지식은 관련지어 설명·구성 방식까지 설명 → 설명 → 인지 순서로 내려간다. 기능은 분석하여 효율적으로 활용·조사하고 분석·구성하고 개선 → 분석·조사·구성 → 구분·예시 탐구로 내려간다. 예시 평가 도구는 정보-1(서·논술형, A~B)과 정보-2(서·논술형, B~C)다.

- **수준을 가르는 말 (정리)**: 지식은 운영 체제 기능과 "관련지어 설명"(A·B) → "설명"(C·D) → "인지"(E). 기능은 "분석하여 효율적으로 활용"(A) → "분석"(B·C) → "구분"(D·E). 가치·태도 표현은 없다.

| B | 피지컬 컴퓨팅의 개념과 구성 방식을 설명하고, 생활 속 피지컬 컴퓨팅 사례를 조사하여 컴퓨팅 시스템의 필요성과 가치를 인식할 수 있다. |

| E | 피지컬 컴퓨팅의 개념을 인지하고, 생활 속 피지컬 컴퓨팅 예시를 탐구하여 컴퓨팅 시스템의 필요성을 수용할 수 있다. |

- **수준을 가르는 말 (정리)**: 지식은 "개념과 구성 방식"(A·B) → "개념"(C·D) → 개념 "인지"(E). 기능은 사례를 "조사하고 분석"(A) → "사례를 조사"(B·C) → "예시를 탐구"(D·E). 가치·태도는 필요성과 가치를 "판단하고 내면화"(A) → "인식"(B·C) → 필요성만 "수용"(D·E).

### [9정01-03] 문제 해결 목적에 맞는 피지컬 컴퓨팅 구성요소를 선택하여 시스템을 구상한다.

| 수준 | 성취기준별 성취수준 (원문) |
|---|---|
| A | 문제 해결 목적에 맞는 피지컬 컴퓨팅 구성요소를 선택하여 시스템을 구성하고 개선하는 과정을 통해 피지컬 컴퓨팅 시스템의 구성요소를 목적에 맞게 선택하는 유연한 태도를 인식할 수 있다. |
| B | 문제 해결 목적에 맞는 피지컬 컴퓨팅 구성요소를 선택하여 시스템을 구성하고 개선하는 과정을 통해 피지컬 컴퓨팅 시스템의 구성요소를 목적에 맞게 선택하는 유연한 태도를 인식할 수 있다. |
| C | 문제 해결 목적에 맞는 피지컬 컴퓨팅 구성요소를 선택하고 시스템을 구성하는 과정을 통해 피지컬 컴퓨팅 시스템의 구성요소를 목적에 맞게 선택하는 유연한 태도를 인식할 수 있다. |
| D | 문제 해결 목적에 맞는 피지컬 컴퓨팅 구성요소를 선택하고 시스템을 구성하는 과정을 통해 피지컬 컴퓨팅 시스템의 구성요소를 목적에 맞게 선택하는 유연한 태도를 인식할 수 있다. |
| E | 문제 해결 목적에 맞는 피지컬 컴퓨팅 구성요소를 구분하는 과정을 통해 피지컬 컴퓨팅 시스템의 구성요소를 목적에 맞게 선택하는 유연한 태도를 수용할 수 있다. |

- **수준을 가르는 말 (정리)**: 기능은 "선택하여 시스템을 구성하고 개선"(A·B) → "선택하고 시스템을 구성"(C·D) → 구성요소를 "구분"(E). 가치·태도는 유연한 태도를 "인식"(A~D) → "수용"(E).
- ⚠ **원문 그대로 A와 B, C와 D가 글자까지 같다.** 지도서(info-guide ch00 5절)도 같은 문장을 옮겨 원문 오류 의심으로 적었다. 학교에서 A/B, C/D를 가를 기준을 따로 정해야 한다. 예를 들어 개선의 근거(왜 그 부품을 바꿨는지)를 설명하면 A, 개선은 했으나 근거가 없으면 B로 가를 수 있다. (제안)

- **읽는 법 (정리)**: 영역별 A는 세 성취기준의 A를 합친 모습이다(관련지어 설명 + 효율적으로 활용 + 구성하고 개선 + 내면화). 가치·태도 칸은 [9정01-01]에 없던 "컴퓨팅 시스템의 필요성과 가치"를 영역 전체에서 다룬다.

## 예시 평가 도구

### 정보-1: 컴퓨팅 시스템의 구성요소 파악 (p.50~53)
- **성취기준** [9정01-01] | **유형** 서·논술형 | **목표 성취수준** A~B | **배점** 6점
- **평가 과제**: 컴퓨팅 시스템의 구성요소를 파악하여 동작 원리 설명하기
- **문항** (스마트폰 그림): 1. 구성요소의 명칭 쓰기 / 2. 하드웨어와 소프트웨어로 구분하기 / 3. 역할과 동작 원리 설명하기
- **채점 기준**

  | 문항 | 채점 요소 | 2점 | 1점 | 0점 |
  |---|---|---|---|---|
  | 서1 | 컴퓨팅 시스템 구성요소 분석 | 명칭 6개 이상 정확 | 4개 이상 | 절반 이상 못 함 |
  | 서2 | 하드웨어/소프트웨어 구분 | 6개 이상 명확 | 4개 이상 | 절반 이상 못 함 |
  | 서3 | 역할 및 동작 원리 설명 | 6개 이상 적절 | 4개 이상 | 절반 이상 못 함 |

- **예시 답안**: 카메라, 볼륨 버튼, 전원 버튼, 충전 단자, 디스플레이(하드웨어) / 사진 앱, 계산기 앱(소프트웨어)
- **채점 시 고려 사항**: 기종마다 다른 기능은 빼고 공통으로 적용되는 기능과 동작 원리로 채점한다. "일반적인 명칭으로 구분할 수 있다면 정답과 비슷한 답안도 답으로 인정한다."
- **피드백**: 맞히지 못한 학생에게는 구성요소를 하드웨어와 소프트웨어로 나누어 설명하고 실생활 컴퓨팅 시스템 사례로 이해를 돕는다.
- **수준과의 연결 (정리)**: 이 문항을 맞히면 구성요소와 동작 원리를 "관련지어 설명"할 수 있다고 본다(A·B). 운영 체제 기능의 '분석·활용'은 이 문항에서 평가하지 않는다. A/B를 끝까지 가르려면 운영 체제 과제를 더한다. (제안)

### 정보-2: 생활 속 피지컬 컴퓨팅 사례 분석 (p.54~57)
- **성취기준** [9정01-02] | **유형** 서·논술형 | **목표 성취수준** B~C | **배점** 5점
- **평가 과제**: 생활 속 피지컬 컴퓨팅 사례를 조사하고 피지컬 컴퓨팅 시스템의 구성과 문제 해결 방식 분석하기
- **문항**: 생활 속 피지컬 컴퓨팅 시스템을 하나 찾아 입력·처리·출력·활용 가치를 표에 쓴다. 문항에 디지털 도어록 예시가 주어진다.
- **채점 기준**

  | 문항 | 채점 요소 | 척도 |
  |---|---|---|
  | 서1 | 구성요소 분석 | 3점: 구성과 문제 해결 방식을 모두 적절하게 분석 / 2점: 입력·처리·출력 중 2가지 / 1점: 1가지 / 0점: 발견 못 함, 분석 못 함 |
  | 서2 | 활용 가치 설명 | 2점: 활용 장점 설명 + "필요성과 가치를 내면화" / 1점: 장점만 설명 / 0점: 설명 못 함, 장점을 수용하지 않음 |

- **예시 답안**: 엘리베이터. 입력은 버튼과 층 감지 센서, 처리는 프로세서가 이동 방향과 경로를 정함, 출력은 모터가 문을 여닫고 이동함. 활용 가치는 효율적 이동 알고리즘으로 대기 시간이 줄고, 사용 데이터로 사용 방법을 개선할 수 있다는 것이다.
- **0점 예시가 보여 주는 것 (정리)**: "엘리베이터를 이용하면 걸을 때보다 빠르게 이동할 수 있다"는 0점 예시다. 기계 자체의 장점은 점수가 없다. **컴퓨팅 시스템(입력·처리·출력과 데이터 활용) 덕분에 생기는 장점**을 써야 점수를 받는다.
- **채점 시 고려 사항**: 활용 가치는 "장점과 가치를 논리적으로 설명하는지를 중심으로" 평가한다.
- **피드백**: 개념과 구성 방식을 다시 확인하고, 피지컬 컴퓨팅으로 문제를 해결하는 과정을 설명하는 예시 자료를 만들어 준다.

## 세특·평가에 쓰기 (제안)
- **파랑(성취수준) 재료**: [9정01-01] A의 "관련지어 설명하고 … 효율적으로 활용", [9정01-02] A의 "조사하고 분석하여 … 판단". 그대로 붙이면 성취기준 지식의 단순 서술이 되므로 학생이 실제로 분석한 기기와 결과를 초록 문장으로 붙인다.
- **초록(수행) 재료**: 정보-2 표의 입력·처리·출력 칸. 예(지어낸 문장): ‘엘리베이터의 층 감지 센서와 호출 버튼을 입력으로, 이동 방향 결정을 처리로 분석함’
- **[9정01-03] A/B 동일 문제**: 세특 문장에서는 A·B 같은 기호 대신, 학생이 '개선'의 근거를 말했는지를 관찰 사실로 적어 차이를 드러낸다.
