# ch08 선택 중심 교육과정 — 설계의 개요 (고등학교 정보 교과 과목 구조) (PDF p.18~22)

## 한눈에
고등학교 정보 교과는 **일반 선택 「정보」** 1개, **진로 선택 「인공지능 기초」「데이터 과학」「정보과학」** 3개, **융합 선택 「소프트웨어와 생활」** 1개로 되어 있다. 고등 「정보」는 **중학교 「정보」와 같은 영역**으로 짜여 일관성을 유지하면서 진로 선택 과목의 기초 공통이 된다. 교과 역량·구성 체계 문장은 공통 교육과정 개요와 거의 같고, 차이는 **과목·진로 연계**에 맞춘 표현에 있다.

## 1. 과목 구성 (p.21, 원문을 표로)

| 구분 | 과목 | 구성 근거 (원문) |
|---|---|---|
| 일반 선택 | **정보** | "중학교 '정보'와 동일한 영역으로 구성하여 일관성을 유지하면서, 진로 선택 과목의 기초 공통이 되도록 내용을 구성하였다." |
| 진로 선택 | **인공지능 기초** | "컴퓨터과학, 데이터 과학, 정보시스템 분야의 지식" |
| 진로 선택 | **데이터 과학** | "컴퓨터과학, 데이터 과학 분야의 기초 지식" |
| 진로 선택 | **정보과학** | "컴퓨터과학과 소프트웨어 공학 분야에 관한 지식" |
| 융합 선택 | **소프트웨어와 생활** | "다양한 학문 분야와의 융합을 통해 문제 해결을 경험할 수 있는 프로젝트 형태로 각 영역을 구성하였다." |

- 진로 선택 3과목: "과목의 성격과 학문적 기저를 고려하였다", "해당 내용이 필요한 진로와 연계될 수 있는 내용을 구성하였다."
- 과목 사이의 관계: "각 과목은 하나의 학문적 뿌리에서 분야와 지식의 깊이를 달리하여 병렬적으로 연계되면서도 각 과목을 통해 추구하는 능력이나 목표 역량은 차별성을 두었다."

```
초등 실과 '디지털 사회와 인공지능' 영역
        ↓
중학교 「정보」 (공통, 5개 영역)
        ↓ 같은 영역
고등 「정보」 (일반 선택) ── 진로 선택의 기초 공통
        ├─ 「인공지능 기초」  컴퓨터과학 + 데이터 과학 + 정보시스템
        ├─ 「데이터 과학」    컴퓨터과학 + 데이터 과학
        └─ 「정보과학」       컴퓨터과학 + 소프트웨어 공학
「소프트웨어와 생활」 (융합 선택) — 여러 학문 분야와 융합한 프로젝트형
```
(그림은 원문을 정리한 것. 중학교 「정보」가 "고등학교 정보 교과의 모든 과목과 연계성을 갖는다"는 문장은 [ch01](ch01-character-goals.md))

## 2. 과목별 핵심 아이디어와 내용 체계 범주 (p.21)
- 핵심 아이디어: "각 과목을 구성하고 있는 학문 분야의 기초 지식에 근거하여 학습자의 깊이 있는 학습을 도모하고, 학습의 전이를 통해 해당 내용이 필요한 진로와 연계되도록 선정하였다." 선정 기준(지식으로서의 중요성, 사회적 가치·유용성, 미래지향적 전이 효과)은 공통과 같다.
- 지식⋅이해: "구체적 지식 관점에서 핵심이 되는 내용"
- 과정⋅기능: 공통과 같음 — "탐구적 성향의 절차적 지식"
- 가치⋅태도: "인공지능, 데이터 과학 등 신기술 분야의 지식을 습득하는 과정에서 내면화되는 내용"

## 3. 교사에게 요구하는 것 (p.22, 원문)
- "정보 교과는 시대적으로 필요한 역량을 함양하는 교과인 만큼 학교 현장에서 교사는 학습자의 진로 진학과 연계되는 실천적 역량이 함양되도록 교육과정을 구성한다."
- "인공지능 기초나 데이터 과학 등의 내용이 많은 분야에 적용됨에 따라 해당 지식이 필요한 분야로 진학하는 학습자의 깊이 있는 학습을 도모한다."
- "모든 분야에서 소프트웨어와 인공지능이 필요한 만큼 소프트웨어와 생활 과목을 통해 학습자가 자신의 역량을 확장하고, 학습의 전이를 경험하여 삶의 주도성을 갖춘 인재로 성장할 수 있도록 한다."

## 4. 공통 교육과정 개요(p.4~6)와 다른 문장

| 항목 | 공통 「정보」 (p.4~6) | 선택 중심 (p.20~22) |
|---|---|---|
| 역량 이름 | "인공지능(AI) 소양" (p.4) | "인공지능 소양" |
| 컴퓨팅 사고력 정의 | "문제를 해결하기 위한 새로운 방법론을 제시할 수 있는 능력" | "문제를 해결하는 데 새로운 방법론을 제시할 수 있는 능력" |
| 컴퓨팅 사고력·인공지능 소양의 연계 | "역량과 연계된다" | "역량과 직접 연계된다" |
| 디지털 문화 소양 정의 | "의사 소통하고 협업할 수 있는 능력" | "의사 소통하고 협업하는 능력" |
| 성격 및 목표 | "과목에서 추구하는 목표를 구체화" | "각 선택 과목에서 추구하는 목표를 구체화" |
| 교수·학습, 평가 | "내용 체계에 기반한 성취기준을 달성하는 데 도움이 되는 … 원칙과 구체적 방법" | "교수⋅학습, 평가의 원칙 및 중점은 과목의 성격과 성취기준 달성에 도움이 되는 방법" |
| 영역 문단 | 5개 영역, 초등 실과 연계, 영역 사이 관계 | 과목 구성(일반·진로·융합 선택) |
| 핵심 아이디어 | 교과 역량을 고려한 영역 목표 달성, 학습의 전이 | 학문 분야의 기초 지식 근거, **진로 연계** |
| 지식⋅이해 | "교과 지식 중 핵심" | "구체적 지식 관점에서 핵심" |
| 가치⋅태도 | "디지털 사회의 핵심역량을 기르는 정보 교과의 전 과정을 통해 내면화" | "인공지능, 데이터 과학 등 신기술 분야의 지식을 습득하는 과정에서 내면화" |
| 교사 문단 | 성취기준 충실 달성, 디지털 역량 파악, 융합 설계 | 진로 진학 연계 실천적 역량, 진학자 깊이 있는 학습, 삶의 주도성 |
| 같은 문단 | 구성 체계 세 목표(선순환), 과정⋅기능 설명, 세 범주 연결 문장 | (같음) |

## 중학교 수업에서 쓰는 법 (제안)
- **진로 연계 수업 자료**: 디지털 문화 [9정05-01] 진로 탐색([ch06](ch06-digital-culture.md))에서 1절 표로 고교 과목을 소개한다. 「내가 좋았던 중학교 단원 → 이어지는 고교 과목」(데이터 단원 → 데이터 과학, AI 단원 → 인공지능 기초, 프로그래밍 단원 → 정보과학)을 잇는 칸을 둔다(영역↔과목 대응은 학문적 기저로 추정한 것).
- **수준 차이 대응**: 교수·학습 방향 (바)가 "상위 학년군의 성취기준"을 활용할 수 있다고 한다([ch07](ch07-teaching-assessment.md)). 앞서가는 학생의 심화 과제는 고등 「정보」 성취기준(PDF p.26~, 범위 밖)에서 고른다.
