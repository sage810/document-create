# 빠른 참조표 — 요소 판단·수준 사다리·역량 재료·대응표

## 1. 이 문장은 어느 요소인가 (판단 규칙)
| 문장이 말하는 것 | 요소 | 색 |
|---|---|---|
| 이 성취기준에서 학생이 **결과적으로 어디까지** 도달했나 | 성취수준 | 파랑 |
| 그렇게 판단한 **근거**: 평가 과제에서 실제로 한 일·소재·결과 | 수행 과정 및 결과 | 초록 |
| 수업·평가에서 관찰된 **역량** (관련역량 정의의 낱말이 있다) | 역량 | 빨강 |
| 특정 성취기준과 상관없는 **평소** 흥미·태도·습관 | 교사 총평 | 검정 |

- 요소는 연결어가 아니라 **내용**으로 가른다. "이를 통해"는 빨강(p.120, p.121)에도 초록(p.196)에도 나온다.
- 한 단락에 **파랑·초록·빨강은 반드시**, 검정은 필요할 때 넣는다(예시 6개가 모두 이렇다).
- 기재 지침([ch05](chapters/ch05-writing-guidelines.md))으로 보면 **파랑 + 초록**이 최소 단위다. 성취수준만 있고 관찰 근거가 없으면 "성취기준에 명시된 지식의 단순 서술"이 되기 쉽다.

## 2. 수준 사다리 — 평가기준 상·중·하에서 바뀌는 낱말 (원문)
| 성취기준 (2015) | 하 | 중 | 상 |
|---|---|---|---|
| [9정02-02] 자료 수집·관리 | 수집 + 저장 | 수집 + 관리 | 수집 + 체계적으로 분류·관리 + **공유** |
| [9정03-01]① 상태 파악 | 해결할 문제가 무엇인지 설명 | 현재·목표 상태 설명 | 현재·목표 상태 **명확히 정의** |
| [9정03-01]② 작업 분석 | 두 상태의 차이 설명 | 해야 할 작업이 무엇인지 설명 | 해야 할 작업을 **순서대로 제시** |
| [9정03-02] 요소 분류 | 요소 나열 | 필요·불필요 요소 구분 | 구분 + **이유 제시** |
| [9정03-04] 절차 표현 | 제시된 방법을 순서대로 표현 | 탐색 + 순서대로 표현 | 다양한 방법 탐색 + **논리적이고 명확하게** 표현 |
| [12정보05-03] 장치 구성 | 하드웨어 종류 제시 | 선택 + 역할 설명 | 선택하여 **구성** |
| [12정보05-04] 제어 프로그램 | 명령문 작성 | 프로그램 작성 | **효율적인** 프로그램 작성 |
| [12정보03-04] 제어 구조 설계 | 문제 해결 전략 설계 | **간단한** 문제 알고리즘 설계 | **복잡한** 문제 알고리즘 설계 |
| [12정보03-05] 성능 비교 | 분석 | 분석·비교 | 비교·분석 + 가장 효율적인 것을 **근거를 토대로 설명** |
| [12인기04-02] 데이터 영향 | (편향만) 이해 | 탐색 + 이해 | **효율적으로** 탐색 + **효과적으로 설명** |
| [12인기01-02] AI와 사회 변화 | 이해 | 탐색 + 이해 | 탐색 + 이해하여 **설명** |
| [12인기02-07] 지도·비지도학습 | 무엇인지 설명 | 차이 설명 | **사례를 들어** 비교·설명 |

**사다리 규칙 (정리)**: 나열 → 설명 → 구분·정의 → 순서대로 제시 → 이유·근거·사례를 들어 설명. 상으로 갈수록 동사가 늘고(탐색 + 표현), 대상이 넓어지고(간단한 → 복잡한), 수식어가 붙는다(체계적으로·명확히·논리적이고·효율적인).

## 4. 요소별 맺음 표현 (예시 원문에서)
| 요소 | 맺음 |
|---|---|
| 파랑 | ~함 / ~할 수 있음 / ~을 높은 수준으로 이해함 / ~을 구체적으로 제시함 |
| 초록 | '~' 활동에서 ~함 / ~를 예로 들어 ~를 설명하고 / 이를 바탕으로 ~함 / ~라는 결론을 내림 / 우수한 평가를 받음 |
| 빨강 | 이를 통해 ~ 능력을 발휘하였음 / ~ 능력을 함양하고 / 이 과정에서 ~ 모습을 보임 / ~하는 데 뛰어난 역량을 보임 / ~ 능력이 뛰어남 |
| 검정 | ~에 흥미를 가지고 / ~ 능력이 탁월함 / 평소 ~하는 등 ~ 자세를 가진 학생임 / ~에 관심이 많은 학생으로 / ~하고자 노력함 / ~모습이 인상적임 |

## 5. 이런 문장이면 고친다 (정리)
| 신호 | 고칠 점 |
|---|---|
| 파랑 문장에 소재·활동 이름이 길게 들어 있다 | 소재는 초록으로 옮기고 파랑은 평가기준 동사로 |
| 초록 문장이 "잘함·우수함"뿐이다 | 무엇을 어떻게 했는지(소재, 동사, 결과)로 바꿈 |
| 빨강 문장에 역량 정의 낱말이 없다 | 관련역량 정의에서 구 2~3개를 가져옴 |
| 검정 문장이 성취기준 결과를 되풀이한다 | 평소 태도·관심·확장 노력으로 바꿈 |
| 수준어(공유, 이유, 근거, 명확히)가 없다 | 평가기준 상·중·하에서 해당 수준의 낱말을 넣음 |
| 2015 성취기준 코드를 2022 학생에게 그대로 쓴다 | 아래 6절 대응표로 2022 성취기준 확인 |
| 활동 이름만 이어진다("~활동, ~활동에 참여함") | 기재 지침 위반(활동의 단순 나열). 활동 하나를 골라 소재·한 일·결과로 씀 ([ch05](chapters/ch05-writing-guidelines.md)) |
| 성취기준 문장을 그대로 옮겨 어느 학생에게나 맞는다 | 기재 지침 위반(성취기준 지식의 단순 서술). 학생이 고른 예와 만든 결과물로 바꿈 |
| "성실함·적극적임"만 있고 행동이 없다 | 참여도·태도를 관찰한 행동(질문, 검색, 오류 해결, 협업)으로 씀 |
| 변화·성장 문장에 전후 근거가 없다 | 관찰한 전과 후가 있을 때만 씀. 없으면 확장 노력("~하고자 노력함")으로 맺음 |
