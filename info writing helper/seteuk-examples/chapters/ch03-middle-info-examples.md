## 예시 1 — 1:1, 데이터 수집·관리 (p.120)

### 성취기준·평가기준 (원문)
- **[9정02-02]** 인터넷, 응용 소프트웨어 등을 활용하여 문제 해결을 위한 자료를 수집하고 관리한다.

| 수준 | 평가기준 |
|---|---|
| 상 | 인터넷을 활용하여 문제 해결을 위한 자료를 수집하고, 수집한 자료를 응용 소프트웨어를 활용하여 체계적으로 분류하고 관리하며 공유할 수 있다. |
| 중 | 인터넷을 활용하여 문제 해결에 필요한 자료를 수집하고, 수집한 자료를 응용 소프트웨어를 활용하여 관리할 수 있다. |
| 하 | 인터넷을 활용하여 자료를 수집하고, 수집한 자료를 컴퓨터에 저장할 수 있다. |

- **평가 과제**: 자신이 사용하는 물건 중 하나를 선택한 후 다양한 데이터를 수집･분석하여 '빅데이터 기반 사업 계획서' 작성하기
- **관련역량**: 의사소통 역량, 지식정보처리 역량, 정보문화소양

### 예시 문장 색 분해 (원문)
| 요소 | 문장 |
|---|---|
| 총평(검정) | (…) 문제 해결 수업에서 독창적인 아이디어를 제시하며, 데이터를 수집하고 분석하는 능력이 탁월함. |
| 성취수준(파랑) | 인터넷 설문 조사 도구와 데이터 포털을 활용하여 문제 해결을 위한 데이터를 효과적으로 수집, 관리하고 공유함. |
| 수행(초록) | ‘빅데이터를 활용한 사업 계획서 작성’ 활동에서 ‘텀블러’와 관련된 검색량 추이, 성별 및 연령별 조회 결과 등의 데이터를 분석하고 시각화함. |
| 수행(초록) | 데이터 분석 결과를 바탕으로 목표 고객을 설정하고 온라인 설문 조사를 통해 고객의 요구를 반영한 사업 계획서를 체계적으로 작성함. |
| 수행(초록) | 사업 구상 1분 발표 활동에서 논리적이고 설득력 있는 주장으로 다른 학생들에게 우수한 평가를 받음. |
| 역량(빨강) | 이를 통해 다양한 자료를 수집하고 분석하며, 적절한 매체를 활용하여 자료를 효과적으로 처리하는 데이터 분석 능력을 발휘하였음. (…) |

### 분석 (정리)
- **성취수준 = 평가기준 '상'의 동사 사슬**: 상의 수집 → 체계적으로 분류·관리 → 공유가 "효과적으로 수집, 관리하고 공유함"으로 줄었다. **'공유'** 가 상과 중을 가르는 낱말이다(중은 '관리', 하는 '저장'). '인터넷' 대신 '인터넷 설문 조사 도구와 데이터 포털'로 실제 도구를 넣었다.
- **수행 3문장 = 과제 진행 순서**: 고른 물건('텀블러') → 쓴 데이터(검색량 추이, 성별·연령별 조회) → 한 일(분석·시각화 → 목표 고객 설정 → 온라인 설문 → 계획서) → 결과(1분 발표, 동료 평가). 활동 이름은 작은따옴표로 인용했다.
- **관련역량 세 개가 나뉘어 드러남**: 지식정보처리는 빨강 문장(정의 구 "수집·분석", "적절한 매체를 활용", "효과적으로 처리")에 있다. 의사소통은 초록 문장의 "논리적이고 설득력 있는 주장"에, 정보문화소양은 "문제 해결을 위한 데이터" 활용에 녹아 있다.
- **총평으로 시작**: 특정 성취기준에 묶이지 않는 전체 인상("독창적인 아이디어", "능력이 탁월함")을 맨 앞에 두었다.

### 예시 문장 색 분해 (원문)
| 요소 | 문장 |
|---|---|
| 총평(검정) | (…) 알고리즘 설계와 프로그래밍에 흥미를 가지고, 주어진 문제를 해결하기 위해 절차적으로 사고하는 능력이 탁월하고, 효율적인 알고리즘을 작성함. |
| 성취수준(파랑) | 문제 상황을 분석하여 문제를 정의하고, 현재 상태와 목표 상태를 파악하며, 수행해야 할 작업을 구조화하여 문제 해결에 필요한 요소와 불필요한 요소를 명확하게 구분함. |
| 수행(초록) | 반장 선거를 효율적으로 진행할 수 있는 프로그램을 개발하기 위하여 초기 상태와 목표 상태를 정의함. |
| 수행(초록) | 프로그래밍의 개념과 원리를 이해 및 활용하는 능력이 우수하고, 작성한 프로그램의 가독성이 높고 기능별로 구조화하여 완성도 높은 프로그램을 구현함. |
| 역량(빨강) | 이를 통해 실생활 문제를 프로그래밍으로 해결하는 능력을 함양하고, 복잡한 문제를 분해하고 추상화하는 능력이 뛰어나며 주변의 다른 문제에도 적용하고자 노력함. (…) |

### 분석 (정리)
- **N:1 압축**: 성취기준 세 개의 결과를 **성취수준 한 문장**에 문제 해결 순서대로 이었다. 문제 정의·상태 파악(03-01 ①) → 작업 구조화(03-01 ②) → 필요·불필요 요소 구분(03-02). '명확하게'로 상 수준임을 표시했다.
- **[9정03-04] 절차 표현은 다른 요소에 흩어져 있음**: 파랑 문장에 직접 나오지 않는다. 총평의 "절차적으로 사고", "효율적인 알고리즘을 작성"과 초록의 "기능별로 구조화"가 이 성취기준을 받친다. N:1에서는 성취기준마다 문장을 따로 두지 않아도 된다는 사례다.
- **수행 = 구체 소재 하나**: '반장 선거' 프로그램 하나로 상태 정의와 구현 품질(가독성, 기능별 구조화, 완성도)을 모두 보였다.
- **역량은 컴퓨팅 사고력 정의 + 전이**: "실생활 문제를 프로그래밍으로 해결", "분해하고 추상화"에 이어 "주변의 다른 문제에도 적용하고자 노력함"으로 맺는다. 성장·확장을 보여 주는 맺음이다.
- 수행 문장에 "초기 상태"가 나오는데 이는 2022 개정 표현(초기·현재·목표 상태)과 같다.

## Key Takeaways
1. 파랑 문장은 평가기준 **'상' 문장의 동사들을 남기고** "~할 수 있다"를 "~함"으로 바꾼다. 수준을 가르는 낱말(공유, 명확하게, 이유)을 꼭 넣는다.
2. 초록 문장은 **활동 이름 → 학생이 고른 소재 → 한 일 → 결과** 순서다.
3. 빨강 문장은 "이를 통해"로 시작해 **관련역량 정의 구**로 채운다.
4. 중학교 예시 두 개는 모두 **총평으로 시작**한다. 교과 전체 인상을 먼저 주고 근거로 들어간다.
