# 앤더슨·크라스월의 신 교육목표 분류 체계 정리

## 0. Bloom의 개정 목표분류학: 수행 동사의 위계

```
  ▲ 상위 수준 사고 기술
  │
  │                 ▲
  │                ╱ ╲
  │               ╱ 6 ╲        창조함 ─ 지식을 사용하여 새로운 것을 만들어냄
  │              ╱─────╲
  │             ╱   5   ╲      평가함 ─ 정보를 검증하고 판단
  │            ╱─────────╲
  │           ╱     4     ╲    분석함 ─ 알려진 사실을 분리하여 관계를 확인
  │          ╱─────────────╲
  │         ╱       3       ╲  적용함 ─ 새로운 상황에서 정보 사용
  │        ╱─────────────────╲
  │       ╱         2         ╲  이해함 ─ 배운 내용의 의미를 이해
  │      ╱─────────────────────╲
  │     ╱           1           ╲  기억함 ─ 구체적 사실을 기억
  │    ╱─────────────────────────╲
  │
  ▼ 기초 수준 사고 기술
```

| 위계 | 단계 | 의미 | 수행 동사 |
|:---:|---|---|---|
| **6 (최상위)** | **창조함** | 지식을 사용하여 새로운 것을 만들어냄 | 도입하다, 조립하다, 작문하다, 구성하다, 만들다, 디자인하다, 개발하다, 가설을 세우다, 발명하다, 통합하다, 역할극하다, 도식화하다, 타당화하다, 용이하게 하다, 제안하다 |
| **5** | **평가함** | 정보를 검증하고 판단 | 감정하다, 논박하다, 평가하다, 비판하다, 토론하다, 편집하다, 추정하다, 등급을 매기다, 판단하다, 합리화하다, 설득하다, 순위를 매기다, 값을 매기다, 재구조화하다 |
| **4** | **분석함** | 알려진 사실을 분리하여 관계를 확인 | 분석하다, 유형화하다, 연결짓다, 논평하다, 다이어그램화하다, 분리하다, 유추하다, 조직하다, 계획하다, 우선순위를 매기다, 질문하다, 설문하다, 추산하다 |
| **3** | **적용함** | 새로운 상황에서 정보 사용 | 적용하다, 계산하다, 차트로 만들다, 검증하다, 예측하다, 풀이하다, 문제해결하다, 생산하다, 구성하다, 수정하다 |
| **2** | **이해함** | 배운 내용의 의미를 이해 | 연관짓다, 분류하다, 유사점을 찾다, 비교하다, 바꾸다, 설명하다, 구별하다, 그림으로 나타낸다, 순서대로 나열하다, 관계를 파악하다, 바꾸어말하다, 요약하다 |
| **1 (기초)** | **기억함** | 구체적 사실을 기억 | 정의내리다, 확인하다, 이름붙이다, 나열하다, 위치시키다, 짝짓다, 암기하다, 기억해내다, 암송하다, 알아맞히다, 기록하다, 재현하다, 언급하다, 말하다 |

> 아래쪽(기억함)이 **기초 수준 사고 기술**, 위쪽(창조함)이 **상위 수준 사고 기술**이다. 아래 본문의 인지 과정 차원(기억하기 → 이해하기 → 적용하기 → 분석하기 → 평가하기 → 창안하기)과 같은 위계다.

---

> 앤더슨과 크라스월(Anderson & Krathwohl, 2001)이 블룸(Bloom)의 교육목표 분류 체계를 수정·보완해 내놓은 **신 교육목표 분류 체계**의 유용성과 구조, 그리고 이를 활용해 수업목표와 수업활동을 뽑아내는 방법을 정리한 노트

---

## 핵심 요약

- 교육목표는 **동사(인지 과정)** 와 **명사(지식)** 로 이루어져 있어서, 목표를 **인지 과정 차원 6단계 × 지식 차원 4유형**의 2차원 표에 놓고 볼 수 있다.
- 이 표를 쓰면 목표마다 맞는 **교수 활동**과 **평가 방법**을 고를 수 있다. 이렇게 **목표, 교수, 평가를 서로 맞추는 것**이 학습자 중심 수업의 핵심이다.
- 실제로 목표를 분류할 때는 문장 표현이 모호한 경우가 많아서 **추론이 필요할 때가 많다**.
- 예시로 든 '옴의 법칙' 단원을 보면, 하나의 단원 목표를 지식 유형별, 인지 과정별로 나누어 구체적인 수업목표와 교수 활동으로 펼쳐 낼 수 있다.

## 1. 신 교육목표 분류 체계의 유용성

### 교사에게 주는 여섯 가지 유용성

| # | 유용성 | 내용 |
|---|---|---|
| 1 | 학생 관점의 목표 검토 | 목표를 이루려면 학생이 무엇을 알고, 무엇을 할 수 있어야 하는지 점검하게 해 준다 |
| 2 | 교육 가능성의 폭 확장 | 기억 위주의 사실적 지식 수업을 개념적·절차적·메타 인지 지식으로, 그리고 이해·적용·분석·평가·창안 수준까지 넓혀 고차원 목표를 가르칠 가능성을 높인다 |
| 3 | 지식과 인지 과정의 관계 파악 | 목표 안에 들어 있는 지식과 인지 과정이 어떻게 맞물리는지 보여 준다 |
| 4 | 평가 문항 작성 효율화 | 템플릿으로 문항을 찾고 교과 내용에 맞게 조금만 고치면 되므로, 좋은 문항을 짧은 시간에 만들 수 있다 |
| 5 | 목표·교수·평가의 일관성 점검 | 셋이 서로 맞는지 쉽게 확인할 수 있고, 목표가 교수 방법과 평가를 이끈다 |
| 6 | 용어 이해와 의사소통 | 인지 과정 관련 용어에 익숙해지게 해서 교사들끼리 소통하기 쉬워진다 |

### 학습자 중심 수업과의 관계: 목표, 교수, 평가의 일치

이 체계는 학생이 성취할 지식과 인지 과정뿐 아니라 **가장 알맞은 수업과 평가 방법**까지 알려 준다.

**예시 비교**

| 구분 | 목표 1: 유리수와 무리수를 구별한다 | 목표 2: 미국·영국 소설가들의 주요 작품명을 안다 |
|---|---|---|
| 분류 | 개념적 지식 **분석하기** | 사실적 지식 **기억하기** |
| 수업 활동 | 유목과 분류에 초점을 둔다. 예시와 예시가 아닌 것을 제시해 유목을 형성하게 하고, 상위 유목과 연결해 유목들 사이의 중요한 차이를 강조한다 | 사실을 기억하는 활동으로 구성한다. 기억할 사실(예: 줄거리·인물이 아닌 작품 이름)을 떠올리게 하고, 리허설 같은 기억 전략으로 암기 연습을 시킨다 |
| 평가 방법 | **수업이나 교과서에서 다루지 않은** 숫자 목록을 주고 "유리수인가 무리수인가?", "그 이유는?", "어떻게 바꾸면 다른 수 체계의 예가 되는가?" 등을 묻는다 | 수업이나 교과서에서 **다룬** 작품명을 주고 연결형 문제(왼쪽 소설, 오른쪽 작가)를 풀게 한다 |

**개념적 지식 '분석하기' 평가의 두 가지 특징**
1. 기억이 아니라 이해를 재야 하므로, 수업과 교과서에서 다루지 않은 예를 써야 한다.
2. 위의 세 가지 질문 유형은 개념적 지식을 분석하는 모든 목표 평가에 두루 쓸 수 있는 **청사진**이다.

> 이런 **목표-교수-평가의 일치**가 없으면 학습자 중심 수업은 비효과적이다.

## 2. 신 교육목표 분류 체계의 구조

### 기본 원리

- 교육목표는 **동사 + 명사**로 된 진술문이다.
  - **동사** = 학생이 수행할 **인지 과정** → 타일러의 표현으로는 '행동'
  - **명사** = 학생이 습득하거나 구성할 **지식** → 타일러의 표현으로는 '내용'
- 타일러는 목표를 학생이 발달시킬 행동의 종류와 그 행동이 다룰 내용으로 표현하는 것이 가장 유용하다고 보았다.
- **인지 과정 차원**: 기억하기 → 이해하기 → 적용하기 → 분석하기 → 평가하기 → 창안하기 (뒤로 갈수록 **복잡성** 증가)
- **지식 차원**: 사실적 → 개념적 → 절차적 → 메타 인지 지식 (뒤로 갈수록 **추상성** 증가)

### Anderson의 신 교육목표 분류표 (2차원 매트릭스)

| 지식 차원 \ 인지 과정 | 1. 기억하다 (remember) | 2. 이해하다 (understand) | 3. 적용하다 (apply) | 4. 분석하다 (analyze) | 5. 평가하다 (evaluate) | 6. 창안하다 (create) |
|---|---|---|---|---|---|---|
| **A. 사실적 지식** | A1 | A2 | A3 | A4 | A5 | A6 |
| **B. 개념적 지식** | B1 | B2 | B3 | B4 | B5 | B6 |
| **C. 절차적 지식** | C1 | C2 | C3 | C4 | C5 | C6 |
| **D. 메타 인지 지식** | D1 | D2 | D3 | D4 | D5 | D6 |

### 2-1) 지식 차원과 하위 유형

| 지식 차원 | 하위 유형 | 예 |
|---|---|---|
| **A. 사실적 지식**: 학문에 친숙해지거나 학문 안의 문제를 풀기 위해 알아야 할 기본 요소 | 용어에 대한 지식 | 기술적 어휘, 음악 기호 |
| | 세부 사항과 요소에 대한 지식 | 주요 천연자원, 신뢰할 만한 정보원 |
| **B. 개념적 지식**: 기본 요소들이 함께 작동하도록 묶어 주는 더 큰 구조 속 관계 | 분류와 유목에 대한 지식 | 지질학적 시기, 기업 소유 형태 |
| | 원리와 일반화에 대한 지식 | 피타고라스 정리, 수요·공급 원리 |
| | 이론, 모델, 구조에 대한 지식 | 진화론, 의회 구조 |
| **C. 절차적 지식**: 무언가를 하는 방법, 탐구 방법, 기능·알고리즘·기법, 방법 사용 준거 | 교과 특유의 기능과 알고리즘 | 수채화 그리기 기능, 정수 나눗셈 알고리즘 |
| | 교과 특유의 기법과 방법 | 인터뷰 기법, 과학적 방법 |
| | 적절한 절차를 언제 쓸지 정하는 준거 | 뉴턴 제2법칙 절차의 적용 시점 판단 준거, 비용 추정 방법의 타당성 판단 준거 |
| **D. 메타 인지 지식**: 인지 전반에 대한 지식과 자기 인지에 대한 인식 | 전략적 지식 | 단원 구조를 잡는 개요화 지식, 발견법 사용 지식 |
| | 맥락적·조건적 지식을 포함한 인지 과제에 대한 지식 | 교사별 시험 유형, 과제별 인지적 요구 |
| | 자기 자신에 대한 지식 | "에세이 비평은 강점이고 쓰기는 약점"이라는 인식, 자기 지식 수준에 대한 인식 |

### 2-2) 인지 과정 차원과 하위 유형

| 인지 과정 | 정의 | 하위 유형 | 예 |
|---|---|---|---|
| **1. 기억하기** | 장기 기억에서 알맞은 지식을 되찾기 | 1-1 인지하기 | 역사적 사건이 일어난 날을 알아보기 |
| | | 1-2 상기하기 | 역사적 사건이 일어난 날을 떠올리기 |
| **2. 이해하기** | 문어·구어·시각적 메시지에서 의미를 구성하기 | 2-1 해석하기 | 연설이나 기록을 다른 말로 표현하기 |
| | | 2-2 예 들기 | 여러 미술 양식의 예 제시하기 |
| | | 2-3 분류하기 | 정신 질환 사례 분류하기 |
| | | 2-4 요약하기 | 사건 줄거리 요약하기 |
| | | 2-5 추론하기 | 예들로부터 문법 원리 추론하기 |
| | | 2-6 비교하기 | 역사적 사건을 현대 상황과 비교하기 |
| | | 2-7 설명하기 | 18세기 프랑스 주요 사건의 원인 설명하기 |
| **3. 적용하기** | 주어진 상황에서 절차를 수행하기 | 3-1 집행하기 | 정수를 정수로 나누기 |
| | | 3-2 활용하기 | 어떤 상황에 뉴턴 제2법칙이 맞는지 판단하기 |
| **4. 분석하기** | 재료를 요소로 나누고, 부분끼리, 그리고 전체 구조·목적과 어떤 관계인지 판단하기 | 4-1 구별하기 | 수학 문장제에서 필요한 숫자와 필요 없는 숫자 구별하기 |
| | | 4-2 조직하기 | 역사 기록의 증거를 찬반 증거로 구조화하기 |
| | | 4-3 귀인하기 | 에세이 저자의 관점을 정치적 입장에서 파악하기 |
| **5. 평가하기** | 준거나 표준에 기초해 판단 내리기 | 5-1 점검하기 | 과학자의 결론이 관찰 데이터에 기초했는지 판단하기 |
| | | 5-2 비평하기 | 문제 해결 방법 두 가지 중 최선 판단하기 |
| **6. 창안하기** | 요소들을 묶거나 새 패턴·구조로 재조직해 일관된 전체를 만들기 | 6-1 생성하기 | 관찰된 현상을 설명할 가설 세우기 |
| | | 6-2 계획하기 | 역사 주제 리서치 보고서 계획하기 |
| | | 6-3 산출하기 | 특정 목적에 맞는 생물 서식지 짓기 |

## 3. 수업목표 추출의 예: '옴(Ohm)의 법칙' 단원

### 3-1) 지식 차원별 목표 지식

| 지식 차원 | 목표 지식 |
|---|---|
| 사실적 지식 | 전류, 전압, 저항에 대한 지식 |
| 개념적 지식 | 전기 회로라는 개념 체계 안에서 요소들 사이의 인과 관계에 대한 지식 |
| 절차적 지식 | 옴의 법칙(전압 = 전류 × 저항)으로 수치를 계산하는 절차 |
| 메타 인지 지식 | 옴의 법칙을 외우는 기억술 전략, 옴의 법칙 학습·적용에 대한 자기 목표 설정 등 |

### 3-2) 인지 과정 차원별 수업목표 (11가지)

| 코드 | 인지 과정 | 수업목표 예 |
|---|---|---|
| A-1 | 사실적 지식 회상하기 | 전류, 전압, 저항의 측정 단위 회상하기 |
| B-1 | 개념적 지식 회상하기 | 전기 회로의 구조를 기억을 더듬어 그리기 |
| C-1 | 절차적 지식 회상하기 | 옴의 법칙 적용 단계 기억하기 |
| D-1 | 메타 인지 지식 회상하기 | 난관에 부딪쳤을 때 "실패한 접근을 고집하지 말고 다른 전략을 찾아라!"라는 전략 구호 떠올리기 |
| A-2 | 사실적 지식 해석하기 | 전류, 전압, 저항을 자기 말로 정의하기 |
| B-2 | 개념적 지식 설명하기 | 회로의 변화가 전류에 미치는 영향 설명하기 |
| C-3 | 절차적 지식 집행하기 | 전류와 저항 값이 주어졌을 때 전압 계산하기 |
| B-4 | 개념적 지식 구별하기 | 문장제에서 저항 계산에 필요한 정보 가려내기 |
| C-5 | 절차적 지식 점검하기 | 예전에 성공했던 해결책이 지금 문제에도 맞는지 검토하기 |
| D-5 | 메타 인지 지식 비평하기 | 자기 이해 수준에 맞는 해결 계획 고르기 |
| B-6 | 개념적 지식 생성하기 | 배터리를 바꾸지 않고 전구를 더 밝게 하는 다른 방법 생각해 내기 |

### 3-4) 수업목표 분류가 어려운 두 가지 이유

목표는 정확히 분류하기 어려울 때가 많아서, 종종 **추론**으로 분류해야 한다.

**① 동사·명사 말고 다른 수식 표현이 섞여 혼란을 준다**
- "지역사회에서 수요와 공급의 법칙의 예들을 제시할 수 있다." → 동사 '예를 제시한다', 명사 '수요와 공급의 법칙' = **개념적 지식 이해하기**. '지역사회에서'는 예를 고르는 조건일 뿐, 분류와는 상관없다.
- "적절한 구어와 문어의 형태의 준거를 만족시킬 독창적 작품을 생산한다." → 동사 '생산한다', 명사 '준거' = **개념적 지식 창안하기**. '적절한 구어와 문어의 형태의'는 준거의 뜻을 풀어 주는 말일 뿐이다.

**② 동사가 뜻하는 인지 과정이나 명사가 뜻하는 지식이 모호하다**
- "물질의 변화와 그 변화의 원인을 기술한다." → '기술한다'가 상기, 해석, 설명, 생산 가운데 무엇을 뜻하는지 분명하지 않다.
- "신문과 잡지에 실린 사설들을 평가할 수 있다." → 동사 '평가'는 분명하지만 '사설'은 지식 유형이 아니라 학습 자료일 뿐이다. 평가 준거(편견의 존재 여부, 관점의 명료성, 주장의 논리성 등)를 개념적 지식으로 추정하면 **개념적 지식 평가하기**로 볼 수 있다.

## 4. 수업활동 추출의 예

### 단원 목표
> 과학과: "전류와 자기의 법칙을 활용하여 여러 가지 문제를 해결한다." → **개념적 지식 적용하기(활용하기)** 목표

### 4-1) 지식 차원 분석: 필요한 세 가지 지식

1. 풀어야 할 문제의 유형을 판단하는 능력 → **개념적 지식**
2. 알맞은 법칙을 골라 실행하는 능력 → **절차적 지식**
3. 해결책을 계획하고 점검하고 고치는 능력 → **메타 인지 지식**

따라서 교수 활동은 이 세 가지 지식을 익히도록 돕는 데 초점을 둔다.

### 4-2) 인지 과정 차원 분석

- 세 활동의 동사 **결정하기, 선택하기, 적용하기**는 각각 다음에 해당한다.
  - 결정하기 → 이해하기의 **분류하기**
  - 선택하기 → 분석하기의 **구별하기**
  - 적용하기 → 적용하기의 **실행하기**
- 실행하는 동안 여러 선택을 해야 하므로, 과정을 **점검하고** 결과를 **비평하는** 활동(평가하기)도 들어가야 한다.

### 4-3) 종합

교수 활동은 **세 가지 지식**(개념적, 절차적, 메타 인지)과 **여섯 가지 인지 과정**(상기하기, 분류하기, 구별하기, 실행하기, 점검하기, 비평하기)을 포함해야 한다. 이 인지 과정들은 기억하기부터 평가하기까지 다섯 개의 인지 과정 차원에 걸쳐 있다.
